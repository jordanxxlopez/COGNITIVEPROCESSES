Put them on my calculator

  1. Download the ZIP on my computer and extract it.
  2. Install TI Connect™ CE from Texas Instruments, then connect the calculator with its USB cable.
  3. Open Calculator Explorer in TI Connect CE. Drag the .8xp files inside the programs folder into it, choose the connected calculator, and send them to RAM.
  4. On the calculator, press PRGM → EXEC, select a name such as BMONE, press ENTER to paste its name, then ENTER again to run.
  5. Enter each requested value and press ENTER. For a negative number, use the calculator’s (−) key. Enter probabilities as decimals, such as .05.

BME423 is an optional chooser menu; it needs the calculation files installed too. Every other program works on its own. If memory is tight, send just the programs I want and archive unused ones.

The programs use A–Z, θ, and scratch lists beginning BM. They set Float/Normal/Real modes. Existing L1–L6 lists are left alone.
