## p3
- **Two recognition problems show what a neural network, or NN, is built to do.** In the first, a huge number of images of faces, each made of about **48 million pixels**, must each be classified (assigned) to one of **1000 possible people**. In the second, **speech waves** must each be assigned to one of **25 sounds**. A neural network is the kind of system that can solve both.
  - A pixel is one tiny dot of an image. It is stored as a number for its brightness or color. So a single face image is really a list of about 48 million numbers. A speech wave is also stored as a list of numbers, one per moment in time. So both problems have the same form. Numbers go in, and a choice among a fixed set of options comes out.
- **The name is not explained yet. The network is defined by its behavior, what it takes in and what it gives back.** Its job is to take a bunch of numbers, such as the 48 million pixel values of one image, and return a **probability distribution**, written here as a **pdf**.
  - A probability distribution is a list of probabilities, one for each possible answer. Each says how likely the network thinks that answer is. For the speech problem with 25 sounds, the distribution has 25 numbers. For the face problem with 1000 people, it has 1000.
- **With only 5 vowels, in the agreed order read, rad, rude, Rud and rod, a possible pdf for one speech wave is [0.2, 0.2, 0.4, 0.2, 0].** Each position lines up with one vowel in the agreed order. This pdf says there is a 20 percent chance the sound is the vowel in read. There is a 20 percent chance for rad, 40 percent for rude, 20 percent for Rud and 0 percent for rod.
  - The agreed order matters for reading the list. The numbers carry no meaning unless everyone knows which position belongs to which vowel.
  - The probabilities in a pdf **must sum to 1**, the same as 100 percent. Here 0.2 plus 0.2 plus 0.4 plus 0.2 plus 0 is 1.0. The sum has to be 1 because the sound must be one of the five vowels. So all the possible answers together account for all of the chance.
  - The network's best guess is the vowel in rude, because 0.4 is the largest number. It is still not certain. Sixty percent of the probability is spread over other vowels.

## p4
- **The input of a neural network is a bunch of numbers, also called a signal or a vector.** A vector is an ordered list of numbers, such as [4, 1, minus 3, 2, 1, 0.4, 1, 2, minus 3, and so on]. Real inputs usually contain thousands of numbers. In the speech case these could be the **pressure numbers of a speech wave**, the air pressure sampled (measured) at each moment as the sound passes.
- **The output is a decision pdf.** Given the input signal, the network returns the probability of each possible object. Here that is each of the vowels in read, rad, rude, Rud and rod.
- **The network can decide because it has knowledge, stored in a large set of numbers called weights, written w.** The input vector is combined with these weights through many calculations. At the end, a decision about which object was detected comes out.
  - Large networks have **several trillion weights**. Making one decision involves **billions of calculations**. The weights are what separate a network that decides well from one that decides badly. Two networks with the same structure but different weights give different answers to the same input.
- **The weights are not set by hand, so the network finds them on its own.** The plan is "Fake it till you make it," or FITYMI. It is carried out by stochastic gradient descent, SGD. The procedure runs as a loop.
  - Step 1, random weights: The network starts with **random weights**, which contain no real knowledge.
  - Step 2, one signal: It is given one signal, say a recording of the vowel in **Rud**.
  - Step 3, forward propagation: It runs **forward propagation**. It pushes the input through all of its calculations with its current weights to produce a pdf. With random weights that pdf does not reflect reality. It might return [0.4, 0.1, 0.2, 0.2, 0.1].
  - Step 4, the target: The network is told its answer is wrong. The correct pdf is [0, 0, 0, 1, 0], 100 percent on the vowel in Rud and 0 on everything else. The gap between what it said and what it should have said is its **error**, also called its **loss**. 
  - Step 5, the update: The network adjusts its weights so that the loss becomes smaller.
  - Step 6, the repeat: It is given another signal, and the loop repeats, **billions of times**.
- **The wrong pdf in step three shows why the loss is large.** The network put 0.4 on the vowel in read, its highest value. It put only 0.2 on the vowel in Rud, the true answer. Its numbers still sum to 1. So it is a valid probability distribution. But the probability is in the wrong places.
  - Learning means moving probability toward the correct answer. After many rounds, the network puts nearly all of it on the vowel that was actually spoken. The correct pdf, with all of its probability on a single answer, is the target the network is pushed toward.

## p5
- **Two big questions describe how a neural network works.** **Learning** asks how, specifically, a network learns its weights. **Inference** asks how, specifically, a network combines its weights with its inputs to produce an output.
- **Inference is answered first, because inference is part of learning.** Every round of learning begins with forward propagation. Forward propagation is inference. The network cannot measure its loss until it has combined the input with its current weights and produced an answer. So the exact calculation used in inference has to be understood before learning can be.

## p6
- **Santiago Ramón y Cajal established that the brain is made of neurons, separate individual cells rather than one continuous web.** The figure is **Cajal's drawing of a retinal circuit**, from Recuerdos de mi vida, volume II, 1917, Figure 40. It is cropped to one half and rotated so that the main direction of signal flow runs from left to right.
  - Circles mark the **somata**, the cell bodies holding the nucleus. Each neuron is given a number called its **activity** or **activation**. It can be positive or negative. Negative values are quantities used in artificial neurons. They do not mean that a real neuron fires at a negative rate, which is impossible.
  - Arrows mark selected **synaptic contacts**, the points where one neuron connects to another. Signals travel rightward through them to a receiving neuron. Each contact is labeled with a **weight w**, a signed number. A **synaptic weight** says how strongly, and in which direction, one neuron's activity affects the next. A positive weight pushes the receiving neuron's activity up. A negative weight pushes it down.
- **The circuit reduces to three input neurons and one receiving neuron.** The three input neurons have activations of minus 1, 1 and 3. Their connections carry weights of minus 2, 3 and 1.
- **One neuron computes a weighted sum.** The receiving neuron multiplies each input activation by the weight of its connection and adds up the products. Minus 1 times minus 2 is 2, because a negative activation times a negative weight is positive. So this input raises the receiving neuron's activity. Then 1 times 3 is 3, and 3 times 1 is 3. Adding gives 2 plus 3 plus 3, which is 8. So 8 becomes the activation of the receiving neuron. No extra constant, called a **bias**, is added here.
- **This weighted sum has several names that all mean the same operation, the inner product, the scalar product and the dot product.** Each takes two lists of the same length, here the activations [minus 1, 1, 3] and the weights [minus 2, 3, 1]. It multiplies them position by position. It adds the results into one number.
  - It is called the scalar product because its result is a scalar (a single number). The same idea appears as the integral of f times g. When the two lists are replaced by two continuous functions, multiplying position by position becomes multiplying the functions point by point. Adding up the products becomes taking an integral.
  - This operation is the answer to the inference question at the level of one neuron. A neuron in an artificial network combines its inputs with its weights by taking the dot product of the incoming activations and the incoming weights.

## p7
- **The brain works through chemistry and electrical activity. Neural networks work through arithmetic. Three publications mark the turning of one into the other.**
  - In 1943, **Warren McCulloch and Walter Pitts** published "A Logical Calculus of the Ideas Immanent in Nervous Activity." It treated nervous activity as something that could be described with formal logic and calculation.
  - In 1962, **Frank Rosenblatt** published Principles of Neurodynamics, subtitled Perceptrons and the Theory of Brain Mechanisms. It developed the **perceptron**, an artificial neuron that computes a weighted sum of its inputs and uses it to make a decision.
  - In 1986, **David Rumelhart, James McClelland and the PDP Research Group** published Parallel Distributed Processing, subtitled Explorations in the Microstructure of Cognition, Volume 1, Foundations. It described cognition as the activity of many simple neuron-like units working at the same time, with knowledge spread across the weights between them. It also presented backpropagation, the learning method for networks with many layers.
- **Over these four decades, the electrical and chemical activity of neurons came to be described as numbers.** The passing of signals across synapses came to be described as multiplying by weights and adding. That is the same weighted-sum calculation performed by a single artificial neuron. Moving from chemistry and electricity to arithmetic is a modeling step (an idealization of the brain). It is not a claim that the physical substrate is identical.

## p8
- **There are two opposing beliefs about how modern AI relates to the human mind. They are views, not exam material.**
  - Most engineers, neuroscientists and people in general hold that modern AI has nothing to do with how humans think, perceive, act or decide. On this view the brain is full of chemistry, electrical activity and abstract processes. None of that is part of **large language models**, which are made only of numbers and arithmetic.
  - A smaller group, including Khalil Iskarous, holds that modern AI is the result of about 100 years of gradual, evolutionary tinkering with how arithmetic can **emulate the chemical and electrical activity of the brain**. On this view those attempts appear to have succeeded. So the arithmetic in modern AI is a working imitation of brain activity rather than something unrelated to it.

## p9
- **A multilayer perceptron, or MLP, is a neural network built from layers of artificial neurons, where every neuron in one layer connects to every neuron in the next.** The example network has five layers in a row, an **Input** layer, **Hidden 1, Hidden 2, Hidden 3**, and an **Output** layer. The middle layers are **hidden layers**. They are neither the input given to the network nor the answer it gives back.
  - The layer sizes are 5, 3, 4, 3 and 7. Every connection between neighboring layers carries its own weight w. So the number of connections is 5 times 3 plus 3 times 4 plus 4 times 3 plus 3 times 7. That is 15 plus 12 plus 12 plus 21, or **60 weights**. Real networks follow the same design with far more neurons per layer. That is how the count reaches the trillions.
- **Every neuron in a hidden layer does exactly what the single neuron in Cajal's circuit did.** It receives activations from all neurons in the layer before it. It multiplies each by the weight of its connection. It adds the products. This is the dot product again, repeated for every neuron in every layer.
  - The five input neurons carry 2, 1, 3, 4 and 2. The middle neuron of Hidden 1 has incoming weights 2, minus 1, 1, 3 and minus 2. So its activation is 2 times 2 plus 1 times minus 1 plus 3 times 1 plus 4 times 3 plus 2 times minus 2. That is 4 minus 1 plus 3 plus 12 minus 4, or 14. The largest contribution is the fourth input, 4 times 3. The two negative weights pull the total down.
  - The top neuron of Hidden 1 uses the weights 0.5, 1, 1, minus 0.5 and 0.5. That gives 1 plus 1 plus 3 minus 2 plus 1, or 4. The bottom neuron uses minus 1, 0.5, 0.5, minus 1 and 0.5. That gives minus 2 plus 0.5 plus 1.5 minus 4 plus 1, or minus 3. So Hidden 1 comes out as 4, 14 and minus 3.
- **The same calculation then moves forward one layer at a time.** Hidden 1's activations become the inputs to Hidden 2. The top neuron of Hidden 2 has weights 1, 0.25 and 0.5. So its activation is 4 plus 3.5 minus 1.5, or 6. The four neurons of Hidden 2 end up as 6, minus 2, 5 and 1. Those feed Hidden 3, whose three neurons end up as 3, minus 1 and 2.
  - Passing activations from layer to layer this way, from the input all the way to the output, is **forward propagation**. It is the full answer to the inference question. The network combines its weights with its inputs by computing dot products, layer after layer.
  - The hidden layers use **linear hidden activations**. So each neuron's activation is simply its weighted sum, with nothing further done to it and no bias added. A usual MLP adds a **nonlinear activation function** at each hidden neuron, which applies a nonlinear transformation (reshapes the weighted sum) before passing it on. That step is left out here so the arithmetic stays pure dot products.
- **The output layer has 7 neurons. Its final values 0.05, 0.10, 0.20, 0.30, 0.15, 0.12 and 0.08 come from a softmax step.** Each output neuron first computes a weighted sum of Hidden 3's activations, a raw score. Softmax then converts the seven raw scores into seven positive numbers that sum to 1.00. Larger scores turn into larger probabilities.
  - Softmax is what turns the network's arithmetic into the **decision pdf** a neural network is supposed to return. Here the fourth output gets the highest probability, 0.30. So it is the network's best guess among the seven possible answers.

## p10
- **The same network is given a new input, and the pop quiz asks for the activation of Hidden 1, Neuron 2.** The five input neurons now carry minus 2, 1, 3, minus 4 and 2. The five weights into the second neuron of Hidden 1 are 3, minus 2, 1, 2 and 5.
- **The activation is the dot product of the inputs and the weights.** The first input, minus 2, times 3 gives minus 6. The second, 1, times minus 2 gives minus 2. The third, 3, times 1 gives 3. The fourth, minus 4, times 2 gives minus 8. The fifth, 2, times 5 gives 10. Adding gives minus 6 minus 2 plus 3 minus 8 plus 10, which is minus 3. **The activation of Hidden 1, Neuron 2 is minus 3.**
  - The hidden activations are linear. So the answer is just the weighted sum, with no bias added and no further function applied. The output neurons stay empty until every layer before them has been computed, because each layer depends on the one before it.

## p12
- **Learning follows the "Fake it till you make it" plan.** The multilayer perceptron starts with **random weights**. One **input-output pair**, an I/O pair, is picked at random to learn from. An I/O pair is one input together with the correct answer for it. Here the input is x equal to [minus 2, 1, 3, minus 4, 2]. The correct output is [0, 0, 0, 0, 0, 1, 0], all of the probability on the sixth of the seven answers.
- **With random weights, forward propagation produces a pdf that is wrong.** Suppose the network returns 0.05, 0.10, 0.20, 0.30, 0.15, 0.12 and 0.08. It gives only 0.12 to the sixth answer, which should have received 1. It gives its highest probability, 0.30, to the fourth answer, which should have received 0. The difference between this pdf and the true pdf is the network's loss for this pair.
- **The network then changes its weights to make its output pdf closer to the true one.** The method is **SGD**, which in neural networks is now called **backpropagation**. The error measured at the output is passed backward through the layers. Each of the 60 weights is adjusted in the direction that makes the loss smaller.
  - After one adjustment, the network with this same input would give a little more probability to the sixth answer and a little less to the others. One adjustment does not make the network correct. It only makes it slightly less wrong.
- **The process is repeated over and over again with billions of I/O pairs.** Each pair gives one small correction. Over billions of corrections, the weights come to hold real knowledge about which inputs go with which outputs. This repeated training on billions of pairs is the work carried out at **data centers**.

## p13
- **SGD can be applied to a much simpler problem, estimating the average of a list of numbers.** Here the weight w is a single number, the estimate of the average of [73, 90, 98, 46, 400, 81, 82, 78, 62, 91, 61, 84, 75, 84, 81, 75]. The network in this case has just one weight. Learning means finding the value of w that best represents the whole list.
- **One of the numbers, 400, is a mistake.** Every other number lies between 46 and 98. So 400 does not belong with the rest of the data. Even so, it strongly affects the mean (the average). The full list has 16 numbers whose sum is 1561. And 1561 divided by 16 is about 97.56. So the actual average including the mistake is **about 100**.
  - Without the mistake, the true average is **about 80**. Removing 400 leaves 15 numbers with a sum of 1161. And 1161 divided by 15 is 77.4. So a single bad data point raises the average by about 20.
  - An estimate of w learned from this data will be pulled toward the mistake. In the same way, a neural network trained on data that contains errors will learn some of those errors. Accurate arithmetic does not correct an erroneous (incorrect) observation on its own.
- **SGD sees data points one at a time in a random order.** For simplicity, the list is assumed to already be in the random order in which the data will arrive. So w is first compared against 73, then 90, then 98, and so on through the list. After each number, w is adjusted to reduce its error on that number. This follows the same loop the neural network uses on its I/O pairs.
