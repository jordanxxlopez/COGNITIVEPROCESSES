## p2
- This **neural network** copies a very simple piece of human perception. It takes the **two formants**, F1 and F2, of a single vowel said on its own, and it decides which of five words it heard, **done, dune, dean, Don or Dan**. It has 2 input neurons, hidden layers of 3, 2 and 4 neurons, and 5 output neurons. Every neuron connects to every neuron in the next layer.
- **The weights are the network's knowledge.** Each weight is a positive or negative number. For each recording, the network is told the right answer as a probability distribution. For a speaker's /i/, it is told **0, 0, 1, 0, 0**, which means a 100 percent chance that the word was dean.
  - At first, **the weights are random**, so the network knows nothing. The distribution it produces is usually very different from the right answer.
  - That difference is a **mistake**, and the network learns by correcting its mistakes.

## p3
- **Forward propagation** carries the input through the network. Take **F1 of 320 and F2 of 2000**, which is one speaker's /i/. Each neuron in the first hidden layer computes an **inner product**, which means it multiplies each formant by its weight and adds the results. Those activations go into the next layer, which does its own inner products. This continues until the output gives a probability for each word.
  - With random weights, the network gives its highest probability, more than half, to **done**. So it decides it heard done, even though the right answer is dean.
- To fix the mistake, **all the weights have to change**, both the ones near the output and the ones near the input. The method that does this is **backpropagation**, which combines **stochastic gradient descent** and **dynamic programming**.

## p4
- **Changing a weight at the very end changes the output probabilities right away.** The output probabilities are the network's decision, and the last weights are exactly the ones used in the final inner products.
  - For example, the probability of done comes partly from a weight of 0.1 times an activation of about 1.57.
  - The network said done, but the answer was dean, so the probability of done is **too high**. Raising that 0.1 to 0.5 would make the probability of done even higher, which is the opposite of what we want. So that weight should go **down**.
  - For the last weights, it is easy to tell whether each one should go up or down.
- **Changing a weight near the input sets off a chain of changes.** It changes the activations in the first hidden layer. Those change the second hidden layer, which changes the third, which finally changes the decision.
  - So deciding how to change an early weight is a very hard problem. It is like the dynamic programming puzzle where always picking the smallest next step gives the wrong answer.

## p5
- The real formant data from the class shows why AI is hard. Each recording is a dot. **F1 is on the horizontal axis**, and **F2 is on the vertical axis**. There are 525 dots, 105 for each vowel.
  - Pattern: The data does show a pattern. The **/i/ dots are high up**, with a **high F2 and a low F1**, just as the theory predicts. And /i/ is clearly different from /u/.
  - Overlap: There is also **a large amount of overlap**. Many /æ/ dots sit among the /i/ dots, and many others overlap with schwa. The /u/, /a/ and schwa groups of dots pile on top of each other.
  - Errors: Some dots are probably measurement mistakes. Real data always has errors, the same way speech recorded by a phone on a noisy train has errors. So these dots were left in.
- **If each vowel's dots formed its own separate group, AI would be easy.** Because the groups overlap, a network has to see the data many times to learn where each vowel is most likely. Even then, many points are unclear. If a new speaker's formants land in the middle of the overlap, the best the network can do is pick the vowel whose dots are most common there.
  - People tried for about seventy years to remove the differences between speakers, which is called **normalization**, without success. Hearing a lot of speech from the same speaker does help, because it gives the system more information about that person.
  - This overlap was first discovered in the early 1950s by **Peterson and Barney**. During the Second World War, spectrograms were kept secret by the military, and the overlap was found once spectrograms became available.
  - Good speech recognition only arrived around 2011 or 2012, using neural networks trained by backpropagation. Surprisingly, speech that changes over time turned out to be easier for modern systems than this frozen, one-moment problem.

## p7
- **Stochastic gradient descent** is the same method used to improve an average from data. Here it is used to improve every weight. It has the same **learning rate**, with the same tradeoff between learning fast and learning accurately.
- **Dynamic programming** decides the order. The weights at the end are improved first, then the weights before them, and so on back to the beginning. So the easiest problem is solved first, and the hardest problem is solved last.
  - The error tells the network which way each output should move. Done, at about 56 percent, should go down. Dean should go up, and the other words should go down.

## p8
- For the last weights, one inner product connects each weight to the decision, so the direction of the change is clear. The network said done when the answer was dean. So any last weight that pushes done up should be **lowered**, and any last weight that pushes dean up should be **raised**.
  - A good exam answer says which way the weight should move and then explains why. Name the activation the weight multiplies and the output it feeds into.

## p9
- **Backpropagation changes the last weights first, then the weights before them, and so on back to the first weights.** Each problem gets easier because something has already been learned from the problems solved before it.
  - Modern systems use this same method on about **six trillion weights**. That is what the huge data centers are doing.
  - **Geoffrey Hinton** won the **2024 Nobel Prize in Physics** for backpropagation. This idea is at the center of much of today's economy, and it has roots in physics through dynamical systems.
  - Put simply, it is easiest to blame the weights closest to the mistake. That blame is then passed backward to the weights that came before them.

## p10
- Training uses **two matrices** of numbers. The first has one row per recording with **F1 and F2**. The second has a matching row of **zeros and a single one**, which marks the vowel the recording really was. During learning, the network picks a row, makes its decision, and compares it with the true answer. If the decision is wrong, the weights change.
- **If the network makes the right decision, there is no error, so it has nothing to learn.** This can be a real problem. A network can keep getting the right answer by **memorizing** its data without learning the real pattern underneath. Stopping the learning at that point would be stopping too early.
- Children learning English show the same thing, as **Carol Chomsky** observed in the early 1960s.
  - Stage 1: Very young children say **go** and **went** correctly, because they are just **memorizing** what they hear.
  - Stage 2: Children notice the real pattern, that most English verbs make the past tense by adding a sound at the end, as in **jump** and **jumped**. As a result, they start saying **goed**.
  - Stage 3: Children learn that some verbs are **exceptions**, and they get both the regular verbs and the exceptions right.
  - A right answer early on can come from memory, and real learning can show up as new mistakes.

## p11
- **The import lines bring into Python the programs for inner products, backpropagation and related work**, so none of that has to be written by hand. The exam can ask what these lines mean, but it will never ask you to write the program from scratch.
  - Libraries: This works because of **libraries**. A library is a collection of programs written by one group that other people can use without knowing how they work inside. The idea of building software this way goes back to **Margaret Hamilton's** work on the software that flew **Apollo 11** to the moon.
  - PyTorch and TensorFlow: Around 2015, **Facebook** released **PyTorch** and **Google** released **TensorFlow**. After that, researchers no longer had to write their own backpropagation code. Most people now use PyTorch, which is often just called torch.
  - Load lines: The **load** lines read the formant matrix and the matching vowel matrix from files on the computer.
- **Sequential means the network is a sequence of layers**, one after another. Every network covered so far is like this. A large language model is an example of a network that is not just a sequence of layers.
  - Linear lines: Each **Linear** line is one **processing layer**. A processing layer has weights and does inner products with the numbers coming in. The input layer does no processing, so the five layers need only **four lines**.
  - nn.Linear(2, 3): The line reads as "this layer receives information from 2 neurons, and it has 3 neurons." The other lines read the same way.
- The last lines are all PyTorch needs for learning.
  - SGD and lr: **SGD** is stochastic gradient descent, and **lr** is the **learning rate**, set here to 0.1. **A higher learning rate learns much faster but less accurately. A lower learning rate learns more accurately but much more slowly.**
  - So changing the learning rate from 0.1 to 0.3 makes the network **learn faster**, but its **accuracy goes down**.
  - Loss, backward and step: **Loss** is the measure of the **mistake**. The program calculates the mistakes so it can learn from them. **backward** runs **backpropagation**, and **step** updates the weights.

## p12
- Artificial neural networks borrow their basic ideas from discoveries about real brains. Real brains have **neurons**, and each neuron **collects information from many other neurons**, which is what the inner product does.
- **Lord Edgar Adrian** discovered in the 1920s that **neurons are nearly digital**, and he won the **Nobel Prize in 1932**. A real neuron is either **firing** or **not firing**. It is not at some level in between like 2, 16 or 34. But the neurons in the network so far have activations that can be any number, like slightly below zero, 6.64, 2.72 and 1.57.
- The **sigmoid** is an **activation function** that makes the network work more like Adrian's discovery. It takes an inner product and gives back a number between zero and one.
  - Large negative input: An inner product of **minus 4**, minus 6 or minus 1000 gives about **zero**, so the neuron is **off**.
  - Positive input: An inner product of **2** gives about 0.8 or 0.9. An inner product of **4**, 6 or 100 gives about **one**, so the neuron is **on**.
  - So the sigmoid makes neural processing **nearly digital**, the way brain chemistry does. Without that limit, an activation of a thousand would be like lightning coming out of someone's head.
- The sigmoid also matches perception. **Some things that seem alike are perceived as different, and some things that are very different are perceived as the same.** Very different large negative inputs all come out as off. But two nearly equal inputs on either side of the steep middle come out as one off and one on.

## p13
- Adding the sigmoid one hidden neuron at a time changes the whole calculation after it. Each neuron's raw inner product is replaced by its sigmoid value. Then every later activation is recalculated, and the output probabilities shift.
  - The first hidden neuron, slightly below zero, becomes about 0.4. The second, about 6.6, becomes nearly 1.
  - With the sigmoid on all nine hidden neurons and the same random weights, the network's choice moves from done to Dan. So it is still wrong until it is trained.

## p14
- In the program, **nn.Sigmoid** is added after each hidden linear layer. It means "apply the sigmoid," and it makes that layer nearly digital. The last layer gets no sigmoid, because its outputs go into the loss calculation.
  - The sigmoid can also be replaced by other functions that look somewhat like it, such as **ReLU**. Trying them out shows whether they make recognition better or worse.
  - **AI copies abilities that animals have.** Its most basic ideas come from biologists' discoveries about how brains work. Computer scientists then add their own ideas on top.

## p15
- The full training program runs **2000 updates**. Each update uses all the recordings, with a learning rate of 0.1. The formants are first divided by a thousand, which turns hertz into kilohertz. After every update, the program records the **accuracy**, which is the percent of recordings the network gets right. The word with the highest score counts as the network's answer.
- **The accuracy starts at 20 percent.** With random weights, the network knows nothing. But with **five vowels**, even a random guess is right **one time out of five**, which is 20 percent. That level is called **chance**.
  - With **ten categories**, chance would be **10 percent**, because a random guess would be right one time in ten.
- After a while, the accuracy **jumps up to about 40 percent**, which shows the network is learning something. Then it **levels off**, ending near **45 percent**. Each pass of learning is called an **epoch**, and a problem like this takes thousands of epochs.

## p16
- Training was repeated **ten times** on the same data. Each run started from a **different set of random weights**. A starting set of random numbers is called a **seed**, but the word itself will not be on the exam.
  - Paths: The runs take **different paths**. One run stays at chance for about 500 epochs before jumping up. Another jumps up very early, and another climbs more slowly.
  - End point: **All ten runs end at the same accuracy**, close to 45 percent. Learning by stochastic gradient descent always involves chance along the way, but the end point is the same.
- Children learning language are similar. One child's family might talk mostly about sports, and another child's family might talk mostly about politics. So each child hears very different words and voices. But by about age four, both children speak the same language, because the basic patterns under their different experiences are the same.
- **The network levels off near 40 percent, not 100 percent, because the vowel data overlap so much.** For a point in the middle of the overlap, even a person looking carefully at the data would have to guess. AI is not magic, so a problem that is very hard for people is also hard for machines.
  - The next experiment is to add or remove layers, or change the number of neurons in each layer, to see whether the 40 percent gets better or worse.
