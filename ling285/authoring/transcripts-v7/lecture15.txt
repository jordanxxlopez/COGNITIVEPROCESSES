2|The vowel network takes two formant measurements, **F1** and **F2**, and gives one response for each of five words, **done, dune, dean, Don** and **Dan**, in that order. >> The inputs carry measurements of the sound. >> The outputs carry the network’s response for each possible word. >> Both are drawn as circles, but they do different jobs. || Three **hidden layers** sit between the inputs and the outputs. >> They contain **three, two and four** neurons. >> The whole arrangement runs **2 to 3 to 2 to 4 to 5**. These numbers count the neurons in each layer, not recordings or training trials. >> A hidden neuron receives values from the layer before it and sends its result to the layer after it. || The network is **fully connected**. >> Every neuron in one layer connects to every neuron in the next. >> Each connection has its own **weight**, and all **40** illustrative weights are revealed, values such as **+0.005**, **−0.001**, **+0.6** and **−0.4**. >> A weight sets how the value traveling along that connection contributes to the receiving neuron. A positive weight keeps the sign of the contribution, and a negative weight reverses it. || F1 reaches all three neurons in the first hidden layer, and so does F2. >> Each of those connections has a different weight. >> So each first-layer neuron combines the same two measurements in its own way. || The weights stay fixed for this network. >> Changing a formant changes what travels through the connections. >> Changing a weight changes how strongly a connection contributes. >> A weight describes one connection’s contribution, not the probability of any word.
3|**Forward propagation** carries information from the inputs, through the hidden layers, to the outputs. The example input is **F1 = 320** and **F2 = 2000**. || The top neuron of the first hidden layer computes **w₁ times F1 plus w₂ times F2**. >> Its weights are **+0.005** for F1 and **−0.001** for F2. >> F1 contributes +0.005 times 320, and F2 contributes −0.001 times 2000. >> Adding the positive and negative contributions gives **−0.40**. || Multiplying each input by its weight and adding the products is an **inner product**. >> The other two neurons in that layer use the same inputs with different weights, giving **6.64** and **2.72**. >> A negative result such as −0.40 is still a value the next layer can use. || Each later layer repeats the same operation on the values from the layer before it. >> The second hidden layer gives about **5.50** and **−5.93**. >> The third hidden layer gives about **1.57, −1.95, −1.95** and **−2.88**. >> Values must flow in this order, because each neuron needs the results of the layer before it. || The five final weighted sums are **logits**, scores that are not yet probabilities. >> The logits are **0.622, −1.398, −1.300, −0.478** and **−1.076**. >> **Softmax** turns them into probabilities. It raises e to each logit and divides by the sum of all five of those exponentials, so the five probabilities share one total of 1. >> A negative logit still becomes a positive probability. || **Done** gets the largest probability, about **55.7%**, **Don** gets about 18.5%, **Dan** about 10.2%, **dean** about **8.1%** and **dune** about 7.4%. >> These are the network’s current responses to this input. They do not say which word was actually spoken. >> The hidden activations here are linear, and the weights stay fixed during the forward pass.

6|**Backpropagation** starts by comparing what the network produced with what it should have produced. >> The **computed output** is the current probability distribution, with **done** at **55.7%** and **dean** at only **8.1%**. >> The **desired output** puts a **1** on **dean** and a **0** on the other four words, because dean is the word that was spoken. >> The target names the correct word, so it can disagree with the network’s largest response. || **Cross-entropy loss** measures the mismatch using the probability given to the true word. >> For this example, the loss is the negative log of the probability of dean. >> Giving dean more probability lowers the loss, and giving it less raises it. || The calculation runs **backward**, from the output connections toward the inputs. >> The contribution of the final layer of weights is found first. >> That result is then used to find the contributions of hidden layer 3, then hidden layer 2 and finally hidden layer 1. >> The four steps replace each layer’s weights with updated values, such as **+0.1** becoming **+0.083** and **+0.6** becoming **+0.622**. || A **gradient** describes how the loss changes when one weight changes slightly. >> The update rule subtracts the learning rate, **η**, times the gradient from the old weight. >> A positive gradient lowers the weight, and a negative gradient raises it. Learning does not simply make positive weights bigger or negative weights smaller. || The activations stored during the forward pass stay fixed throughout the backward pass. >> All gradients use the original weights and stored activations, so together they form one simultaneous update. >> A new forward pass is needed to see the updated network’s predictions. >> The input connections use a much smaller learning rate because their inputs are raw formant values in hertz.
7|The question is simple to state. **If we increase this w, will the error go up or down?** >> The desired word is **dean**. >> The network currently gives its largest probability to **done**. >> What matters is how a small change in a weight affects the probability given to the true word. || The **pink-marked** connection runs from the top neuron of the last hidden layer to **done**. >> It is a positive connection, and that hidden neuron has a positive activation of about **1.57**. >> Increasing this weight raises done’s final score. >> Softmax makes the five probabilities share one total, so boosting the wrong word leaves less probability for dean. The loss goes **up**. || The **blue-marked** connection runs from **F1** to the top neuron of the first hidden layer. >> Increasing it raises that neuron’s value, because F1 is positive. >> That change then travels through several positive and negative connections and reaches all five outputs. >> The sign of this first connection alone cannot decide whether the error rises or falls. || The full backward calculation settles it for this network and the dean target. >> The gradient for the input connection is positive too. >> A small increase therefore raises the error, so the update decreases this weight. >> Both marked connections call for decreases here, but the early one needed the combined effect of every downstream path to establish that direction.
8|Why does training **backpropagate**? Comparing the **last** weights with the **first** weights answers the question. || The **last weights, W5**, directly determine the output probabilities. >> The error is very directly determined by them. >> The difference between the computed and desired outputs can be used straight away to find better W5 values. || The **first weights, W2**, are much harder to judge. >> W2 affects the first hidden activations. >> Those activations affect two more layers of activations, along with other weights, before any output appears. >> It is really hard to work out how much W2 is to blame for a mistake made all the way at the end. >> The effect of W2 on the error **includes** the effect of W5, since W5 is downstream of W2. || So improving **W5 is the easy problem**, and improving W2 depends on it. >> Solving small problems first and reusing their answers for bigger problems that depend on them is **dynamic programming**. >> **Backpropagation is Bellman–Viterbi dynamic programming.** >> It computes the effects near the output first and reuses them for each earlier layer, instead of redoing the whole downstream calculation for every early weight. || **Backpropagation = SGD + dynamic programming.** >> **SGD**, stochastic gradient descent, is the rule that adjusts the weights. >> Backpropagation supplies the gradients that rule needs, and dynamic programming makes computing them efficient.
9|Training uses two **training matrices**, one of inputs and one of correct answers. || The **Formant_Inputs** matrix is **110 × 2**. >> Each of its 110 rows holds **F1** and **F2** for one recording, in hertz. >> The two columns are the two sound measurements, and the network takes one row at a time as one example. || The **TrueVowel_Outputs** matrix is **110 × 5**. >> Its columns are **done, dune, dean, Don** and **Dan**. >> Each row puts a **1** in the correct word’s column and **0** in the other four. >> This is a **one-hot** target, since exactly one position is on. || The illustrative rows pair formants with words. >> **500, 1500** goes with **done**. >> **350, 1000** goes with **dune**. >> **320, 2000** goes with **dean**, the same example used in the network. >> **700, 1100** goes with **Don**, and **800, 1700** goes with **Dan**. || The rows of the two matrices must stay matched. >> The third input row, 320 and 2000, pairs with the third target row, dean. >> Moving an input row without moving its target would attach the measurements to the wrong answer. >> The five shown rows illustrate the layout of the full 110 examples. || The network’s output is separate from the target matrix. >> Before backpropagation, the network still favors **done** at 55.7% for the dean example. >> The target keeps the correct label even when the network is wrong, and training compares the two.
10|One full-batch training step can be written in a short **PyTorch** program. || The data are loaded first. >> **X = torch.load("Formant_Inputs.pt").float()** loads the 110 × 2 formant matrix. >> **Y = torch.load("TrueVowel_Outputs.pt").float()** loads the 110 × 5 one-hot targets. >> **.float()** makes both into floating-point tensors. The program assumes these files already exist. || The network is declared with **nn.Sequential**. >> **nn.Linear(2, 3)**, **nn.Linear(3, 2)**, **nn.Linear(2, 4)** and **nn.Linear(4, 5)** keep the **2 to 3 to 2 to 4 to 5** arrangement. >> No activation function is declared between the layers. || The training step has five lines. >> **sgd = torch.optim.SGD(net.parameters(), lr=0.1)** sets up stochastic gradient descent with a **learning rate of 0.1**. >> **sgd.zero_grad()** clears any gradients left from before. >> **loss = nn.CrossEntropyLoss()(net(X), Y)** runs the forward pass and compares the scores with Y. CrossEntropyLoss handles the softmax-related step itself, so the last layer supplies logits. >> **loss.backward()** computes the gradient of the loss for every parameter. >> **sgd.step()** changes the parameters using those gradients. || These steps are separate. >> Computing a gradient does not change a weight by itself, and clearing gradients does not erase learned weights. >> All **110 rows** contribute to this one step, and there is no repeated training loop. >> The code uses PyTorch’s default starting weights and biases, so it shares the drawing’s layer sizes but not its exact numbers.
11|The **sigmoid activation function** is **σ(z) = 1 / (1 + exp(−z))**. It takes an inner product, z, and returns a value between 0 and 1. || The sigmoid squashes large values toward its two limits. >> If the inner product is a **large positive** number, the sigmoid is near **1**. >> If it is a **large negative** number, the sigmoid is basically **0**. >> For an inner product of **−4**, **σ(−4) = 0.0180**, and for **4**, **σ(4) = 0.9820**. || The curve is S-shaped. >> The horizontal axis is the **linear activation**, the weighted sum, and the vertical axis is the **sigmoid activation**. >> The curve is steep in the middle and flat near both ends. >> Near the ends, further changes in the input make only small changes in the output. || In the formula, a large positive z makes exp(−z) tiny, so the output approaches 1. >> A large negative z makes exp(−z) huge, so the output approaches 0. || **Lord Edgar Adrian**, who won the **Nobel Prize in Physiology or Medicine in 1932**, supplies biological context. >> **Neurons are nearly digital**, roughly on or off. >> Adrian’s work concerned firing rates, and the sigmoid is a model of a graded activation, not a claim that real neurons have only two states. || **Animal perception** reflects this kind of response. >> Some things that seem alike are perceived as different, and some things that are very different are perceived as the same. >> Inputs on opposite sides of the steep middle can give very different outputs, while inputs near a flat end give nearly the same output.
12|Sigmoid is applied to the network **one neuron at a time**. The inputs stay **F1 = 320** and **F2 = 2000**, and the weights stay the same. >> **Purple** neurons are still linear. >> **Green** neurons pass their inner product through sigmoid. >> The nine hidden neurons are switched in layer order, three, then two, then four. || The first switch changes the first hidden neuron from **−0.400** to about **0.401**. >> That new output changes what the next layer receives. >> Every downstream value is therefore **recalculated**. >> This builds a sigmoid network step by step. It is not the same as wrapping sigmoid around the numbers stored from the all-linear network. || After all three first-layer neurons use sigmoid, their outputs are about **0.401, 0.999** and **0.938**. >> The second layer, recalculated and then passed through sigmoid, gives about **0.713** and **0.223**. >> The third layer finishes at about **0.599, 0.609, 0.609** and **0.481**. || The outputs still use **softmax**. >> With every hidden neuron using sigmoid, **Dan** has the largest probability, about **32.0%**. >> **Dean** rises to about **23.0%**, **dune** is about 20.2%, **done** falls to about 16.2% and **Don** is about 8.5%. >> The inputs and weights never changed, yet the output pattern did. || This sequence changes the activation rule, not the weights. >> Dean’s probability is higher than in the all-linear network but still not the largest. >> Adding sigmoid can change which word the network favors without showing that the network has learned the right answer.
13|The PyTorch program is the same as before, with **sigmoid** added to the hidden layers. >> It still loads **X**, the 110 × 2 formant matrix, and **Y**, the 110 × 5 targets. >> **nn.Sigmoid()** now follows **nn.Linear(2, 3)**, **nn.Linear(3, 2)** and **nn.Linear(2, 4)**. || The layer sizes still run **2 to 3 to 2 to 4 to 5**. >> Sigmoid changes each value but not how many values a layer produces. >> Three values stay three after sigmoid, so the next **nn.Linear(3, 2)** still receives the right number of inputs. >> The same holds for the two-value and four-value hidden layers. || The last layer, **nn.Linear(4, 5)**, has no sigmoid after it. >> Its five scores are logits for **CrossEntropyLoss**, which handles the softmax-related calculation. >> Hidden sigmoid activations and the final word probabilities do different jobs. A hidden neuron is not one of the five words. || The training lines are unchanged. >> **zero_grad** clears old gradients, the forward pass and loss compare predictions with the targets, **backward** computes gradients and **step** applies the update. >> The learning rate is still **0.1**, and all 110 recordings contribute to the single step. || The drawn network uses the original illustrative weights with no biases, where Dan gets **32.0%** and dean **23.0%**. >> The short program starts with PyTorch’s own default weights and biases. >> It matches the drawing’s structure, but reproducing its exact probabilities would also need the same weights and bias settings.
