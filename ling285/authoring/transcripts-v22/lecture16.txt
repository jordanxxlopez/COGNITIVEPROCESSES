2|This **neural network** simulates a very simple piece of human perception. It takes the two formants, F1 and F2, of an isolated vowel and decides which vowel it is, choosing among done, dune, dean, Don and Dan. Two input neurons take in the formants, three hidden layers process them, and five output neurons give the decision. >> Every neuron connects to every neuron in the next layer, so the network is fully connected. || **The weights are the network's knowledge.** Each one is a positive or negative number, so a positive weight pushes the next neuron up and a negative one pushes it down, and the bigger the weight, the stronger the push. >> At first the weights are random, so the network does not know anything and its decisions are stupid. >> The right answer is given as a probability distribution, which for a recording of dean puts all of the probability on dean, meaning the network should be completely sure it was dean. >> That target is usually very different from what the stupid network produces at first, and the network learns by correcting the mistake between the two.
3|**Forward propagation** carries one input through the network to a decision. The example vowel has a low F1 and a high F2, and it is one person's /i/. **Every step is an inner product**, which means multiplying each incoming number by its weight and adding the results. >> For the top neuron of the first hidden layer, the F1 part adds a little and the F2 part takes away a little more, so its activation lands just below zero. >> Because those two weights point in opposite directions, a higher F1 pushes this neuron up while a higher F2 pushes it down. >> The other neurons do the same thing with their own weights, layer by layer, until the network reaches a decision. || The last numbers are turned into a **probability distribution**, a set of numbers that add up to one, by an operation called **softmax**. Softmax makes every score positive and divides each one by the total, so a bigger score always gives a bigger probability, and raising one vowel's score lowers the probabilities of the others. >> With these weights, done gets the highest probability, a little over half, so the network decides done. >> But the correct answer is dean, so the network's knowledge is wrong and it has to change its weights.

5|The vowel data from the class's own lab is plotted with F1 along one axis and F2 along the other, and **each vowel forms a cloud of points**, since the same vowel comes out a little differently every time. Some of the patterns are clear. The vowel /i/, as in dean, sits apart with a high F2 and a low F1, just as the theory predicts, and the vowel of Dan spreads toward high values of F1. || **But there is a lot of overlap.** The vowels of dune, Don and done crowd into the same region, so a new speaker whose formants land there could be saying any of the three. Some points are probably errors, but real data always has errors, so they stay in because that is what real life is like. >> If every vowel sat in its own separate spot, recognizing vowels would be easy. Instead a network has to see the data many times to learn what really separates the vowels, and no setting of the weights can separate recordings that land on top of each other. || This overlap was discovered when **Peterson and Barney** measured the vowels of many speakers from spectrograms and found an enormous overlap between them. >> For decades people tried to write programs to solve it, including trying to normalize away the differences between speakers, but none of it worked. >> What finally worked was a neural network trained with backpropagation. >> Everyone predicted that a static problem like two formants from one moment would be easy and that moving speech would be very hard, but everyone turned out to be wrong, since large language models deal with very dynamic information and work much better.

7|**Backpropagation** is the algorithm that changes all the weights so that the network makes better decisions, and it is made of two algorithms working together. **Stochastic gradient descent** improves each weight gradually, the same way SGD improved an estimate of an average, and it has the same learning rate. **Dynamic programming** decides the order, so the last weights get improved first and the earlier ones after. || Comparing two outputs gives the error. The **computed output** is what the network produced, which puts most of the probability on done and only a small amount on dean. The **desired output** is the right answer, with a one for dean and zeros everywhere else. >> The difference between them is the **error**, also called the **loss**, and more probability on dean means less error. >> The error says exactly how each output should move, so the probability of done should go down, the probability of dean should go up, and the others should go down. || **The weights are changed from the end backward.** First come the connections into the outputs, then the connections into the third hidden layer, then the second and then the first, while the activations from the forward pass stay fixed and are reused. >> The weight from a positive neuron into dean gets bigger, the weights from the negative neurons into dean get smaller, and the weight from that positive neuron into done gets smaller. >> The weights leaving the formants barely move, because they use a much smaller step to match the large values in hertz.
8|The same thing has to be asked about every weight, which is whether raising it would make the error go up or down. **The weights at the end of the network are much easier to change than the weights at the beginning.** || **The end weights are easy because they directly change the decision.** Done's large probability comes partly from multiplying a positive end weight by a positive activation, along with the other products feeding done. If that end weight went up, done's probability would go up, which is the exact opposite of what is needed. >> So that weight should go down, since any change to an end weight is directly, automatically and immediately reflected in the probabilities. || **The beginning weights are hard because their effect is buried under many layers.** Changing a weight in the first layer changes that layer's activations, which change the next layer's activations, which change the third layer, which finally change the probabilities. >> Just by looking at an early weight, there is no way to tell which direction it should move, but backpropagation still figures it out. >> This is the same trap as the greedy choice in dynamic programming, where picking the cheaper of two next steps without looking ahead can lead to the wrong answer.
9|**Dynamic programming says that if problems can be ordered by difficulty, the easiest should be solved first, then the next, and so on up to the hardest.** Backpropagation follows exactly that order. The last weights are the easiest problem, because the output probabilities and the error are directly determined by them, so the error can be used right away. >> The first weights are the hardest problem, because they affect their own activations, which affect another two layers of activations along with other weights, and their effect on the error already includes the effect of the later weights. || **Solving the end first makes the rest easier.** Changing the last weights first teaches something that makes the problem of the next layer easier, and that makes the layer after it easy too, all the way back to the start. >> So backpropagation is Bellman and Viterbi's dynamic programming combined with SGD, with SGD improving each weight a little at a time and dynamic programming saying to go from the end backward. || **Backpropagation is how every modern AI system learns**, because today's largest systems run it on enormous numbers of weights, one small step at a time. >> These ideas come from physics and are closely tied to the dynamical systems behind acoustics and masses and springs.
10|To train the network, it gets **two matrices**, which are tables of numbers with one row for each student recording. The input matrix holds each recording's F1 and F2, and the target matrix holds a one-hot answer for each recording. >> Each row in one table goes with the same row in the other, so a row of formants from a recording of dean is paired with a target that says dean. || **Learning picks rows one at a time.** It takes one row, uses its weights to calculate a decision for that row's formants, and changes its weights if that decision differs from the desired answer, starting from the last weights. Then it picks another row and does the same thing again. >> **If the network already gets a row right, there is no error, so there is nothing to learn from that row.** That can be a serious problem, since a network can get rows right by accident over and over and stop learning before it learns the real pattern. || **Children learning English go through the same problem**, as Carol Chomsky discovered. At first very young children say go and went correctly, because they are just memorizing what they hear. >> Then they notice the real pattern, that most English verbs add ed for the past, as in jump and jumped, and they start saying goed. >> Only later do they learn that some verbs are exceptions, and then they get both the regular and the exceptional verbs right. Neural networks can also just memorize weights that give the right answers without learning the pattern, and that is what makes learning so difficult.
11|A short **Python program** builds and trains the network, and it never has to be written from scratch, since brackets and dots do not matter. **The import lines bring in libraries**, which are collections of programs that other people wrote for one job and that can be used without knowing how they work inside. >> Before libraries like PyTorch existed, everyone doing AI had to write their own backpropagation code. >> The import lines bring into Python everything needed for inner products, backpropagation and related work, which is why the whole training program fits on one page. || **The word Sequential means a neural network that is a sequence of layers.** All the networks built so far are a sequence of layers, while a large language model is a network that is not just a sequence of layers. **Each Linear line is one processing layer**, a layer that has weights and does inner products with the incoming information. >> The first linear line says it receives information from two neurons and has three neurons of its own, and the following lines go from three to two, from two to four, and from four to five. >> The network has five layers but only four lines, because the input layer does no processing. || **The last lines are the only lines PyTorch needs for learning.** SGD is stochastic gradient descent, and lr is the learning rate, which sets the size of each step. **A bigger learning rate learns a lot faster but is less accurate, while a smaller one is more accurate but learns much more slowly.** >> The loss is the mistake, so the network calculates its mistakes and learns from them, and backward is backpropagation. >> Nothing changes until step is called, which is when the weights actually change.
12|**Neural networks do not come out of nowhere**, because their basic features come from discoveries about animal brains. Scientists found that brains have neurons and that each neuron collects information from many other neurons, which is the inner product. **Adrian** discovered that **neurons are nearly digital**, meaning that they either fire or they do not fire. >> A real neuron's activation is off or on rather than any number, while the neurons of the vowel network can take any value at all. || **The sigmoid** is an activation function that was added to networks to copy Adrian's discovery. It takes a neuron's linear activation, its inner product, and turns it into a number between zero and one. >> If the inner product is large and positive the sigmoid is near one, and if it is large and negative the sigmoid is basically zero, so a fairly negative inner product and a hugely negative one both come out almost at zero. >> In this way the sigmoid digitizes neural processing, copying the brain chemistry that keeps real neurons close to off or on. || Near zero the curve is steep, so a small change in the inner product makes a big change in the output, while far from zero it is flat, so even big changes barely matter. **Animal perception reflects this S shape too**, since some things that seem alike are perceived as different and some things that are very different are perceived as the same. >> So AI is duplicating the abilities of animals. People will say that AI has nothing to do with human cognition, but that is false, because a big reason it works is that it copies our own abilities.
13|The sigmoid is added **one hidden neuron at a time**, while the input and every weight stay the same. The first neuron to switch has an inner product just below zero, on the steep middle of the curve, so it comes out just under one half and now sends a positive number instead of a negative one. >> After each switch, everything downstream is recalculated, because later neurons depend on earlier ones. >> So the sigmoid network cannot be made by running the old linear numbers through the sigmoid one at a time. || With every hidden neuron on sigmoid, every hidden activation sits between zero and one, and **Dan becomes the top answer**, while dean rises to second place and done drops well behind. >> Only the activation rule changed and no weight moved, so this is not learning. >> The decision changed completely, but dean is still not the top answer.
14|The command **nn.Sigmoid** is added after each of the first three linear layers, and it means apply the sigmoid, which makes the neurons digital. The layer sizes stay exactly the same, because the sigmoid changes the values but not how many there are. >> The last linear layer has no sigmoid, because its five scores go to the loss, which turns them into probabilities. >> The sigmoid squeezes each hidden neuron on its own, while the softmax turns all five final scores together into a decision that adds up to one. >> The training lines and the learning rate stay the same as before.
15|Training runs **thousands of times**, which is far more than the few dozen steps needed to average a list of numbers. Each full pass of learning is called an **epoch**, and the run starts from random weights. >> After every epoch, accuracy is measured without training, with the vowel that gets the largest score counted as the network's answer. Accuracy is the percentage of recordings it gets right, and these are the same recordings it learns from. || **Accuracy starts at twenty percent because that is the level of chance.** At the start the weights are random, so the network knows nothing, but it still is not at zero, because with five vowels a random guess is right one time in five. >> The word chance means how often someone would be right just by guessing randomly, so with five possible answers chance is twenty percent. || **After a couple hundred epochs, accuracy jumps up well above chance**, so the network is learning something. It dips back toward chance for a moment, recovers, and then levels off a little below half after a few hundred epochs.
16|The same training is run **ten times**, each time starting from different random weights, while everything else stays identical. All ten runs start near chance, some leave chance quickly and others stay flat longer, and several briefly drop back toward chance. After a few hundred epochs they come together, and **all ten finish at the same accuracy, a little below half**. >> So **different starting weights change the path but not the destination**, because the learning process is so similar each time. || **The network levels off well below perfect accuracy because the data overlap so much.** Its final accuracy is clearly better than chance, so the network has learned something, but it is still pretty low, because AI is not magic. >> If a person had to name the vowel for formants landing where several vowels overlap, they would have to squint hard and might still guess wrong. If the decision is very hard for humans, it is not surprising that it is hard for machines. >> The limit comes from two formants not being enough to separate dune, Don and done, not from unlucky starting weights, so trying more starting points would not help. >> In lab, different designs can be tested by adding or removing layers, changing the number of neurons, or swapping in the sigmoid or other functions, to discover whether each change improves that accuracy or makes it worse.
