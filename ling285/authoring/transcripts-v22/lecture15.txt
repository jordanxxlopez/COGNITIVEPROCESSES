2|**A neural network is a numerical processing machine**, which means it takes in numbers, processes them and makes a decision. This one is a very simple speech recognizer that takes the formants measured from vowels in lab and decides which vowel was spoken. The two input neurons just take information from the environment, one taking F1 and the other taking F2, and the five output neurons stand for done, dune, dean, Don and Dan. >> Between them are three hidden layers, which are called hidden because they are neither the input nor the output. || **The weights are the network's knowledge.** Every connection between two neurons has a weight, a positive or negative number, and everything the network knows about vowels is stored in these numbers. >> The network is fully connected, so every neuron sends a connection to every neuron in the next layer. >> A positive weight pushes the next neuron up and a negative weight pushes it down, and the bigger the weight, the stronger the push. >> The weights leaving the formants are tiny, because formants are big numbers in the hundreds and thousands of hertz, so tiny weights are enough to turn them into modest values for the rest of the network. || **How many layers and neurons a network should have is not known in advance.** With no hidden layers at all, the network would most likely keep making mistakes. More numbers give it more freedom, so as those numbers improve, the network can capture something as hard as recognizing a vowel from just two numbers. >> In practice, people try the simplest design first, see how it performs, and then add more.
3|**Forward propagation** is how the network makes a decision, by sending the input forward through the layers one at a time. The example input is a vowel with a low F1 and a high F2, there are no extra constants added in, and each hidden neuron passes its sum straight on. **Each neuron computes an inner product**, multiplying each incoming number by the weight on that connection and adding the results. >> For the top neuron of the first hidden layer, F1 is multiplied by a small positive weight and F2 by a small negative weight, so the F1 part adds a little, the F2 part takes away a bit more, and the neuron's activation lands just below zero. >> None of these calculations ever have to be done by hand, because what matters is understanding what is happening. || **The same thing repeats at every layer.** The activations of one layer become the inputs to the next, which does more inner products with its own weights, until the network reaches the output. >> Each layer has to wait for the one before it, so a change at the input ripples all the way through. || **Knowledge has been reduced to positive and negative numbers, and making a decision uses nothing but multiplying and adding**, which is arithmetic from second grade. The word **inference** means figuring out a decision, and almost all of its work is done by simple numbers that hold the knowledge together with addition and multiplication. >> This did not come out of nowhere, since the brain's own chemistry also performs operations like addition and multiplication. || After the last layer, the final numbers are turned into a **probability distribution**, which is a set of numbers that add up to one, and those numbers are the network's decision. The operation that does this is called **softmax**, and it just converts numbers into probabilities, so a bigger score always ends up as a bigger probability. >> Probabilities go from zero to one and percentages go from zero to a hundred, but they are the same idea, and each number says how sure the network is about one vowel. >> For the example vowel, the network gives done a little over half of the probability, much more than any other vowel, so the network decides it heard done.

6|**This network is stupid, and in fact all neural networks start out stupid**, because they start with random weights, which means they know nothing. This one decided done, but the formants were actually for /i/, as in dean. **A network becomes smarter only by being told the right answer**, which is given as the **desired output**. >> The desired output for dean puts no chance on done, dune, Don or Dan and all of the chance on dean. >> A target written with zeros everywhere and a single one is called a **one-hot encoding**. >> In practice, the network gets a table of data, where each row says that when a person produced these two formants, the vowel was a particular one. || The output the network actually produced is called the **computed output**, and the gap between it and the desired output is the **error**. Here the network gave dean only a small chance when it should have given dean all of it, so the error is large. **Backpropagation** is the algorithm that changes all the weights so that the network becomes a little smarter. >> The goal is to pump up the probability of the right answer toward one and push the wrong ones down toward zero. >> Learning is gradual, just as in stochastic gradient descent, because the network sees one example, changes its weights a little, sees another and changes them a little more. || The new weights are worked out **from the output backward**. First the connections into the outputs change, then the ones into the third hidden layer, then the second and then the first, while the activations from the forward pass stay as they were. >> The weight from a positive neuron into dean gets bigger, which adds more to dean. >> The weight from that same neuron into done gets smaller, which takes away from done. >> The weights leaving the formants barely change, because they use a much smaller step size to match the large values in hertz.
7|For any weight, the same thing always has to be asked, which is **whether the error will go up or down if this weight goes up**. Comparing two marked weights makes the difference clear. || **The weight from the last hidden layer to done is an easy problem.** Done's large probability comes from an inner product that includes this positive weight times a positive activation. If the weight went up, that contribution would grow, done's probability would go up, and the network would get more wrong, since done should have no probability at all. >> So the weight should go down, because a smaller weight shrinks that contribution and pulls done's probability down. >> There is only one inner product between this weight and the probability, so the decision is crystal clear. || **The weight from F1 to the first hidden layer is a hard problem.** Changing it changes the activation of its neuron in the first layer, which changes the second layer, which changes the third layer, which finally changes the probabilities. >> At every step, that change mixes with many other weights and activations, some pushing one way and some the other. >> So its effect on the decision is mediated by all of the calculations in between, and just by looking there is no way to tell whether it should go up or down, although backpropagation still works it out.
8|**Why the weights are changed from the end backward is guaranteed to be on the exam.** The answer comes from comparing the last weights, labeled **W5**, with the first weights, labeled **W2**. **Improving W5 is easy**, because the output probabilities are directly determined by the last weights, and so the error is very directly determined by them too, which means the error can be used right away to decide how to change them. || **Improving W2 is a much harder problem.** W2 affects its own activations, which then affect another two layers of activations along with many other weights, so it is really hard to figure out how much blame W2 deserves for mistakes made all the way at the end. >> Moreover, the effect of W2 on the errors includes the effect of W5, since W5 is downstream of W2, so any change in W2 has to pass through W5 to reach the output. >> A strong exam answer explains that changing an early weight's influence on the probabilities is a much more involved and mediated set of calculations, while changing a last weight changes the probabilities right away. So the last weights pose a simple, trivial problem, while the early weights pose a complex, big problem that already includes the effect of the later ones. || **When a problem contains smaller and smaller problems inside it, the algorithm to use is dynamic programming.** Dynamic programming solves the easiest problem first and then uses its answer to solve the next bigger one, and it comes from Bellman and Viterbi. >> So **backpropagation is SGD plus dynamic programming**. SGD changes each weight gradually, a little at a time, and dynamic programming gives backpropagation its back, since it improves the last weights first and works its way toward the first.
9|To train the network, it has to be told **the desired output for every input**, and that information is given as **two matrices**, which are just tables of numbers. Both come from the class's own lab data, with one row for each recording. >> The input matrix has two columns, because the network takes two numbers in, F1 and F2. >> The target matrix has five columns, because the network decides among five vowels, and each row is a one-hot answer with a one for the true vowel. || **The rows of the two tables must line up**, because row by row they describe the same recording. If the first row of formants comes from a recording of done, the first row of the target has to say done. >> If one table were reordered and not the other, the network would learn from the wrong answers. >> The target itself never changes, because training compares the network's computed output with it and changes only the weights.
10|A short **Python program** trains this network, and it never has to be written from scratch, because brackets and punctuation do not matter. What matters is what each line does. **The import lines bring in a library**, which is code that someone else already wrote, so a network can be described in just a few lines. >> The line import torch means use the PyTorch library, and the second import brings in its neural network tools, so these lines bring into Python everything needed for inner products and backpropagation. >> The load lines read the two saved tables from files, in the same way that a file is loaded when it is double-clicked. || **The word Sequential means that the network is a sequence of layers**, one layer after another, which describes every network built so far. **The word Linear means a layer that does inner products** by multiplying and adding. >> The first linear layer takes two inputs and produces three outputs, the next takes three and produces two, the next takes two and produces four, and the last takes four and produces five. >> The network has five layers but only four linear lines, because the input layer does no processing and just receives numbers. || The last lines are the only lines PyTorch needs for learning. **SGD** is stochastic gradient descent with a learning rate that sets the size of each step, the **loss** is the mistake, the gap between the computed and desired outputs, **backward** is backpropagation, and **step** actually changes the weights. >> The program takes one step using all of the rows together, and it starts from PyTorch's own default weights, so it would not reproduce the hand-picked numbers in the diagram.
11|**Neural networks did not come out of nowhere**, because their most basic features come from discoveries about animal brains. Neuroscientists discovered that there are neurons, so artificial networks have neurons, and they discovered that each neuron collects information from many other neurons, which is exactly what the inner product does. || **Adrian** discovered that **neurons are nearly digital**, meaning that they either fire or they do not fire. A real neuron's activation is basically off or on, while the vowel network's neurons can take any value at all, with no limit. >> The **sigmoid** is an activation function that was added to copy Adrian's discovery, and it takes the inner product and turns it into a number between zero and one. >> If the inner product is large and positive, the sigmoid is near one, and if it is large and negative, the sigmoid is basically zero, so only inner products close to zero land in between. >> In this way the sigmoid digitizes neural processing, copying the brain chemistry that keeps real neurons close to off or on. || **Animal perception reflects this S shape too**, since some things that seem alike are perceived as different and some things that are very different are perceived as the same. In the steep middle of the curve two close inputs come out far apart, and out on the flat ends two very different inputs come out nearly the same. >> So AI is duplicating the abilities of animals. People often say that AI has nothing to do with human cognition, but that is false, because a big reason it works is that it copies our own abilities using math as simple as multiplying and adding.
12|The sigmoid can be added to the vowel network **one hidden neuron at a time**, keeping the same input and every weight the same. Each hidden neuron switches from linear to sigmoid in layer order, and the outputs still go through softmax, so they stay probabilities that add up to one. >> The first neuron to switch has an inner product just below zero, on the steep middle of the curve, so the sigmoid turns it into a value just under one half. The neuron now sends a positive number where it used to send a negative one. || **After each switch, everything that comes after it is recalculated**, because later neurons get their inputs from earlier ones. So the old linear numbers cannot simply be run through the sigmoid one at a time, since each new value has to come from the updated layer before it. || As the neurons switch, **the network's answer moves**. At first it decides done with a clear majority, then done's lead shrinks until done and Don are nearly tied, then Don takes the lead, and then Dan does. >> With every hidden neuron on sigmoid, Dan is on top, dean has risen to second place, and done has dropped well behind. >> Only the activation rule changed and no weight moved, so this is not learning, and even though the decision changed completely, dean still is not the top answer.
13|The program becomes a sigmoid network by adding **nn.Sigmoid** after each hidden layer, and nn.Sigmoid means apply the sigmoid, which makes the neurons digital. The sigmoid changes the values but not how many there are, so a layer that produces three numbers still produces three, and the network keeps exactly the same shape. >> The last linear layer has no sigmoid after it, because its five outputs go to the loss, which turns them into probabilities. >> The sigmoid squeezes each hidden neuron on its own toward off or on, while the softmax turns all five final scores together into a decision that adds up to one. >> In lab, the sigmoid can also be swapped for other functions, such as one called ReLU, to discover whether they make vowel recognition better or worse.
