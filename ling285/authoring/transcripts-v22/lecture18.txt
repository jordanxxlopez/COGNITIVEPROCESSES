2|**A single neuron takes a list of inputs and gives back one weighted sum.** It multiplies each input by its weight and adds the products, so an inner product turns the input vector into one response. >> A neural network combines many such operations through its layers and returns a decision vector, with a response for each possible answer. || **A large language model takes a sequence of vectors and predicts what comes next.** Each layer transforms the representations produced by the preceding layer, until the output gives the probabilities of the possible next tokens. >> A likely continuation receives a stronger predicted response, so the final vector expresses a decision about the sequence. || **An agentic system connects whole language models into a graph.** Different models develop the outline, write the draft, criticize it, revise it and produce the final answer. >> The critic and reviser form a loop, allowing a changed draft to be evaluated again. The agents communicate in English and can work in other human languages and computer languages. || **Inference uses learned weights to process an input, while learning changes those weights.** Inner products supply the weighted combinations used in inference, and stochastic gradient descent adjusts the weights using the backward calculation organized through dynamic programming.
3|**Predicting the next word requires useful representations of the sequence, so a language model develops those representations through many layers.** Each layer receives the vectors produced by the layer before it and changes them into information that can help with the prediction. >> A representation is the information about an input item carried in its vector. || **Several heads work in parallel inside each layer.** Each acts as a different expert, contributing information that the layer combines with the contributions of the other heads. The result is a new set of representations that brings those contributions together. >> The experts here are processing components within the model. A head contributes to one layer, while an agentic graph connects whole language models to work on a task. || **The following layer repeats the process using the representations it receives.** Its heads again work in parallel, and their contributions are combined before the vectors continue onward. >> The heads provide different contributions within a stage, while the layers develop the representations through successive stages. The final prediction depends on both kinds of organization.
4|**A dynamical system repeatedly turns its current state into a new state by applying a rule.** An oscillator’s state contains position and velocity, and the two quantities take turns changing. Position is updated using the old velocity, and velocity is then updated using the new position. >> Feeding the updated state back through the rule produces an oscillating trajectory from the starting state. || **Jordan’s recurrent network uses feedback to carry recent output into the next moment.** Plan and state units feed the hidden layer, and the output is copied back into the state units. Their self-connections keep a fading trace of the earlier state. >> The same weights are reused as time advances, so each new output depends on the plan and on the history carried by the state units. || **An LLM develops its vectors through successive layers, so depth plays the role of time in this comparison.** One layer transforms the vectors, and the next layer uses those transformed vectors as its own input. >> Following a single value through the layers gives a changing trajectory. The trajectory develops step by step, but its curve is not the oscillator’s cosine. || **The oscillator and Jordan network reuse the same rule at each time step, while the LLM has a separate set of weights at each layer.** The shared principle is that each new state depends on the state produced before it, with network depth supplying the sequence of transformations for the LLM. || A changing quantity can follow a different path from another quantity over the same period. The stock-return sequences rise and fall along separate paths. Each path records a sequence of values, just as following a value through successive transformations gives its trajectory.
5|**A language model takes a sequence of vectors and predicts the next item.** A vector is a list of numbers, so the same input format can represent different kinds of material. >> The prediction task stays the same even when the sequence comes from a different source. || **The vectors can represent words in a sentence.** In the cat that the dog chased ran up the old tree and sat on the blank, the task is to predict the missing next word. >> The prediction uses the sentence so far, including the fact that the cat is the one that sat. || **The vectors can represent pieces of sound or a picture.** A spectrogram is divided into consecutive frames, and the model predicts the next frame of sound. A picture is divided into patches read row by row, and the task is to predict the missing bottom-right patch. >> The input represents an unfolding sound in one case and an ordered set of picture pieces in the other. || **The vectors can also represent amino acids in a protein.** The insulin B-chain example gives a sequence of amino acids and leaves the following residue to be predicted. >> The amino acid at the next position is Y. || **Words, sounds, picture patches and amino acids reach the model as sequences of vectors.** The model uses the preceding vectors to predict the following one, even though the original materials are different.
6|English allows only **certain sequences of sounds** in its words, and knowing which sequences are allowed is called **phonotactic knowledge**. **A simple syllable in English can have a consonant, then a vowel, then a consonant**, as in Don, mat, sit, cup, dog and fish. >> The pattern is about sounds, not letters, so the silent e in shave, kite and rope does not count, and two letters can spell one consonant sound, as in ship, chin and bath. || Syllables can also have **clusters**, which are groups of consonants together. A cluster before the vowel is called an **onset**, as in split, flat and black, and a cluster after the vowel is called a **coda**, as in desk, help and lamp. >> Each real word has an impossible twin marked with a star, and many twins use the same letters in the other order, such as flat and lfat, help and hepl, and lamp and lapm, so the order of the sounds matters. >> **The order of consonants mirrors itself around the vowel.** In flat the l sits right next to the vowel with the f farther out, and in help the l again sits next to the vowel, now on the other side, with the p farther out. Each impossible twin puts the wrong consonant against the vowel. || **A long word is a chain of syllables**, such as ba-na-na, At-lan-tic and ath-lete. The sounds t and l are fine across a syllable break, but tl cannot start a syllable, which is why Atlantic is a word but tlantic is impossible. >> The sound ng can end a syllable, as in ring, but it can never start one. >> So whether a sequence of sounds is allowed depends on where the syllable breaks fall.
7|**Phonotactic knowledge can be revealed through GPT learning.** Each item is the start of an English word, and the task is to guess the next letter. People agree on their guesses quickly, and how much they agree changes from item to item. || **Almost anything can follow once a vowel has come.** After ra, likely letters include t, n, r and l, and many others are possible too, because the onset is over once the vowel arrives. >> **At the start of a word, the choices narrow sharply** to exactly what an English onset allows. After sp the next letter is l, r or a vowel and never n, and after k it is a vowel or n, as in knee. >> After b and f the next letter is r, l or a vowel, after sh it is a vowel or r, as in shrimp, and after skr or after m at the start of a word only a vowel can come. >> After bram, the letter b is almost forced, as in bramble, though a new syllable could also start there. || **Guessing the next letter is the same as predicting the sixteenth item**, which is the same game of predicting the next token that a large language model plays. A GPT trained only on this game learns English sounds and spelling, because its predictions can only get good by matching the patterns of English syllables. >> Its prediction is a probability distribution over the next letter, and the shape of that distribution carries the knowledge. >> After ra the distribution is broad, spread over many letters, while after skr it is sharply peaked on a few vowels, because English allows nothing else there. >> So the more the letters so far restrict what can come next, the more the probability piles onto a few letters.
