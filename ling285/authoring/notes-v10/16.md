## p2
- **This network copies a simple piece of human perception, deciding which vowel it heard.** The network takes the **two formants**, F1 and F2, of a single vowel. It decides which of five words it heard, **done, dune, dean, Don or Dan**.
  - The network has 2 input neurons, hidden layers of 3, 2 and 4 neurons, and 5 output neurons. Every neuron connects to every neuron in the next layer.
- **The weights are the network's knowledge, and the network learns by correcting mistakes.** Each weight is a positive or negative number. The network is told the right answer for each recording as a probability distribution. For a speaker's /i/, the right answer is **0, 0, 1, 0, 0**, which means a 100 percent chance that the word was dean.
  - At first **the weights are random**, so the network knows nothing, and its output is usually very different from the right answer.
  - The difference between the output and the right answer is a **mistake**. The network learns by correcting its mistakes.

## p3
- **Forward propagation carries the input through the network, one layer at a time.** Take **F1 of 320 and F2 of 2000**, which is one speaker's /i/.
  - Each neuron in the first hidden layer computes an **inner product**. It multiplies each formant by its weight and adds the results.
  - Those activations go into the next layer, which does its own inner products. This continues until the output gives one probability for each word.
- **With random weights, the network is wrong.** The network gives more than half of its probability to **done**, so it decides it heard done. The right answer is dean.

## p4
- **The last weights are the easiest to change, because they connect directly to the decision.** The output probabilities are the network's decision, and the last weights are the weights used in the final inner products.
  - For example, the probability of done comes partly from a weight of 0.1 times an activation of about 1.57.
  - The network said done, but the answer was dean, so the probability of done is **too high**.
  - Raising that 0.1 to 0.5 would raise the probability of done, which is the opposite of what is wanted. So that weight should go **down**.
- **The first weights are the hardest to change, because their effect passes through every layer.** Changing a weight near the input changes the first hidden layer, which changes the second, which changes the third, which finally changes the decision.

## p5
- **The real formant data from the class shows why AI is hard.** Each recording is a dot. **F1** is on the horizontal axis, and **F2** is on the vertical axis. There are 525 dots, 105 for each vowel.
  - The data has a pattern. The **/i/ dots sit high**, with a **high F2 and a low F1**, as the theory predicts. /i/ is clearly different from /u/.
  - The data also has **a lot of overlap**. Many /æ/ dots sit among the /i/ dots, and many others overlap with schwa. The /u/, /a/ and schwa groups pile on top of each other.
  - Some dots are probably measurement mistakes. Real data always has errors, the same way speech to a phone on a noisy train has errors, so the dots were left in.
- **If each vowel formed its own separate group, AI would be easy.** Because the groups overlap, a network has to see the data many times to learn where each vowel is most likely. Even then, many points are unclear.
  - For a new speaker whose formants land in the middle of the overlap, the best answer is the vowel whose dots are most common there.
  - Removing the differences between speakers is called **normalization**. People tried it for about seventy years without success. Hearing a lot of speech from the same speaker does help, because it gives the system more information about that person.
- **This overlap was first discovered in the early 1950s by Peterson and Barney.** Spectrograms had been kept secret by the military during the Second World War, and the overlap was found once spectrograms became available.
  - Good speech recognition only arrived around 2011 or 2012, using neural networks trained by backpropagation.
  - Surprisingly, speech that changes over time turned out to be easier for modern systems than this frozen, one-moment problem. Large language models use information from before and after each moment.

## p7
- **Backpropagation changes all the weights using two tools, stochastic gradient descent and dynamic programming.**
  - **Stochastic gradient descent** is the same method used to improve an average from data. Here it improves every weight. It has the same **learning rate**, with the same tradeoff between learning fast and learning accurately.
  - **Dynamic programming** decides the order. The weights at the end are improved first, then the weights before them, and so on back to the beginning. The easiest problem is solved first and the hardest problem is solved last.
- **The error says which way each output should move.** Done, at about 56 percent, should go down, dean should go up, and the other words should go down.

## p8
- **For the last weights, one inner product is enough to decide the direction.** The network said done when the answer was dean. So any last weight that pushes done up should be **lowered**, and any last weight that pushes dean up should be raised.

## p9
- **Backpropagation changes the last weights first, then the weights before them, back to the first weights.** Each problem is easier because something was already learned from the problems solved before it.
  - Modern systems apply this to about **six trillion weights**, which is what huge data centers are doing.
  - **Geoffrey Hinton** won the **2024 Nobel Prize in Physics** for backpropagation. The idea is at the center of much of today's economy, and it has roots in physics through dynamical systems.
  - In plain terms, blame for a mistake is easiest to assign to the weights closest to the mistake. That blame is then passed backward to the weights that came before.

## p10
- **Training uses two matrices of numbers, one for the formants and one for the true vowels.** The first matrix has one row per recording with **F1 and F2**. The second matrix has the matching row of **zeros and a single one** that marks the true vowel.
  - Learning picks a row, computes the network's decision, and compares it with the true answer.
  - If the decision is wrong, the weights change.
- **If the network makes the right decision, there is no error, so there is nothing to learn.** This can be a real problem. A network can keep getting the right answer by **memorizing** its data without learning the pattern underneath. Stopping the learning at that point would be stopping too early.
- **Children learning English show the same pattern, as Carol Chomsky observed in the early 1960s.**
  - First, very young children say **go** and **went** correctly, because they are **memorizing** what they hear.
  - Second, they notice the real pattern, that most English verbs form the past by adding a sound at the end, as in **jump** and **jumped**. So they start saying **goed**.
  - Third, they learn that some verbs are **exceptions**, and they get both the regular verbs and the exceptions right.
  - In plain terms, a right answer early on can come from memory, and real learning can show up as new mistakes.

## p11
- **The program's lines each have a job, and the exam can ask what the lines mean, but never how to write the program from scratch.**
  - **The import lines bring into Python the programs for inner products, backpropagation and related work**, so none of it has to be written by hand.
  - This works because of **libraries**, which are collections of programs written by one group that other people can use without knowing how they work inside. The idea of software built from parts like this goes back to **Margaret Hamilton's** software for **Apollo 11**.
  - Around 2015, **Facebook** released **PyTorch** and **Google** released **TensorFlow**, so researchers no longer had to write their own backpropagation code. Most people now use PyTorch, often called torch.
  - The **load** lines read the formant matrix and the vowel matrix from files.
- **Sequential means the network is a sequence of layers, one after another.** Every network covered so far is a sequence of layers. A large language model is an example of a network that is not just a sequence of layers.
  - Each **Linear** line is one **processing layer**. A processing layer has weights and does inner products with the incoming numbers.
  - The input layer does no processing, so the five layers need only **four lines**.
  - **nn.Linear(2, 3)** means "receive information from 2 neurons, and have 3 neurons." The other lines read the same way.
- **The last lines are all PyTorch needs for learning.**
  - **SGD** is stochastic gradient descent. **lr** is the **learning rate**, set here to 0.1.
  - **A higher learning rate learns much faster but less accurately. A lower learning rate learns more accurately but much more slowly.** So changing the learning rate from 0.1 to 0.3 makes the network learn faster, but its accuracy goes down.
  - **Loss** is the measure of the **mistake**. The program calculates the mistakes so it can learn from them.
  - **backward** runs **backpropagation**, and **step** updates the weights.

## p12
- **The sigmoid makes neurons nearly digital, like real neurons.** Artificial networks borrow their basic ideas from real brains. Real brains have **neurons**, and each neuron **gathers information from many other neurons**, which is what the inner product does.
- **Lord Edgar Adrian discovered in the 1920s that neurons are nearly digital, and he won the Nobel Prize in 1932.** A real neuron is either **firing** or **not firing**, not at some in-between level like 2, 16 or 34. The network's neurons so far are not like that, because their activations are numbers like slightly below zero, 6.64, 2.72 and 1.57.
- **The sigmoid takes an inner product and gives back a number between zero and one.**
  - An inner product of **minus 4**, minus 6 or minus 1000 gives about **zero**, so the neuron is **off**.
  - An inner product of **2** gives about 0.8 or 0.9. An inner product of **4**, 6 or 100 gives about **one**, so the neuron is **on**.
  - So the sigmoid makes neural processing nearly digital, the way brain chemistry does. Without that limit, an activation of a thousand would be like lightning coming out of someone's head.
- **The sigmoid also matches perception.** **Some things that seem alike are perceived as different, and some things that are very different are perceived as the same.** Very different large negative inputs all come out as off. Two nearly equal inputs on either side of the steep middle come out as off and on.

## p13
- **Adding the sigmoid one hidden neuron at a time changes the whole calculation after it.** Each neuron's raw inner product is replaced by its sigmoid value. Every later activation is recalculated, and the output probabilities shift.
  - The first hidden neuron, slightly below zero, becomes about 0.4. The second, about 6.6, becomes nearly 1.
  - With the sigmoid on all nine hidden neurons and the same random weights, the network's choice moves from done to Dan. The network is still wrong until it is trained.

## p14
- **In the program, nn.Sigmoid is added after each hidden linear layer.** nn.Sigmoid means "apply the sigmoid," which makes that layer nearly digital. The last layer gets no sigmoid, because its outputs go into the loss calculation.
  - The sigmoid can be replaced by other functions that look somewhat like it, such as **ReLU**, to test whether recognition gets better or worse.
  - **AI copies abilities that animals have.** Its most basic ideas come from biologists' discoveries about how brains work. Computer scientists then add their own ideas on top.

## p15
- **The full training program runs 2000 updates and records the accuracy after each one.** Each update uses all the recordings, with a learning rate of 0.1. The formants are divided by a thousand first, which turns hertz into kilohertz.
  - **Accuracy** is the percent of recordings the network classifies correctly. The word with the largest score counts as the network's answer.
- **The accuracy starts at 20 percent, which is chance.** With random weights, the network knows nothing. With **five vowels**, a random guess is right **one time out of five**, which is 20 percent. This level is called **chance**.
  - With **ten categories**, chance would be **10 percent**, because a random guess would be right one time in ten.
- **After a while, the accuracy jumps up to about 40 percent and then levels off near 45 percent.** The jump shows the network is learning something. Each pass of learning is called an **epoch**, and a problem like this takes thousands of epochs.

## p16
- **Ten training runs from ten different starting points all end at the same accuracy.** Each run started from a **different set of random weights**. A starting set of random numbers is called a **seed**, though the word itself will not be asked.
  - The runs take **different paths**. One run stays at chance for about 500 epochs before jumping up. Another run jumps up very early. Another run climbs more slowly.
  - **All ten runs end at the same accuracy**, close to 45 percent. Stochastic gradient descent always involves chance along the way, but the end point is the same.
- **Children learning language are similar.** One child's home might talk mostly about sports, and another child's home might talk mostly about politics. Each child hears very different words and voices. By about age four, both children speak the same language, because the basic patterns underneath their different inputs are the same.
- **The network levels off near 40 percent, not 100 percent, because the vowel data overlap so much.** For a point in the middle of the overlap, even a person looking carefully would have to guess. AI is not magic, so a problem that is very hard for people is also hard for machines.
  - The next experiment is to add or remove layers, or change the number of neurons in each layer, to see whether the 40 percent gets better or worse.
