4|A **quarter-wavelength** is the piece of a standing wave that connects a **node**, a point that never moves, to an **antinode**, a point of greatest movement. Quarter-waves are the building blocks of every shape on a **fixed–free string**, because that string has a node at one end and an antinode at the other. >> The fixed bottom of the string cannot move, so it must be a node. >> The free top of the string has nothing holding it, so it must be an antinode. || **One quarter-wave** fits exactly between those two ends. >> The movement starts at zero at the fixed bottom and grows steadily to its largest value at the free top. >> This is the simplest allowed pattern, with no still point anywhere inside the string. Its frequency is the fundamental. || Building the next allowed pattern requires care. >> Adding just one more quarter-wave would carry the shape from the antinode back to a node, so the string would end at a node. >> A node is the wrong condition for the free top, so that pattern is not allowed. >> Adding **two** quarter-waves carries the shape through a node and back to an antinode, so the top is correct again. || The allowed patterns therefore fit **one, three, five and seven quarter-waves** into the same length. >> Each step adds one more node and one more antinode inside the string. >> More sections in the same length make every wave shorter. >> The wave speed along the string stays the same, so shorter waves repeat faster, and each allowed pattern has a higher frequency than the one before. || The demonstration reveals one quarter-wave packet at a time, in every mode that contains it. >> The four modes contain **1, 3, 5 and 7** packets, which match the odd harmonics exactly. >> The numbered pieces divide the standing-wave shape into its sections. They do not move up the string in sequence. >> The string itself moves back and forth, while the still points of each pattern stay fixed in place. || The odd frequency pattern is a direct consequence of the two endpoint conditions. >> Only odd counts of quarter-waves can begin at a node and end at an antinode. >> Even frequencies are absent because the boundaries rule them out, not because anyone chose to leave them out.

6|Every point in a vibrating air column has two separate properties. >> **Movement** is how far an air element travels back and forth. >> **Compression** is how much the spacing between neighboring elements changes. >> These are not the same. Several neighboring elements can travel together over a large distance while the gaps between them stay nearly constant. In another region, the gaps can close and open strongly around a point that barely moves at all. || Each property has to be read in its own way from the animation. >> To see movement, follow one circle through a complete cycle and watch how far it travels. >> To see compression, compare the gaps between neighboring circles. Where the gaps shrink, the air is compressed. Where they widen, it is spread out. || The two properties together explain why the air oscillates. >> Changing compression supplies a **spring-like restoring effect**. Crowded air pushes back toward its usual spacing, and thinned air is pulled back toward it. >> The air’s **inertia** is the mass-like part. Once air is moving, it keeps moving while the restoring effect changes, so it overshoots and the cycle continues. || The ends of the tube decide where each kind of region falls. >> The **closed end** restricts movement, so air there can hardly travel. >> The **open end** permits movement, so air there travels freely. >> Higher modes fit more alternating regions of movement and compression into the same tube, and each mode places those regions at different positions. || The moving **Schwa** reference row and the **F1, F2 and F3** rows are all resonances of one and the same air system. >> They are not separate streams of air flowing through the tube. >> A constriction at one location can strongly affect moving mass in one mode and strongly affect compression in another mode. >> The effect of a constriction therefore depends on the mode being considered as well as on the place where the constriction sits.
7|This **pop quiz** labels six locations along the air column, **A, B, C, D, E and F**, and asks what each location is doing in the different modes. Answering it means reading movement and compression correctly. >> Each marked location has to be followed through a **complete cycle**. >> Watching its air element over the cycle reveals how far it moves. >> Comparing its neighbors over the cycle reveals how much the spacing around it changes. >> A single still frame cannot answer the question, because one frozen moment might catch a strongly moving element as it passes through rest. || A location with strong **movement** is where added mass matters. >> Greater **effective mass** at that spot makes the air harder to speed up and harder to reverse. >> Each cycle takes longer to complete, so the resonance tends to **fall**. || A location with strong **compression change** is where added stiffness matters. >> Greater **stiffness** at that spot produces a stronger return toward the usual spacing. >> When this effect dominates, the cycle becomes faster, and the resonance tends to **rise**. || **Modes 1, 2 and 3** arrange these regions differently along the tube. >> In Mode 1, the regions are spread broadly, with strong movement near the open end. >> In Modes 2 and 3, extra reversals add more alternating regions of movement and compression. >> The same physical location can therefore be a region of strong movement in one pattern and a region of strong compression in another. || Predicting the effect of a local change requires identifying two things at once. >> The **position** of the change along the tube. >> The **mode** whose frequency is being considered. >> Only with both can it be said whether a narrowing at that spot will mainly add moving mass or mainly add stiffness for that particular resonance.

10|**Mode 1** and **Mode 2** are two resonance patterns of one and the same air column. The column is held at the glottal end, where the air is constrained, and open at the lips, where the air can move freely. Comparing the two modes at the same locations explains how vowels shape formants. >> Both modes move the air strongly near the open lips. >> Mode 2 has one additional reversal inside the tube, so its movement and compression are arranged differently from Mode 1 along the rest of the column. || Three markers are placed along the tract, at the **back**, at the **front** and at the **lips**. >> Each marker identifies the same physical place in both modes. >> A narrowing at one marker changes the air at that region, and that change applies to both modes at once. >> What differs is how each mode uses that region. || The effect of a narrowing depends on what the mode is doing at the marker. >> Where the mode **moves the air strongly**, the narrowing’s mass-like effect is important. The extra moving load is harder to reverse, so the vibration tends to slow. >> Where the mode **compresses the air strongly**, the narrowing’s spring-like effect is important. The stronger restoring force returns the air faster, so the vibration tends to speed up. >> Because the two modes can be doing different things at the same marker, one narrowing can move **F1** and **F2** in different directions. || The two modes have a simple fixed relationship only in an ideal case. >> In the uniform reference tube, with no constriction, Mode 2 runs at **three times** the frequency of Mode 1, the odd-multiple pattern of a fixed–free system. >> Once the tract changes shape, the formants move and that simple ratio no longer holds. || It is important to keep formants and harmonics apart. >> **Formants** are resonances of the vocal tract. They change whenever the tract changes shape. >> **Harmonics** are components of the source. Their spacing comes from how fast the vocal folds repeat, and it changes with pitch, not with vowel shape.

15|The vocal folds supply the voiced **source** of speech. Their repetition rate is **F0**, the fundamental frequency, and F0 sets the spacing between the harmonic lines in the source spectrum. || The top row returns to the **fixed–fixed membrane**, with its five modes and their sum. >> The modes are **(1,1) at 100 Hz**, **(2,1) at 200 Hz**, **(1,2) at 300 Hz**, **(2,2) at 400 Hz** and **(3,1) at 500 Hz**. >> A pickup point records the combined motion of all five modes, which gives a spectrum with evenly spaced peaks. >> These membrane frequencies were assigned for the illustration. They model harmonic spacing without claiming that every natural membrane vibrates at harmonic frequencies. || The bottom row presents **three source spectra**, all before the vocal tract filter acts, in the same **0 to 4000 Hz** window. >> With **F0 at 100 Hz**, the harmonic lines are packed closely, with many lines in the window. >> With **F0 at 250 Hz**, the harmonics fall at **250, 500, 750** and onward. These come from **tighter, lighter vocal folds**. >> With **F0 at 350 Hz**, the harmonics fall at **350, 700, 1050** and onward. These come from **very tight and light vocal folds**. || In the same window, **lower F0 gives denser harmonic sampling**, and **higher F0 gives sparser sampling**. >> The comparison links heavier, looser vocal folds with slower repetition, and lighter, tighter folds with faster repetition. >> This follows the same mass–spring logic as every other oscillator. Mass resists changes in movement and slows the cycle, while tension supplies the restoring force and speeds it up. || A voiced vowel contains **many frequencies** at once, not just one. >> The repetition of the source determines which harmonic frequencies are available. >> The vocal tract then strengthens some regions of the spectrum and weakens others. >> Changing pitch changes the spacing of the source harmonics, while changing vowel shape changes the tract’s favored regions. These are two distinct contributions to the same sound, and they can be changed independently.
16|The **filter** in source–filter theory is the vocal tract, modeled as a **fixed–free** tube with one end closed and one end open. It selects **formants**, and its core rule can be stated in two sentences. >> **A formant encourages the closest harmonics to be audible.** >> **Harmonics far from that formant are muted.** >> The voiced source supplies the harmonics, and the filter chooses which of them survive. In this sense, the vowel shape is the filter. || A formant acts like a pulse of emphasis in the spectrum. >> Harmonics that fall near the center of a formant are strengthened. >> Harmonics that fall far from every formant are weakened. >> The result is a spectrum in which only certain regions stand out. || Each vowel shape places its formants at different frequencies. >> **Schwa**, the neutral vowel, has well-separated first and second resonances, near **500** and **1500 Hz**. >> **/u/** places both lower, near **300** and **1000 Hz**, and also marks a third formant near **2000 Hz**. >> The front vowel **/i/ or /ɪ/** has a low F1 near **300 Hz** and a much higher F2 near **2200 Hz**, so its first two formants are far apart. >> **/a/** places its first two targets close together, at **800** and **900 Hz**. >> These values belong to this particular illustration. || Changing the position of the tongue and lips changes the tract’s shape, and that moves these favored frequency regions. >> Each formant target lifts the harmonics that sit nearest to it. >> Harmonics between targets stay weak, which creates the valleys between formant peaks. || It is important to separate the formant targets from the harmonic lines. >> A **formant target** identifies a resonance of the tract, a property of the filter. >> A **harmonic line** identifies a component of the source, a property of the vocal folds. >> A target can lie between two source lines and still strengthen the harmonics on either side of it. Filtering changes their heights without creating a new component at each target, so source spacing and the filter’s pattern are different properties.
17|This grid compares **the same vowel filter at different pitches**. Source rows run across, and vowel filter columns run down, so every cell combines one source with one filter. **Dashed red ticks** mark the formant targets of each filter, and **colored stems** mark the actual harmonics after filtering. || Each row holds the source fixed. >> The top row comes from **heavy, loose** vocal folds, with the lowest F0 and closely spaced harmonics. >> The middle row comes from **lighter, tighter** folds, with **F0 at 250 Hz**. >> The bottom row comes from the **lightest, tightest** folds, with **F0 at 350 Hz** and widely spaced harmonics. || Each column holds the vowel filter fixed. >> Moving down a column changes only F0, so the formant ticks stay in exactly the same places while the harmonic stems spread apart. >> Moving across a row changes only the vowel filter, so the harmonic stems stay put while the formant ticks move. >> This arrangement separates the effects of the source from the effects of tract shape. || **Dense harmonics trace the formant shape well.** >> With a low F0, many harmonics fall near each resonance. >> Their heights rise toward each formant and fall away from it, drawing the filter’s **envelope**, the smooth outline of favored strengths. >> More harmonics in the window give a smoother, easier-to-read shaped spectrum. || **Sparse harmonics can miss a formant or make it look ambiguous.** >> With a high F0, the gaps between stems widen, so each formant is sampled by fewer harmonics. >> A strong stem may sit beside a formant target instead of directly on it, even though the target has not moved. >> The two close /a/ targets can then look like one grouped region instead of two separate peaks. Closer harmonics give more information, but they still do not guarantee two clearly separate peaks for formants that are very near each other. || Difficulty reading a formant does not mean that the resonance has disappeared. >> The ticks stay in the same place within every column. >> A line’s horizontal position gives its frequency, and its height gives its strength. >> When the targets are unchanged but the stems have spread apart, the change has come from the source, and the filter has stayed the same.
18|A **spectrum** shows the sound at **one instant**, and a **spectrogram** **stacks many spectra over time**. Converting from one display to the other takes two steps. || In a **spectrum**, frequency runs along the horizontal axis and peak height gives amplitude. >> Each spectrum describes one short slice of sound. >> The sequence contains three slices of **/i/** followed by three slices of **/a/**. || The **first step** maps the spectrum’s frequency axis onto the spectrogram’s **vertical axis**. >> Each spectrum is turned on its side, so a peak at the right of a spectrum, a high frequency, becomes a mark near the top of the spectrogram. >> The slices are then placed side by side from left to right in time order. >> In the finished spectrogram, time runs left to right and frequency runs from bottom to top. || The **second step** turns **spectrum height into darkness**. >> **Black** means high amplitude, **gray** means medium and **white** means low. >> A tall peak becomes a dark mark, and a low dip becomes a pale one. >> Two kinds of change can now be read separately. A **rising** band is moving to a higher frequency. A **darkening** band is becoming stronger at the frequency where it already sits. || The horizontal axis means something different in each display. >> Moving to the right in a **spectrum** means moving to a higher frequency. >> Moving to the right in a **spectrogram** means moving to a later time. || During the **/i/ to /a/** transition, the first strong band **rises** and the second strong band **falls**, bringing them toward each other. >> One upper band also moves down, while a fainter band stays in the high-frequency region. >> Connecting neighboring slices traces the changing resonance pattern of the vocal tract. >> Position and darkness carry different information about that change, position giving frequency and darkness giving strength.

21|Speech science leads **back to AI**. The plan is to build a **neural network**, or **NN**, that is trained on students’ own **formants** and decides which vowel is being spoken. This connects everything about how the vocal tract shapes vowels to a computational system that learns to recognize them. || The network’s inputs are **F1** and **F2**. >> F1 and F2 are the first two resonance regions emphasized by the vocal tract, the formants that the mass–spring model of the tract explains. >> They provide a compact pair of measurements for each vowel. >> The network does not need every individual point in the waveform. Two numbers already carry much of what distinguishes one vowel from another, because tongue position and lip shape move these two formants in characteristic ways. || The **input** and the **output** are different kinds of information. >> The input is a pair of measurements of the sound, the two formant frequencies. >> The intended output distinguishes between candidate vowel categories, picking out which vowel was spoken. >> Knowing the formant pair supplies evidence about the sound. Knowing the true label tells which category that example actually belongs to. >> Recognition means learning to relate the measured pattern to the correct category. || The proposed exercise links the physical explanation of speech with AI. >> The mass–spring account explains where F1 and F2 come from and why different vowels have different values. >> The network learns the relationship between those two numbers and the vowel categories, using students’ formant measurements as training data. >> At this stage, the inputs and the task are set. Showing that the network actually recognizes vowels well would require the results of training and testing it on real examples.
22|The vowel network is a **purely linear** feed-forward network. Its structure runs from **2 inputs**, through **hidden layers of 3, 2 and 4 neurons**, to **5 outputs**, one per word, and it uses **no activation functions**. || The two inputs are **F1** and **F2**. >> Their order matters, because each input position stands for one particular formant. >> Swapping them would change their meaning for the network. || Every layer is **fully connected**. >> Each receiving neuron connects to every neuron in the layer before it. >> Each connection has its own **weight**, a number that sets how strongly that incoming value counts. >> A receiving neuron multiplies each incoming value by the weight on its connection and then adds all of those products together. That sum is the neuron’s value. || The **hidden layers** hold intermediate combinations of the inputs. >> The first hidden layer has **three** neurons, the second has **two** and the third has **four**. >> Each hidden value is a new weighted combination of the values before it. Hidden values are not new measured formants, and they are not finished vowel categories. >> Because each neuron has its own weights, different neurons combine the same inputs in different ways. || The **five outputs** correspond, from top to bottom, to **/done/, /dune/, /dean/, /Don/** and **/Dan/**. >> Keeping that order fixed preserves the meaning of each output value, so the first output always refers to /done/. || **Purely linear** means that no activation function appears between the layers. >> Each layer passes its weighted sums directly to the next layer. >> The whole network is therefore a chain of weighted sums from input to output. >> Passing these sums forward describes the computation, but it does not by itself guarantee that the five final values behave like probabilities. A separate step would be needed for that.
23|An example input enters the network with **F1 = 320** and **F2 = 2000**. Before training begins, **every edge gets a random weight**. || The input and the weights play completely different roles. >> The inputs are **measurements** of the sound, the two formant frequencies of one vowel example. >> The **weights** are the network’s **settings**. They determine how the network combines the measurements as they pass from layer to layer. >> Changing the weights can change every internal result, even when the input pair stays exactly the same. || Each connection supplies one weight, and each neuron combines its inputs the same way. >> A neuron multiplies each incoming value by its weight and adds the products. >> A neuron in the first hidden layer receives both F1 and F2, so it has two incoming weights, one for each formant. >> The three neurons in that layer each have their own pair of weights, so they form three different combinations of the same two inputs. || **Before training, every weight is a random number between −1 and 1.** >> Values on the edges include **0.95**, **−0.91**, **−0.15**, **0.28** and **−0.76**. >> The heading says **blue for positive** weights and **orange for negative** weights, though the negative edges appear green in the rendered figure. The safest guide is the written number on each edge, whose sign gives the direction of the contribution and whose size gives its strength. >> A positive weight passes its input along with the same sign, and a negative weight flips it. Positive and negative contributions can therefore reinforce or oppose one another when a neuron adds them up. || The displayed weights are **random starting values**. They contain no learned knowledge about vowels. >> A **forward pass** processes an example using whatever weights the network currently has. >> **Learning** is the separate process that changes those weights so that the outputs become more accurate. >> Naming the outputs /done/, /dune/ and so on does not mean the untrained network already recognizes those words correctly.
24|In the **forward flow**, the input flows forward **layer by layer** through the network. At the output, the network produces **a distribution over the five words**, a set of numbers that says how much support each word gets. || The animation carries the input forward step by step. >> Dots carry the formant values along the connections from the inputs to the first hidden layer. >> Each layer combines the values from the previous layer using its current weights and passes the results on. >> The process repeats until the output layer is reached. This is the **forward pass**. Learning would require an additional process that changes the weights. || The illustrated output distribution assigns a probability to each word. >> **/done/** receives **0.5**. >> **/Dan/** receives **0.2**. >> **/dune/**, **/dean/** and **/Don/** receive **0.1** each. >> /done/ is therefore the favored prediction, while the other words keep some smaller amount of support. || A valid probability distribution has two properties. >> Every value lies between zero and one. >> All of the values add up to exactly one. >> These five values, 0.5, 0.1, 0.1, 0.1 and 0.2, satisfy both conditions. || The bars illustrate the intended kind of output rather than a computed result. >> The purely linear network contains no step that forces its outputs to become a probability distribution. >> The bars therefore picture what the network is meant to produce, not a verified result of the particular random weights shown. || The **predicted category** and the **true category** are different things. >> The predicted category is the word the model favors, here /done/. >> The true category is the example’s actual label, the vowel that was really spoken. >> Judging whether a prediction is correct requires that true label. The tallest bar and the smiley face that appears after it cannot, on their own, show whether the network was right.
