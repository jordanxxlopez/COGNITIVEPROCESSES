4|A **quarter-wavelength** is the part of a standing wave that goes from a **node**, where nothing moves, to an **antinode**, where movement is greatest. A fixed–free string needs a node at its fixed bottom and an antinode at its free top. >> One quarter-wave fits between those two ends. >> This is the simplest pattern, and it gives the lowest frequency. || The next pattern cannot add just one quarter-wave. >> One more would end the string on a node. >> A free end cannot be a node, so that pattern is not allowed. || Adding **two** quarter-waves works. >> It brings the top back to an antinode. >> So the allowed patterns have **one, three, five and seven** quarter-waves. || More pieces in the same length make the waves shorter. >> Shorter waves repeat faster. >> So each allowed pattern has a higher frequency than the one before. || The four patterns line up with the **odd harmonics**. >> Only odd numbers of quarter-waves start at a node and end at an antinode. >> The even harmonics are missing because the two ends of the string rule them out.

6|Each spot in a vibrating column of air can be described in two ways. >> **Movement** is how far the air at that spot travels. >> **Compression** is how much the gaps between neighboring bits of air change. || These are two different things. >> A group of air can travel a long way together while the gaps between them stay the same. >> In other places, the gaps squeeze and stretch a lot around air that barely moves. || Each is found in its own way. >> To find movement, follow one bit of air through a full cycle. >> To find compression, watch the gaps around it open and close. || Together, they keep the air vibrating. >> Squeezed air pushes back. That is the spring. >> Moving air keeps going. That is the mass. || The closed end of the tube holds the air still, and the open end lets it move. >> Each mode places its moving and squeezing regions in different spots. >> So a narrowing in one place can affect moving mass in one mode and squeezing in another. >> What a narrowing does depends on both the mode and the place.
7|This **pop quiz** marks six spots along the air column and asks what each spot is doing. >> Each spot must be followed through a **full cycle**. >> How far its air travels gives its movement. >> How the gaps around it change gives its compression. >> One still picture is not enough, because air that moves a lot can look still for a moment as it passes through rest. || Where the air **moves a lot**, added mass matters. >> Extra mass is harder to get moving and harder to stop. >> The cycle takes longer, so the frequency **goes down**. || Where the air is **squeezed a lot**, added stiffness matters. >> Extra stiffness pushes the air back harder. >> The cycle gets shorter, so the frequency **goes up**. || Each mode puts its moving and squeezing spots in different places. >> A spot that moves a lot in one mode can be squeezed a lot in another. >> So predicting the effect of a narrowing takes two things, the **place** and the **mode**.

10|**Mode 1** and **Mode 2** are two ways that the same column of air can vibrate. The column is closed at the glottis and open at the lips. >> Both modes move the air a lot near the lips. >> Mode 2 has one more back-and-forth reversal inside the tube, so its moving and squeezing spots are in different places. || Three places are marked along the tube, at the **back**, the **front** and the **lips**. >> Each place is the same spot in both modes. >> Narrowing the tube at one place changes the air there for both modes. || What the narrowing does depends on what each mode is doing at that spot. >> If a mode **moves** the air there a lot, the added mass slows it down. >> If a mode **squeezes** the air there a lot, the added stiffness speeds it up. >> The two modes can be doing different things at the same spot. 15|The vocal folds make the **source** of a voiced sound. How fast they repeat is called **F0**, and F0 sets how far apart the harmonics are. || A **vibrating membrane** gives a model for this. >> Its modes combine into one motion with evenly spaced frequencies. >> That even spacing is what a harmonic source looks like. || Different vocal folds give different spacing. >> Heavy, loose vocal folds repeat slowly. Their harmonics are **close together**. >> Tighter, lighter vocal folds repeat faster. With an F0 of **250 Hz**, the harmonics are 250 Hz apart. >> Very tight, light vocal folds repeat faster still. With an F0 of **350 Hz**, the harmonics are 350 Hz apart. || This follows the same rule as every oscillator. >> More mass makes the vibration slower. >> More tension makes it faster. || A voiced vowel is made of **many frequencies** at once. >> The source decides which harmonics are present. >> The vocal tract then makes some of them stronger and others weaker. >> So pitch and vowel shape change two different parts of the same sound.
16|The vocal tract acts as a **filter**. It is like a tube that is closed at one end and open at the other. Its resonances are called **formants**, and they follow one simple rule. >> **A formant makes the harmonics closest to it louder.** >> **Harmonics far from any formant are made quieter.** >> The source supplies the harmonics. The filter decides which ones come through strongly. || Each vowel puts its formants in different places. >> **Schwa** has its first two formants well apart. >> **/u/** has both of them low. >> **/i/** has a low first formant and a very high second formant. >> **/a/** has its first two formants close together. || Changing the shape of the tongue and lips changes the shape of the tract. >> That moves the formants. >> So the shape of the vowel is the filter. || A formant and a harmonic are not the same thing. >> A formant is a resonance of the vocal tract. >> A harmonic is a frequency that comes from the vocal folds. >> A formant can fall between two harmonics and still make both of them louder. The filter changes the strength of harmonics, but it does not create new ones.
17|The same vowel can look different at different pitches. Comparing one vowel at several pitches separates what the voice does from what the vocal tract does. || When only the **pitch** changes, the formants stay in the same place. >> The harmonics spread farther apart as the pitch goes up. || When only the **vowel** changes, the harmonics stay in the same place. >> The formants move. || **Close-together harmonics trace a formant well.** >> At a low pitch, many harmonics fall near each formant. >> Their strengths rise and fall smoothly, showing the shape of the formant clearly. || **Spread-out harmonics can hide a formant.** >> At a high pitch, only a few harmonics fall near each formant. >> A strong harmonic might sit next to a formant instead of right on it. >> Two formants that are close together, like the first two in /a/, can blur into what looks like one. || A formant that is hard to see is still there. >> The vocal tract has not changed. >> Only the voice has changed, and a higher voice gives fewer harmonics to reveal the same formants.
18|A **spectrum** shows the sound at **one moment**. A **spectrogram** lines up **many spectra over time**. || Two changes turn a series of spectra into a spectrogram. >> First, each spectrum is turned on its side, so frequency runs from bottom to top. The spectra are then placed side by side in time order. >> Second, the strength of each frequency is shown as **darkness**. Darker means stronger. || This makes two kinds of change easy to see. >> A band that moves **up** is moving to a higher frequency. >> A band that gets **darker** is getting stronger. || The left-to-right direction means different things in the two pictures. >> In a spectrum, moving right means higher frequency. >> In a spectrogram, moving right means later in time. || As **/i/** changes to **/a/**, the first formant **rises** and the second formant **falls**. >> The two bands move toward each other. >> The spectrogram tracks how the vocal tract changes over time.

21|All of this connects back to **AI**. The plan is to build a **neural network** that learns from students’ **formants** and decides which vowel is being spoken. || The network uses two numbers, **F1** and **F2**. >> These are the first two formants of the vowel. >> Two numbers are enough to start with, because the position of the tongue and lips moves these two formants in typical ways for each vowel. || The **input** and the **output** are different kinds of information. >> The input is the pair of formant measurements. >> The output is a choice among vowel categories. >> To learn, the network needs to know the true vowel for each example. || This links the physics of speech with machine learning. >> The mass–spring model explains where F1 and F2 come from. >> The network learns how those two numbers match up with each vowel. >> Training and testing will reveal how well it learns.
22|The vowel network is a **purely linear** network. It takes **2 inputs**, passes them through **three hidden layers**, and ends with **5 outputs**, one for each word. It uses **no activation functions**. || The two inputs are **F1** and **F2**. || Every layer is **fully connected**. >> Each neuron is connected to every neuron in the layer before it. >> Each connection has a **weight**. A weight is a number that sets how much that connection counts. >> A neuron multiplies each incoming value by its weight and adds them all up. That total is its value. || The **hidden layers** hold in-between results. >> Each hidden value is a new mix of the values that came before. >> Each neuron has its own weights, so each one mixes the inputs in its own way. || The five outputs stand for five words, **done**, **dune**, **dean**, **Don** and **Dan**. || **Purely linear** means each layer just adds up weighted values and passes them on. >> Nothing in between bends or reshapes the numbers. >> So the whole network is a chain of weighted sums. >> On its own, that chain does not turn the outputs into probabilities.
23|One example goes into the network, with **F1 at 320** and **F2 at 2000**. Before training, **every connection gets a random weight**. || The input and the weights do different jobs. >> The input **measures** the sound. >> The weights are the network’s **settings**. They decide how the measurements get mixed together. >> If the weights change, every result inside the network changes, even with the same input. || Each neuron mixes its inputs in its own way. >> It multiplies each incoming value by a weight and adds up the results. >> The first neurons each get F1 and F2, but each one has its own two weights, so each one makes a different mix. || Before training, **every weight is a random number between −1 and 1**. >> Some weights are **positive**, and some are **negative**. >> A negative weight flips the sign of its input. >> So some contributions add up, and others cancel each other out. || These random weights hold no knowledge about vowels yet. >> Sending an example through the network with its current weights is called a **forward pass**. >> **Learning** is what changes the weights so the network gets better.
24|In a **forward pass**, the input moves through the network **one layer at a time**. At the end, the network gives a **probability for each of the five words**. || Each layer mixes the values from the layer before and passes them on. >> This continues until the output layer is reached. >> Learning is a separate step that changes the weights. || In the example, the network gives **done** the highest probability, **0.5**. >> **Dan** gets 0.2. >> Each of the other three words gets 0.1. >> So the network’s best guess is **done**. || Probabilities follow two rules. >> Each one is between zero and one. >> Together, they add up to one. || The example output pictures the kind of result the network should give. >> A purely linear network has no step that makes sure its outputs follow these rules. || A **predicted** answer is not the same as a **true** answer. >> The predicted answer is the word the network favors. >> The true answer is the vowel that was really spoken. >> Only the true answer can say whether the network was right.
25|The same network can be written in **PyTorch**, a tool for building neural networks. || The code first loads PyTorch and its neural-network tools, called **nn**. >> The network itself is stored under the name **net**. || **nn.Sequential** stacks the layers in order. >> Information passes through the layers in the order they are listed. || Each layer is written as **nn.Linear**, followed by two numbers. >> The first number is how many values come in. >> The second number is how many values go out. >> The layers go from 2 to 3, then 3 to 2, then 2 to 4, then 4 to 5. >> The number going out of each layer matches the number coming into the next one, so the values can flow all the way through. || Each layer also says **bias=False**. >> A bias is an extra number that a layer can add to each sum. >> Turning it off keeps every layer purely linear, just like the picture. >> All the weights are still there, and they can still be learned. || This code only **describes** the network. >> It does not train it. >> Training would need examples with the right answers, and a way to change the weights.
