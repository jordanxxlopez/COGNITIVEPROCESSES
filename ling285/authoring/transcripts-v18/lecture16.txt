5|This plot shows all the vowel data, **525** recordings in all, **105** of each vowel. Each dot is one recording, placed by its **F1** and **F2**. >> These are the two numbers the network uses. >> The color gives the right word for each recording. || Each vowel makes a cloud of dots, not a single point. >> The same vowel comes out a little differently each time it is said. >> The five vowels are **i (dean)**, **ae (Dan)**, **u (dune)**, **a (Don)** and **schwa (done)**. || Some vowels are easy to tell apart. >> **i** has a very high F2. >> **ae** has a high F1. || Other vowels overlap a lot. >> **u**, **a** and **schwa** sit in the same part of the plot. >> A dot in that area could belong to any of the three. || This overlap limits the network. >> It sees only F1 and F2, so two recordings in the same spot look the same to it. >> Some recordings will always be labeled wrong, so the network cannot be perfect on these data.

15|Here the vowel network is trained for real. It starts from one set of random weights, called an **initialization**. >> The network is all linear, with no biases and no activation functions. >> The formants are changed from hertz to kilohertz so the numbers stay small. || Training repeats one step **2,000** times. >> Each step clears old gradients, finds the error on all the recordings at once, works backward, and updates the weights. >> The learning rate is **0.1**. || After each step, the code checks the network’s **accuracy**. >> The network’s answer is the word with the biggest score. >> Accuracy is the share of the **525** training recordings it gets right. || Accuracy starts at **20%**, the level of a blind guess among five words. >> It stays there for a while, then jumps up. >> It dips once, recovers, and levels off. >> It ends at about **45%**. || The curve was made with a **NumPy** version of the same program. >> PyTorch was not available where the plot was made.
16|Now training is run ten times, each time from different random starting weights. >> Everything else stays exactly the same. >> So any difference between the runs comes from where the network starts. || The runs take different paths. >> Some improve quickly, and others stay at **20%** for longer. >> Some dip down for a while before they recover. || In the end, all ten runs reach the same place. >> **All ten finish at about 45%** accuracy. >> Their lines lie on top of each other once training settles. || So the starting point changes the path, but not the result. >> Trying more starting points would not help here. >> The limit comes from the network and from the overlapping vowels. || These runs were also made with **NumPy**. >> The same seed number gives different starting weights in NumPy and PyTorch.
