**Section 1: A Network That Recognizes Vowels**

- This **neural network** simulates a very simple piece of human perception. It takes the **two formants**, F1 and F2, of an isolated vowel and decides which of five words it heard, **done, dune, dean, Don or Dan**. It has 2 input neurons, hidden layers of 3, 2 and 4 neurons, and 5 output neurons, and every neuron connects to every neuron in the next layer.

- **The weights are the network's knowledge.** Each one is a positive or negative number, and the network is told the right answer for each recording as a probability distribution. For a speaker's /i/, it is told **0, 0, 1, 0, 0**, which means a 100 percent chance that the word was dean.
  - At first **the weights are random**, so the network knows nothing, and the distribution it produces is usually very different from the right one.
  - The difference is a **mistake**, and the network learns by correcting its mistakes.

**Section 2: Forward Propagation and the Network's Decision**

- **Forward propagation** carries the input through the network. With **F1 of 320 and F2 of 2000**, one speaker's /i/, each neuron in the first hidden layer computes an **inner product**, multiplying each formant by its weight and adding the results. Those activations feed the next layer, which does its own inner products, and so on until the output gives a probability for each word.
  - With random weights, the network gives its highest probability, more than half, to **done**. So it decides it heard done, even though the right answer is dean.

- To fix the mistake, **all the weights must change**, the ones near the output and the ones near the input. The algorithm that does this is **backpropagation**, which is made of **stochastic gradient descent** and **dynamic programming**.
  - **Stochastic gradient descent** is the same algorithm used to improve an average from data, now used to improve every weight. It has the same **learning rate**, with the same tradeoff between learning fast and learning accurately.
  - **Dynamic programming** supplies the order. The weights at the end are improved first, then the ones before them, and so on back to the beginning, so the most trivial problem is solved first and the hardest problem last.

**Section 3: Why the Last Weights Are the Easiest to Change**

- **Changing a weight at the very end is directly and immediately reflected in the output probabilities**, which are the network's decision. Those weights are exactly the ones used in the final inner products.
  - For example, the probability of done comes partly from a weight of 0.1 times an activation of about 1.57.
  - The network said done when the answer was dean, so the probability of done is **too high**. Raising that 0.1 to 0.5 would raise the probability of done, which is the exact opposite of what is wanted, so that weight should go **down**.
  - For the last weights, it is easy to tell whether each should go up or down.

- **Changing a weight near the input sets off a chain of changes.** It changes the activations of the first hidden layer, which change the second hidden layer, which change the third, which finally change the decision. So deciding how to change an early weight is a very hard problem, as hard as the dynamic programming puzzle where simply picking the smaller next step gives the wrong answer.

- **Backpropagation changes the last weights first, then the ones before them, and so on to the first.** Each later problem is easier because something has already been learned from the problems solved before them.
  - The error itself says which way each output should move. Done at about 56 percent should go down, dean should go up, and the others should go down.
  - Modern systems apply this same procedure to about **six trillion weights**, which is what the huge data centers are doing.
  - **Geoffrey Hinton** won the **2024 Nobel Prize in Physics** for backpropagation, an idea at the center of much of today's economy, and it has roots in physics through dynamical systems.
  - In plain terms, the blame for a mistake is easiest to assign to the weights closest to the mistake, and that blame is then passed backward to the weights that came before.

**Section 4: Real Vowel Data Overlaps**

- The real formant data from the class shows why AI is hard. Each recording is a dot, with **F1 along the horizontal axis** and **F2 up the vertical axis**, and there are 525 dots, 105 for each vowel.
  - The data do show a pattern. The **/i/ dots sit high**, with a **high F2 and a low F1**, just as the theory predicts, and /i/ is clearly different from /u/.
  - But there is **enormous overlap**. Many of the /æ/ dots sit among the /i/ dots, many overlap with schwa, and the /u/, /a/ and schwa clouds pile on top of one another.
  - Some dots are probably mistakes in measurement. Real data always has errors, just as speech to a phone on a noisy train does, so they were left in.

- **If the vowels sat in separate clusters, AI would be easy.** Because they overlap, a network has to see the data many times to learn where each vowel is most likely, and even then many points are ambiguous. For a new speaker whose formants land in the middle of the overlap, the best answer is only the vowel whose dots are most common there.
  - Trying to remove the differences between speakers, which is called **normalization**, was attempted for about seventy years without success. Hearing a lot of speech from the same speaker does help, because it gives the system more information about that person.
  - This overlap was first discovered in the early 1950s by **Peterson and Barney**, once spectrograms, which had been kept secret by the militaries during the Second World War, became available. Good speech recognition only arrived around 2011 or 2012, with neural networks trained by backpropagation.
  - Surprisingly, the dynamic problem of speech changing over time turned out to be easier for modern systems than this static one, because large language models use information from the left and the right of each moment.

**Section 5: Learning Happens Only Through Errors**

- Training uses **two matrices** of numbers. The first has one row per recording with **F1 and F2**, and the second has the matching row of **zeros and a single one** that says which vowel it really was. Learning picks a row, computes the network's decision, compares it with the true answer, and changes the weights if the decision is wrong.

- **If the network makes the right decision, there is no error, so there is nothing to learn.** This can be a real problem. A network can keep getting the right answer by **memorizing** its data without learning the pattern underneath it, and stopping its learning then would be stopping too early.

- Children learning English show the same thing, as **Carol Chomsky** observed in the early 1960s.
  - Very young children first say **go** and **went** correctly, because they are simply **memorizing** what they hear.
  - Then they notice the real pattern, that most English verbs form the past by adding a sound at the end, as in **jump** and **jumped**, and they start saying **goed**.
  - Only later do they learn that some verbs are **exceptions**, and they get both the regular verbs and the exceptions right.
  - In plain terms, getting the right answer early can come from memory, and real learning sometimes shows up as new mistakes.

**Section 6: Reading the PyTorch Program**

- The program that trains the network is short, and the exam can ask what its lines mean, though never how to write it from scratch.

```python
import torch
from torch import nn

net = nn.Sequential(
    nn.Linear(2, 3),
    nn.Linear(3, 2),
    nn.Linear(2, 4),
    nn.Linear(4, 5)
)

sgd = torch.optim.SGD(net.parameters(), lr=0.1)
loss = nn.CrossEntropyLoss()(net(X), Y)
loss.backward()
sgd.step()
```

- **The import lines bring into Python the programs for doing inner products, backpropagation and related work**, so none of that has to be written by hand.
  - This works because of **libraries**, collections of programs written by one group that others can use without knowing how they work inside. The idea of software built this way goes back to **Margaret Hamilton's** work on the software that flew **Apollo 11** to the moon.
  - Around 2015, **Facebook** released **PyTorch** and **Google** released **TensorFlow**, so that researchers no longer had to write their own backpropagation code. Most people now use PyTorch, often just called torch.
  - The **load** lines read the formant matrix and the matching vowel matrix from files on the computer.

- **Sequential means a network that is a sequence of layers**, one after another, which describes every network covered so far. A large language model is an example of a network that is not just a sequence of layers.
  - Each **Linear** line is one **processing layer**, which has weights and does inner products with the information coming in. The input layer does no processing, so the five layers need only **four lines**.
  - **nn.Linear(2, 3)** says "I receive information from 2 neurons, and I have 3 neurons." The other lines read the same way.

- The last lines are all that PyTorch needs for learning.
  - **SGD** is stochastic gradient descent, and **lr** is the **learning rate**, set here to 0.1. **A higher learning rate learns much faster but less accurately, and a lower learning rate learns more accurately but much more slowly.**
  - So changing the line from a learning rate of 0.1 to 0.3 makes the network **learn faster**, but its **accuracy goes down**.
  - **Loss** is the **mistake**, and the program calculates the mistakes so it can learn from them.
  - **backward** is **backpropagation**, and **step** updates the weights.

**Section 7: The Sigmoid Makes Neurons Nearly Digital**

- Artificial neural networks borrow their basic ideas from discoveries about real brains. There are **neurons**, and each neuron **gathers information from many other neurons**, which is what the inner product does.

- **Lord Edgar Adrian**, who won the **Nobel Prize in 1932** for work in the 1920s, discovered that **neurons are nearly digital**. A real neuron is either **firing** or **not firing**, not at some level like 2, 16 or 34. The neurons in the network so far are not like that, since their activations are real numbers like slightly below zero, 6.64, 2.72 and 1.57.

- The **sigmoid** is an **activation function** added to the network to work like Adrian's discovery. It takes an inner product and gives back a number between zero and one.
  - An inner product of **minus 4**, minus 6 or minus 1000 gives about **zero**, so the neuron is **off**.
  - An inner product of **2** gives about 0.8 or 0.9, and **4**, 6 or 100 give about **one**, so the neuron is **on**.
  - So the sigmoid **digitizes** neural processing, the way brain chemistry does. Without that limit, an activation of a thousand would be like lightning coming out of someone's head.

- The sigmoid also reflects perception. **Some things that seem alike are perceived as different, and some things that are very different are perceived as the same.** Very different large negative inputs all come out as off, while two nearly equal inputs on either side of the steep middle come out as off and on.

**Section 8: Applying the Sigmoid in the Network**

- Applying the sigmoid one hidden neuron at a time changes the whole calculation downstream. Each neuron's raw inner product is replaced by its sigmoid value, every later activation is recalculated, and the output probabilities shift.
  - The first hidden neuron, slightly below zero, becomes about 0.4, and the second, about 6.6, becomes nearly 1.
  - With the sigmoid on all nine hidden neurons and the same random weights, the network's choice moves from done to Dan, so it is still wrong until it is trained.

- In the program, **nn.Sigmoid** is added after each hidden linear layer, which means "apply the sigmoid," or make that layer digital. The last layer gets no sigmoid, because its outputs go into the loss calculation.
  - The sigmoid can also be replaced by other functions that look somewhat like it, such as **ReLU**, and trying them out shows whether they improve recognition or make it worse.
  - **AI is duplicating abilities that animals have.** Its most fundamental ideas come from biologists' discoveries about how brains work, and computer scientists then add ideas of their own on top.

**Section 9: Training the Network from One Starting Point**

- The full training program runs **2000 updates**, each one using all the recordings, with a learning rate of 0.1. The formants are divided by a thousand first, turning hertz into kilohertz, and after every update the program records the **accuracy**, which is the percent of recordings the network classifies correctly. The word with the largest score counts as the network's answer.

- **The accuracy starts at 20 percent.** With random weights the network knows nothing, but with **five vowels**, even a random guess is right **one time out of five**. That level is called **chance**.
  - With **ten categories**, chance would be **10 percent**, since a random guess would be right one time in ten.

- After a while the accuracy **jumps up to about 40 percent**, so the network is clearly learning something. Then it **levels off**, finishing near **45 percent**. Each pass of learning is called an **epoch**, and it takes thousands of them for a problem like this.

**Section 10: Ten Starting Points, the Same Final Accuracy**

- Training was repeated **ten times** on the same data, each time starting from a **different set of random weights**. A starting set of random numbers is called a **seed**, though the word itself will not be asked.
  - The runs take **different paths**. One stays at chance for about 500 epochs before jumping up, another jumps up very early, and another climbs more gradually.
  - **All ten end at the same accuracy**, close to 45 percent. Learning by stochastic gradient descent always involves chance along the way, but the end point is the same.

- Children learning language are similar. One child's home might talk mostly about sports and another's about politics, so each child hears very different words and voices. Yet by about age four, they speak the same language, because the fundamental patterns underneath their different inputs are the same.

- **The network levels off near 40 percent, not 100, because the data overlap so much.** For a point in the middle of the overlap, even a person looking carefully at the data would have to squint and guess. AI is not magic, so a problem that is very hard for humans is hard for machines too.
  - Adding or removing layers, or changing the number of neurons in each layer, is the next experiment, to see whether those changes improve on the 40 percent or make it worse.
