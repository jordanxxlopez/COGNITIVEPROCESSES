2|**A neuron takes a vector and returns one number.** Each input is multiplied by its weight, and the products are added to give the output. This weighted sum is an **inner product**. A neural network joins many such operations into layers, so one input vector becomes a **decision vector**, with a response for each possible answer. >> **A large language model takes many vectors and predicts what comes next.** Fifteen token vectors pass through five layers in the example. Each layer changes their representations through its weights, and the final output is the sixteenth vector, a **probability distribution** over the next token. The values express which continuations the model treats as more or less likely. || **An agentic system connects several LLMs into a graph.** The Outline model develops a plan, the Write model produces a draft, the Critic model evaluates it, the Revise model changes it, and the Final model produces the answer. The connection between Critic and Revise forms a loop, allowing a revision to be evaluated again. >> The agents communicate through **language**. One model’s written output becomes information another model can use, so the graph coordinates whole language models rather than individual neurons. The agents can speak to each other in English, while the models can also work in other human languages and computer languages. || **Inference uses inner products, and learning uses SGD with dynamic programming.** Inference processes the current inputs with the learned weights. **Stochastic gradient descent**, or SGD, changes weights to reduce prediction error, while backpropagation uses **dynamic programming** to organize the backward calculation. These operations support the small network as well as the language models joined into the agentic graph.
3|**Predicting the next word is difficult because the prediction depends on information spread through the sequence.** A language model therefore uses many layers of processing. Each layer receives representations of the input and changes them before passing them onward, giving the following layer more useful information for the prediction. >> **Within a layer, several heads work in parallel.** A head is one of the processing components that contributes to the layer’s representation. The heads are described as different experts because each can contribute a different part of the information the layer uses. They work alongside one another rather than waiting for one head to finish before another begins. || **The layer brings the heads’ contributions together.** The result is an improved set of representations, written as **x**, for the sequence. A representation is the information carried by a vector about an input item. Combining several contributions lets that representation incorporate more than one head contributes on its own. >> **The next layer repeats the process with the representations it receives.** It has parallel heads whose contributions are combined again. The model therefore develops its representations through a succession of layers, rather than making its final prediction directly from the original input vectors. || **Heads and layers add different kinds of structure.** Heads provide parallel contributions within one processing stage, while layers provide successive stages that refine the vectors further. The prediction at the end depends on these contributions being combined within stages and developed across stages.
4|**A dynamical system takes a state, applies a rule, and uses the resulting state as input again.** In the oscillator example, the state contains position **x** and velocity **v**. It begins with position one and velocity zero, and repeatedly updating those two quantities produces the changing motion. >> The new position uses the old velocity, and the new velocity uses that new position. Repeating these updates produces oscillation. || **Jordan’s recurrent network also feeds its output back into its input.** Plan units and state units feed a hidden layer, which produces an output. That output is copied into the state units, and their small self-loops preserve a fading trace of earlier states. The weights are reused at each time step, allowing recent outputs to influence the next output in a sequence of speech movements. >> **In the LLM comparison, depth plays the role of time.** Fifteen vectors enter the first layer and are transformed by its weights. The resulting vectors enter the next layer, where another transformation takes place. Following one number upward through the layers gives a sequence of changing values, which can be drawn as a curve even though it is not the oscillator’s cosine. || **The rules are organized differently in these systems.** The oscillator and Jordan network apply the same rule repeatedly as time advances. The LLM uses a separate set of weights at each layer, so its successive transformations follow the depth of the network. What connects the examples is the dependence of each new state on the state produced just before it. || The small stock-return graph traces Small, Medium and Large series over the same period. They fluctuate, rise and fall over the years, giving another example of quantities changing over time.

6|Which strings could be English words? The answer builds up in three rows. >> Twenty **one-syllable words**, like Don, mat, cup, fish and ring, each have a single consonant, a single vowel and a single consonant. >> So **a simple syllable in English can have a consonant, then a vowel, then a consonant**. || Next come **clusters**, consonants bunched together. >> Before the vowel they are **onsets**, as in split, flat, black, glad and stop. >> After the vowel they are **codas**, as in desk, box, help, milk and lamp. >> Each real word sits over a starred impossible twin, like *sblit, *lfat, *bnack, *desb and *hepl. || Many twins just swap the order of the letters. >> flat becomes *lfat, help becomes *hepl, lamp becomes *lapm. >> So **order matters**, and the allowed order flips around the vowel. >> **Only certain sequences are allowed before the vowel and after the vowel.** || Longer words string several syllables together. >> ba·na·na, win·dow, pump·kin, nap·kin, At·lan·tic, ath·lete, ad·mit and spa·ghet·ti all break into pieces. >> t·l, th·l and d·m are fine across a break, but no word can start with them, so *tlantic, *thlete and *dmit are out. >> ng can end a syllable, as in ring, but never start one, so *ngapkin is out too. || Put together, **a long word is a chain of syllables** that all follow the same rules. >> **t·l is fine across a break, but tl cannot start a syllable.** >> Knowing which sound sequences a language allows is **phonotactics**, and English speakers know it without ever being taught.
7|The pop quiz asks how **phonotactic knowledge can be revealed through GPT learning**. >> Each item is the beginning of an English word, and you **guess the next letter**. >> The starts are ra_, sp_, k_, skr_, m_, bram_, b_, f_ and sh_. >> People agree fast, and how much they agree shifts from item to item. || Right after a vowel, the field is wide open. >> After **ra_**, t, n, r, l and plenty of others all work, since **after a vowel almost anything** can follow. || At the very start of a word, the choices shrink. >> After **sp_**, **b_** or **f_**, only **l, r or a vowel** will do, never *spn, *bn or *fn. >> After **k_**, a vowel or **n**, as in knee, never *kt. >> After **sh_**, a vowel or **r**, as in shrimp, never *shb. || Some starts leave almost no room. >> After **skr_** or **m_**, only a vowel can come, never *skrl or *mb. >> After **bram_**, b is nearly certain, as in bramble, unless a new syllable begins. || And that is the point. **Guessing the next letter is predicting x₁₆.** >> A **GPT trained only on this game learns English sounds and spelling**. >> Its guesses are spread broad after ra_ and pile up on a few vowels after skr_.
