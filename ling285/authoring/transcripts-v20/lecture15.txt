2|**A neural network is a numerical processing machine.** It takes in numbers, processes them and makes a decision, and this one is a very simple speech recognizer that takes the formants measured from vowels in lab and decides which vowel was spoken. The two input neurons just take information from the environment, one taking F1 and the other taking F2. The five output neurons stand for done, dune, dean, Don and Dan. >> Between them are three hidden layers of 3, 2 and 4 neurons, called hidden because they are neither the input nor the output. || **The weights are the network's knowledge.** Every connection between two neurons has a weight, a positive or negative number, and everything the network knows about vowels is stored in these numbers. >> The network is fully connected, so every neuron sends a connection to every neuron in the next layer, which makes 40 weights in all. >> A positive weight pushes the next neuron up and a negative weight pushes it down, and the bigger the weight, the stronger the push. >> The weights leaving the formants are tiny, because formants are big numbers in the hundreds and thousands of hertz, so tiny weights turn them into modest values for the rest of the network. || **How many layers and neurons a network should have is not known in advance.** With no hidden layers at all, the network would most likely keep making mistakes. More numbers give it more freedom, so as those numbers improve, the network can capture something as hard as recognizing a vowel from just two numbers. >> In practice, people try the simplest design first, see how it performs, and add more.
3|**Forward propagation** is how the network makes a decision, sending the input forward through the layers one at a time. The example input is F1 of 320 and F2 of 2000, there are no extra constants added in, and each hidden neuron passes its sum straight on. **Each neuron computes an inner product**, multiplying each incoming number by the weight on that connection and adding the results. >> For the top neuron of the first hidden layer, F1 is multiplied by a small positive weight and F2 by a small negative weight. The F1 part adds a little and the F2 part takes away a bit more, so the neuron's activation lands just below zero. >> None of these calculations ever have to be done by hand. What matters is understanding what is happening. || **The same thing repeats at every layer.** The activations of one layer become the inputs to the next, which does more inner products with its own weights, until the network reaches the output. >> Each layer has to wait for the one before it, so a change at the input ripples all the way through. || **Knowledge has been reduced to positive and negative numbers, and making a decision uses nothing but multiplying and adding**, arithmetic from second grade. **Inference** means figuring out a decision, and almost all of its work is done by simple numbers that hold the knowledge and by addition and multiplication. >> This did not come out of nowhere. The brain is a chemical and electrical machine, and scientists discovered that its chemistry, with ions such as sodium, potassium and calcium, performs operations like addition and multiplication. || After the last layer, the final numbers are turned into a **probability distribution**, a set of numbers that add up to 1, and those numbers are the network's decision. The operation that does this is called **softmax**, and it just converts numbers into probabilities, so a bigger score always ends up as a bigger probability. >> Probabilities go from 0 to 1 and percentages go from 0 to 100, but they are the same idea. A value of 0.1 means a 10 percent chance that the formants were for that vowel. >> For 320 and 2000, the network gives done about 56 percent, much higher than any other vowel, so the network decides it heard done.

6|**This network is stupid, and all neural networks start out stupid**, because they start with random weights, which means they know nothing. This one decided done, but the formants 320 and 2000 were actually for /i/, as in dean. **A network becomes smarter only by being told the right answer**, which is given as the **desired output**. >> The desired output for dean is zero, zero, one, zero, zero, which says there is no chance it was done, dune, Don or Dan and a 100 percent chance it was dean. >> A target written with zeros and a single one is called a **one-hot encoding**. >> In practice, the network gets a table of data, where each row says that when a person produced these two formants, the vowel was a particular one. || The output the network actually produced is the **computed output**, and the gap between it and the desired output is the **error**. Here the network gave dean only about 8 percent when it should have given it 100 percent, so the error is large. **Backpropagation** is the algorithm that changes all the weights so the network becomes a little smarter. >> The goal is to pump up the probability of the right answer toward 1 and push the wrong ones down toward 0. >> Learning is gradual, just like stochastic gradient descent. The network sees one example, changes its weights a little, sees another and changes them a little more. >> This is why AI needs data centers, since modern systems have trillions of weights, and backpropagation nudges every one of them over and over for months. || The new weights are worked out **from the output backward**. First the connections into the outputs change, then the ones into the third hidden layer, then the second and then the first, while the activations from the forward pass stay as they were. >> The weight from the positive neuron into dean gets bigger, which adds more to dean. >> The weight from that same neuron into done gets smaller, which takes away from done. >> The weights leaving the formants barely change, because they use a much smaller step size to match the large hertz values.
7|For any weight, the question is the same. **If this weight goes up, will the error go up or down?** Two marked weights make the comparison. || **The weight from the last hidden layer to done is an easy problem.** Done's large probability comes from an inner product that includes this weight times a positive activation of about 1.57. If the weight went up, that contribution would grow, done's probability would go up, and the network would get more wrong, since done should be zero. >> So the weight should go down, because a smaller weight shrinks that contribution and pulls done's probability down. >> There is only one inner product between this weight and the probability, so the decision is crystal clear. || **The weight from F1 to the first hidden layer is a hard problem.** Changing it changes the activation of its first-layer neuron, which changes the second layer, which changes the third layer, which finally changes the probabilities. >> At every step, that change mixes with many other weights and activations, some pushing one way and some the other. >> Its effect on the decision is mediated by all the intermediate calculations, so just looking at it, there is no way to tell whether it should go up or down. Backpropagation still works it out.
8|**Why the weights are changed from the end backward is guaranteed to be on the exam.** The answer comes from comparing the last weights, labeled **W5**, with the first weights, labeled **W2**. **Improving W5 is easy**, because the output probabilities are directly determined by the last weights, and the error is very directly determined by them, so the error can be used right away to decide how to change them. || **Improving W2 is a much harder problem.** W2 affects its activations, which affect another two layers of activations along with other weights, so it is really hard to figure out how much blame W2 deserves for mistakes made all the way at the end. >> Moreover, the effect of W2 on the errors includes the effect of W5, since W5 is downstream of W2, so any change in W2 has to pass through W5 to reach the output. >> A strong exam answer explains that changing an early weight's influence on the probabilities is a much more involved, mediated set of calculations, while changing a last weight changes the probabilities right away. The last weights pose a simple, trivial problem, and the early weights pose a complex, big problem that already includes the effect of the later ones. || **When a problem contains smaller and smaller problems, the algorithm to use is dynamic programming.** Dynamic programming solves the easiest problem first and then uses its answer to solve the next bigger one, and it comes from Richard Bellman and Viterbi at USC. >> So **backpropagation is SGD plus dynamic programming**. SGD changes each weight gradually, a little at a time, and dynamic programming gives backpropagation its back, since it improves the last weights first and works toward the first. >> Nobody knew how to do this for neural networks until 1986, and Geoffrey Hinton later won a Nobel Prize for backpropagation, because there would be no AI without it. >> People used to say a messy, chemical brain could never do a clean forward pass followed by a clean backward pass, but research over the last ten years has found that single brain neurons work much like a forward-then-backward process.
9|To train the network, it has to be told **the desired output for every input**, and that information is given as **two matrices**, which are just tables of numbers. Both come from the class's own lab data, with about 110 rows, one for each recording. >> The input matrix has two columns, because the network takes two numbers in, F1 and F2. >> The target matrix has five columns, because the network decides among five vowels, and each row is a one-hot answer with a one for the true vowel. || **The rows must line up**, because row by row the two tables describe the same recording. If the first row of formants is 500 and 1500, the first row of the target says done, and the third row, 320 and 2000, is marked dean. >> If one table were reordered and not the other, the network would learn from the wrong answers. >> The target itself never changes. Training compares the network's computed output with it and changes only the weights.
10|A short **Python program** trains this network, and it never has to be written from scratch, since brackets and punctuation do not matter. What matters is what each line does. **The import lines bring in a library**, which is code that someone else already wrote, so a network can be described in just a few lines. >> Import torch means use the PyTorch library, and the second import brings in its neural network tools. These lines import into Python everything needed for doing inner products and backpropagation. >> The load lines read the two saved tables from files, the same way a file is loaded when it is double-clicked. || **nn.Sequential means the network is a sequence of layers**, one layer after another, which is every network built so far. **nn.Linear means a layer that does inner products**, multiplying and adding. >> The first linear layer takes two inputs and produces three outputs, the next takes three and produces two, then two to four, and finally four to five. >> The network has five layers but only four linear lines, because the input layer does no processing and just receives numbers. || The last lines are the only lines PyTorch needs for learning. **SGD** is stochastic gradient descent, here with a learning rate of 0.1, **loss** is the mistake, the gap between the computed and desired outputs, **backward** is backpropagation, and **step** actually changes the weights. >> The program runs one gradient step using all the rows together, and it starts from PyTorch's own default weights, so it would not reproduce the hand-picked numbers in the diagram.
11|**Neural networks did not come out of nowhere.** Their most basic features come from discoveries about animal brains. Neuroscientists discovered that there are neurons, so artificial networks have neurons, and they discovered that each neuron collects information from many other neurons, which is what the inner product does. || **Lord Edgar Adrian** won the Nobel Prize in 1932 for discovering that **neurons are nearly digital**, meaning they either fire or they don't fire. A real neuron's activation is basically off or on, while the vowel network's neurons have activations like minus 0.4 or 6.64 with no limit. >> The **sigmoid** is an activation function added to copy Adrian's discovery. It takes the inner product and turns it into a number between 0 and 1. >> If the inner product is large and positive, the sigmoid is near 1, and if it is large and negative, the sigmoid is basically 0. An inner product of minus 4 gives almost 0, and an inner product of 4 gives almost 1. >> So the sigmoid digitizes neural processing, copying the brain chemistry that keeps real neurons close to off or on. || **Animal perception reflects this**, since some things that seem alike are perceived as different and some things that are very different are perceived as the same. In the steep middle of the S curve, two close inputs come out far apart, and out on the flat ends, two very different inputs come out nearly the same. >> AI is duplicating animals' abilities. People often say AI has nothing to do with human cognition, but that is false, since a big reason it works is that it copies our own abilities using math as simple as multiplying and adding.
12|The sigmoid can be added to the vowel network **one hidden neuron at a time**, keeping the same input and every weight the same. Each hidden neuron switches from linear to sigmoid in layer order, and the outputs still go through softmax, so they stay probabilities that add up to 1. >> The first neuron to switch has an inner product just below zero, on the steep middle of the curve, so the sigmoid turns it into just under one half. The neuron now sends a positive number where it used to send a negative one. || **After each switch, everything after it is recalculated**, because later neurons get their inputs from earlier ones. So the old linear numbers cannot simply be run through the sigmoid one at a time, since each new value has to come from the updated layer before it. || As the neurons switch, **the network's answer moves**. At first it decides done with a clear majority, then done's lead shrinks until done and Don are nearly tied, then Don takes the lead, and then Dan does. >> With all nine hidden neurons on sigmoid, Dan is on top at about 32 percent, dean has risen to about 23 percent, and done has dropped to about 16 percent. >> Only the activation rule changed and no weight moved, so this is not learning. The decision changed completely, but dean still is not the top answer.
13|The program becomes a sigmoid network by adding **nn.Sigmoid** after each hidden layer, and nn.Sigmoid means apply the sigmoid, which makes the neurons digital. The sigmoid changes the values but not how many there are, so a layer that produces three numbers still produces three, and the network keeps its 2, 3, 2, 4 and 5 shape. >> The last linear layer has no sigmoid after it, because its five outputs go to the loss, which turns them into probabilities. >> The sigmoid squeezes each hidden neuron on its own toward off or on, while softmax turns all five final scores together into a decision that adds up to 1. >> In lab, the sigmoid can also be swapped for other functions, such as one called ReLU, to discover whether they make vowel recognition better or worse.
