2|This **neural network** simulates a very simple piece of human perception. It takes the two formants, F1 and F2, of an isolated vowel and decides which vowel it is, choosing among done, dune, dean, Don and Dan. Two input neurons take in the formants, three hidden layers of 3, 2 and 4 neurons process them, and five output neurons give the decision. >> Every neuron connects to every neuron in the next layer, so there are 40 weights in all. || **The weights are the network's knowledge.** Each one is a positive or negative number, so a positive weight pushes the next neuron up and a negative one pushes it down, and the bigger the weight, the stronger the push. >> At first the weights are random, so the network does not know anything and its decisions are stupid. >> The right answer is given as a probability distribution, such as zero, zero, one, zero, zero for a dean recording, meaning a 100 percent chance it was dean. >> That target is usually very different from what the stupid network produces at first, and the network learns by correcting the mistake between the two.
3|**Forward propagation** carries one input through the network to a decision. The example vowel has F1 of 320 and F2 of 2000, which is one person's /i/. **Every step is an inner product**, multiplying each incoming number by its weight and adding the results. >> For the top neuron of the first hidden layer, the F1 part adds a little and the F2 part takes away a little more, so its activation lands just below zero. >> Because those two weights point in opposite directions, a higher F1 pushes this neuron up while a higher F2 pushes it down. >> The other neurons do the same with their own weights, layer by layer, until the network reaches a decision. || The last numbers are turned into a **probability distribution**, a set of numbers that add up to 1, by an operation called **softmax**. Softmax makes every score positive and divides each by the total, so a bigger score always gives a bigger probability, and raising one vowel's score lowers the others' probabilities. >> With these weights, done gets the highest percentage, about 56 percent, so the network decides done. >> But the correct answer is dean, so the network's knowledge is wrong and it has to change its weights.

5|The vowel data from the class's own lab is plotted with F1 along one axis and F2 along the other, and **each vowel forms a cloud of points**, since the same vowel comes out a little differently every time. Some patterns are clear. /i/, as in dean, sits apart with a high F2 and a low F1, just as the theory predicts, and the vowel of Dan spreads toward high F1 values. || **But there is a lot of overlap.** The vowels of dune, Don and done crowd into the same region, so a new speaker whose formants land there could be any of the three. Some points are probably errors, but real data always has errors, so they stay in because that is what real life is like. >> If every vowel sat in its own separate spot, recognizing vowels would be easy. Instead, a network has to see the data many times to learn what really separates the vowels, and no setting of the weights can separate recordings that land on top of each other. || This overlap was discovered in the 1950s. **Spectrograms** were developed during World War II and kept secret by both sides, and once they became public, **Peterson and Barney** measured many speakers' vowels in 1953 and found this enormous overlap. >> For about 70 years people tried to write programs to solve it, including trying to normalize away the differences between speakers, and none of it worked. >> What finally worked, around 2011 or 2012, was a neural network with backpropagation. >> Everyone predicted that a static problem like two formants from one moment would be easy and that moving speech would be very hard, but everyone was wrong. Large language models deal with very dynamic information and work much better.

7|**Backpropagation** is the algorithm that changes all the weights so the network makes better decisions, and it is made of two algorithms. **Stochastic gradient descent** improves each weight gradually, the same way SGD improved an estimate of an average, and it has the same learning rate. **Dynamic programming** decides the order, so the last weights get improved first and the earlier ones after. || Comparing two outputs gives the error. The **computed output** is what the network produced, putting most of the probability on done and only about 8 percent on dean. The **desired output** is the right answer, with a one for dean and zeros everywhere else. >> The difference between them is the **error**, or **loss**, and more probability on dean means less error. >> The error says exactly how each output should move, so done's probability should go down, dean's should go up, and the others should go down. || **The weights are changed from the end backward.** First come the connections into the outputs, then into the third hidden layer, then the second and then the first, while the activations from the forward pass stay fixed and are reused. >> The weight from the positive neuron into dean gets bigger, the weights from the negative neurons into dean get smaller, and the weight from the positive neuron into done gets smaller. >> The weights leaving the formants barely move, because they use a much smaller step to match the large hertz values.
8|Two marked weights pose the same question, namely whether raising the weight would make the error go up or down. **The weights at the end of the network are much easier to change than the weights at the beginning.** || **The end weights are easy because they directly change the decision.** Done's large probability comes from multiplying a weight of 0.1 by a positive activation of 1.57, along with the other products feeding done. If that weight went up to something like 0.5, done's probability would go up, which is the exact opposite of what is needed. >> So that weight should go down, since any change to an end weight is directly, automatically and immediately reflected in the percentages. || **The beginning weights are hard because their effect is buried under many layers.** Changing a first-layer weight changes that layer's activations, which change the next layer's activations, which change the third layer, which finally change the percentages. >> Just looking at an early weight, there is no way to tell which direction it should move. Backpropagation still figures it out. >> This is the same trap as the greedy choice in dynamic programming, where picking the cheaper of two next steps without looking ahead can lead to the wrong answer.
9|**Dynamic programming says that if problems can be ordered by difficulty, solve the easiest first, then the next, and so on to the hardest.** Backpropagation follows exactly that order. The last weights are the easiest problem, because the output probabilities and the error are directly determined by them, so the error can be used right away. >> The first weights are the hardest problem, because they affect their activations, which affect another two layers of activations along with other weights, and their effect on the error already includes the effect of the later weights. || **Solving the end first makes the rest easier.** Changing the last weights first teaches something that makes the next layer's problem easier, and that makes the layer after it easy too, all the way back to the start. >> So backpropagation is Bellman and Viterbi dynamic programming combined with SGD, with SGD improving each weight a little at a time and dynamic programming saying to go from the end backward. || **Backpropagation is central to the world right now.** Geoffrey Hinton won the 2024 Nobel Prize in Physics for it, and much of the world economy now revolves around this idea. >> Modern systems have about 6 trillion weights, and data centers run backpropagation on all of them, step by step, for months, which is why data centers are now a public issue. >> These ideas come from physics and are closely tied to the dynamical systems behind acoustics and masses and springs.
10|To train the network, it gets **two matrices**, which are tables of numbers with about 110 rows, one for each student recording. The input matrix holds each recording's F1 and F2, and the target matrix holds a one-hot answer for each recording. >> Each row in one table goes with the same row in the other, so the row with 320 and 2000 is paired with dean. || **Learning picks rows one at a time.** It takes one row, such as 800 and 1700, uses its weights to calculate a decision, and changes its weights if that decision differs from the desired answer, starting from the last weights. Then it picks another row and does the same. >> **If the network already gets a row right, there is no error, so there is nothing to learn from that row.** That can be a serious problem, since a network can get rows right by accident over and over and stop learning before it learns the real pattern. || **Children learning English go through the same problem**, as Carol Chomsky discovered in the early 1960s. At first, very young children say go and went correctly, because they are just memorizing what they hear. >> Then they notice the real pattern, that most English verbs add ed for the past, as in jump and jumped, and they start saying goed. >> Only later do they learn that some verbs are exceptions and get both the regular and the exceptional verbs right. Neural networks also can just memorize weights that give the right answers without learning the pattern, which is what makes learning so difficult.
11|A short **Python program** builds and trains the network, and it never has to be written from scratch, since brackets and dots do not matter. **The import lines bring in libraries.** Margaret Hamilton, who designed the software for Apollo 11, created the idea of software, where different groups write programs for one job and others use them without knowing how they work inside. >> Until about 2014, everyone doing AI had to write their own backpropagation code, and around 2015 Facebook released PyTorch and Google released TensorFlow. >> The import lines import into Python everything for doing inner products, backpropagation and related work, which is why the whole training program fits on one page. || **Sequential means a neural network that is a sequence of layers.** All the networks built so far are a sequence of layers, while a large language model is a network that is not just a sequence of layers. **Each Linear line is one processing layer**, a layer that has weights and does inner products with the incoming information. >> The first linear line says it receives information from two neurons and has three neurons, and the following lines go from three to two, two to four, and four to five. >> The network has five layers but only four lines, because the input layer does no processing. || **The last lines are the only lines PyTorch needs for learning.** SGD is stochastic gradient descent and lr is the learning rate, here 0.1. **A bigger learning rate learns a lot faster but is less accurate, while a smaller one is more accurate but learns much slower.** >> Loss is the mistake, so the network calculates its mistakes and learns from them, and backward is backpropagation. >> Nothing changes until step is called, which is when the weights actually change.
12|**Neural networks do not come out of nowhere.** Their basic features come from discoveries about animal brains, since scientists found that brains have neurons and that each neuron collects information from many other neurons, which is the inner product. **Lord Edgar Adrian** won the Nobel Prize in 1932 for discovering that **neurons are nearly digital**, meaning they either fire or they don't fire. >> A real neuron's activation is off or on rather than any number, while the vowel network's neurons have activations like minus 0.4, 6.64 and 1.57. || **The sigmoid** is an activation function added to networks to copy Adrian's discovery. It takes a neuron's linear activation, its inner product, and turns it into a number between 0 and 1. >> If the inner product is large and positive the sigmoid is near 1, and if it is large and negative the sigmoid is basically 0, so minus 4, minus 6 or minus 1000 all give almost 0, while 4, 6 or 100 all give almost 1. >> So the sigmoid digitizes neural processing, copying the brain chemistry that keeps real neurons close to off or on. || Near zero the curve is steep, so a small change in the inner product makes a big change in the output, while far from zero it is flat, so even big changes barely matter. **Animal perception reflects this**, since some things that seem alike are perceived as different and some things that are very different are perceived as the same. >> AI is duplicating animals' abilities. People will say AI has nothing to do with human cognition, but that is false, and a big reason it works is that it copies our own abilities.
13|The sigmoid is added **one hidden neuron at a time**, while the input and every weight stay the same. The first neuron to switch has an inner product just below zero, on the steep middle of the curve, so it comes out just under one half and now sends a positive number instead of a negative one. >> After each switch, everything downstream is recalculated, because later neurons depend on earlier ones. >> So the sigmoid network cannot be made by running the old linear numbers through the sigmoid one at a time. || With all nine hidden neurons on sigmoid, every hidden activation sits between 0 and 1, and **Dan becomes the top answer**, at about 32 percent, while dean rises to about 23 percent and done drops to about 16 percent. >> Only the activation rule changed and no weight moved, so this is not learning. >> The decision changed completely, but dean is still not the top answer.
14|**nn.Sigmoid** is added after each of the first three linear layers, and it means apply the sigmoid, which makes the neurons digital. The layer sizes stay 2, 3, 2, 4 and 5, because the sigmoid changes values, not how many there are. >> The last linear layer has no sigmoid, because its five scores go to the loss, which turns them into probabilities. >> The sigmoid squeezes each hidden neuron on its own, while softmax turns all five final scores together into a decision that adds up to 1. >> The training lines and the learning rate of 0.1 stay the same.
15|Training runs **thousands of times**, much more than the few dozen steps needed to average a list of numbers. Each full pass of learning is called an **epoch**, and this run uses 2000 epochs, starting from random weights. >> After every epoch, accuracy is measured without training, with the vowel that gets the largest score counted as the network's answer. Accuracy is the percentage of recordings it gets right, and these are the same recordings it learns from. || **Accuracy starts at 20 percent, which is chance.** At the start the weights are random, so the network knows nothing, but it still is not at zero, because with five vowels a random guess is right one time in five. >> Chance means how often someone would be right just by guessing randomly, so with five possible answers chance is 20 percent. || **After about 200 epochs, accuracy jumps up into the 40s**, so the network is learning something. It dips back toward chance for a moment, recovers, and then levels off at about 45 percent after a few hundred epochs. >> The curve comes from an equivalent program in NumPy, another numerical library, because PyTorch was not available where the curve was made.
16|The same training is run **ten times**, each time starting from different random weights, and everything else is identical. All ten start near 20 percent, some leave chance quickly and others stay flat longer, and several briefly drop back toward chance. After a few hundred epochs they come together, and **all ten finish at the same accuracy, about 45 percent**. >> **Different starting weights change the path, not the destination**, because the learning process is so similar each time. || **The network levels off well below 100 percent because the data overlap so much.** About 45 percent is clearly better than chance, so the network has learned something, but it is still pretty low, because AI is not magic. >> If a person had to name the vowel for formants landing where several vowels overlap, they would have to squint hard and might still guess wrong. If the decision is very hard for humans, it is not surprising that it is hard for machines. >> The limit comes from two formants not being enough to separate dune, Don and done, not from unlucky starting weights, so trying more starting points would not help. >> In lab, different designs can be tested by adding or removing layers, changing the number of neurons, or swapping in the sigmoid or other functions, to discover whether each change improves that accuracy or makes it worse.
