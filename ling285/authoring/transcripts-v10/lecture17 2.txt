2|The vowel network stands for neural networks from **1943 to 1986**. >> Two formants pass through weighted hidden layers to five word outputs. >> The weights are the same illustrative signed weights as before. || **McCulloch and Pitts (1943)** open the period. >> **“A Logical Calculus of the Ideas Immanent in Nervous Activity”** builds on the **“all-or-none” character of nervous activity**. >> It treats neural events with propositional logic. || The **Parallel Distributed Processing** volumes of **1986** close it. >> They brought trainable networks of many simple connected units into wide use. || **Given some static vector of formants, the NN could make a decision about a few possible categories.** >> A static vector is one fixed set of numbers from one moment. >> The network turns that single input into one of five words. || **Human cognition is far more complex.** >> Speech and sentences are sequences, and what comes next depends on what came before. >> Handling sequences requires networks that keep track of earlier inputs, the step taken by recurrent networks and LLMs.
3|In **1985, Michael Jordan developed recurrent neural networks** for **speech production**. >> That work led to **LLMs** and then **agentic AI**. >> The photo is Michael Jordan. || The network has plan, hidden, output and state units. >> **Plan units** say which sequence to produce. >> **Hidden units** combine, and **output units** respond. >> Outputs loop back into **state units**, and each state unit loops back to itself. || The loops make the network **recurrent**. >> State units carry a trace of the latest outputs. >> Each new output depends on the plan and on what the network just produced. || **Performance on /istrstry/** plots eight articulatory features over 32 time steps. >> **Voice, Place, Sonorant, Sibilant, Nasal, Height, Back and Round** each get a row. >> Sibilant peaks where the s sounds occur, and Nasal and Height hold steady. || **Round** rises early and stays high. >> A feature spreads across several sounds instead of flipping for each one. >> Feeding outputs back makes successive outputs blend, an idea that continues into today’s language models.
4|The page builds from **one neuron** to an **agentic system**. >> One neuron multiplies a vector **x** by weights **w** and sums the products into one number **y**. >> **Vector in, one number out**, an inner product. || A **network** of 4, 3, 4 and 5 units uses **W₁, W₂ and W₃**. >> Each W maps one vector to the next. >> The output is a **decision vector**, so it is **vector in, decision vector out**. || An **LLM** takes **vectors 1 through 15**, one per token, up through **5 layers** of W blocks. >> Six colors mark six kinds of weight sets. >> **Vector 16** comes out on top as a **PDF**, a probability distribution over the next token. >> It is **a dynamical system with many vectors in and one decision vector out**. || An **agentic system is a graph of LLMs**. >> **Outline, Write, Critic, Revise and Final** LLMs run in sequence. >> A **loop** between Critic and Revise sends work back for more revision. || Two operations run underneath everything. >> **Inference is inner products.** >> **Learning is SGD plus DP**, gradient descent organized by backpropagation’s dynamic programming.

6|**Which sequences can be English words?** Three rows build the answer. >> Twenty **one-syllable words** like Don, mat, sit, cup and fish each have one consonant, one vowel and one consonant. >> **A simple syllable in English can have a consonant, then a vowel, then a consonant.** || **Clusters** come before the vowel as **onsets** and after it as **codas**. >> Onsets appear in split, flat, black, glad and stop. >> Codas appear in desk, box, help, milk and lamp. >> Each has a starred impossible twin, *sblit, *lfat, *bnack, *dlad, *tsop, *desb, *bokp, *hepl, *mikl, *lapm. || Order decides which clusters are allowed. >> flat and *lfat, help and *hepl, lamp and *lapm use the same letters in different orders. >> The allowed order mirrors around the vowel. >> **Only certain sequences are allowed before the vowel and after the vowel.** || Long words are built from several syllables. >> ba·na·na, win·dow, pump·kin, nap·kin, At·lan·tic, ath·lete, ad·mit and spa·ghet·ti all break into syllables. >> t·l, th·l and d·m sit across breaks, so *tlantic, *thlete and *dmit fail as word starts. >> ng ends a syllable, as in ring, so *ngapkin fails. || **A long word is a chain of syllables**, each following the same rules. >> **t·l is fine across a break, but tl cannot start a syllable.** >> This sound-sequence knowledge is **phonotactics**, and speakers know it without instruction.
7|The quiz reveals **phonotactic knowledge through GPT learning**. >> Each item starts an English word, and the task is to **guess the next letter**. >> The starts are ra_, sp_, k_, skr_, m_, bram_, b_, f_ and sh_. || After a vowel, many letters fit. >> **ra_** takes t, n, r, l and more, since **after a vowel almost anything** can follow. || Word starts allow only a few letters. >> **sp_**, **b_** and **f_** take **l, r or a vowel**, never *spn, *bn or *fn. >> **k_** takes a vowel or **n**, as in knee, never *kt. >> **sh_** takes a vowel or **r**, as in shrimp, never *shb. || Some starts leave one kind of answer. >> **skr_** and **m_** take only a vowel, never *skrl or *mb. >> **bram_** nearly forces b, as in bramble, unless a new syllable starts. || **Guessing the next letter is predicting x₁₆.** >> A **GPT trained only on this game learns English sounds and spelling**. >> Its distribution is flat after fa_ and sharply peaked after skr_.
