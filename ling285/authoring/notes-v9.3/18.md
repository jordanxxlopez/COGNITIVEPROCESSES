## p2
- Everything in modern AI grows from **one very simple idea**. A **neuron** takes information from other neurons, multiplies each input by its weight, and adds them up. This is the **inner product**, and it stands in for the electrical and chemical signals that neurons send each other. People who move science forward usually start from very simple ideas like this one and then repeat them many times over.
  - A **neural network** repeats the inner product layer after layer. It takes a vector in and gives a **decision** out. Even something as complex as a person making a decision can be built from inner products and a function like the sigmoid, combined many times.
  - But a network that makes one **static decision**, such as hearing one vowel from two formants, cannot capture thinking that **happens over time**.
- **Language depends on connections between words that are far apart.** In "the dog that my parents, who I love very much, who live in a state far, far away," the next word is **barks**, not bark.
  - **Barks** goes with the singular word **dog**, no matter how many other words come in between, even plural words like parents.
  - No one teaches this rule directly. Speakers pick it up from the language around them. An LLM learns it the same way, from data. It uses its weights to do inner products, then more inner products, until it predicts barks.
  - English sentence structure, called **syntax**, is so complicated that many linguists spend their whole careers studying it. That is why an LLM needs so many layers of calculation.
- **LLMs can work with many languages and many kinds of input.** The first use of LLMs, in 2017, was **translation** between languages. Translation is now nearly solved for hundreds of languages.
  - A system trained on several languages, such as English, Dutch and Japanese, learns how words go together in general. So it also gets good at very different languages, such as Navajo.
  - **Multimodal** systems connect different kinds of input, such as text, speech and images. So they can write a caption for a photo or create an image from a spoken description.
- **Nobody fully understands what all the weights are doing.** Over about 75 years, people took something that worked a little, changed it so it worked a little better, and kept going. This is like how dogs were bred over a few hundred years into today's breeds. Researchers around the world are now trying to figure out what the weights do. Part of the reason is to build much smaller, less wasteful systems.
- **An agentic system is a team of LLMs that talk to each other in English.** An outline LLM plans the answer, and a writing LLM writes it. A critic LLM checks whether each statement follows from the one before it, and a revision LLM goes back and forth with the critic. Sometimes a **controller** agent passes the work from one LLM to the next.
  - The agents also **know computer languages**, such as Python and database languages, because they were trained to predict whole programs too.
  - Once each LLM is trained, its weights usually **stop changing** while the agents work together. Some new systems are starting to learn their own connections.
  - Agents share a **common memory**, where they can write and read information. This shared memory gives them a lot of their power. It is also dangerous, because it lets them coordinate in ways nobody planned.
  - The same tools can also do good work. One agentic system acts as a patient teacher for a Native American language that is nearly lost, even though there is far too little text in that language to train an ordinary LLM.

## p3
- **Predicting the next word is so hard that an LLM needs many layers, and each layer needs many heads working side by side.** A **head** is one expert. In each layer, the knowledge from all the heads is combined to make **improved vectors**. Then the next layer does the same thing again.
  - This is a question for the exam, so the structure matters. **Layers go one after another, from the input to the output. Heads sit side by side inside each layer.**
- **A classroom comparison explains heads and layers.** Imagine trying to improve yourself by visiting a series of classes, one class after another.
  - In the first class, every student gives you their own opinion on how to improve. Each student is like a **head**, an expert with its own view.
  - You then **combine** all of those opinions into one improved version of yourself. Combining the heads' opinions is what a layer does.
  - Then you go to the next class and do the same thing again. **The classes are the layers.**
  - In plain terms, layers give an LLM its depth, which is one round of improvement after another. Heads give it width, which is many experts asked at the same time within each round.
- **Each head is a set of weights**, and an expert's knowledge is in its weights. Every head in every layer learns how to improve the vectors, so that at the very end the next word can be predicted.
  - Large systems have **a hundred or more layers** and about **a hundred heads** in each layer. That shows how complicated language, vision and the other tasks really are.
  - The heads and layers are trained the same way as everything else. A sentence like "the dog that ... barks" is taken from text, and the system predicts the next word. If it predicts the wrong word, **every head in every layer** adjusts its weights through backpropagation, so the next prediction is closer to barks.
  - Training at this size uses enormous resources. In some states, a large share of the water goes to the data centers that run this training.

## p4
- **A dynamical system is a rule that is fed its own output again and again.** Numbers go in, the rule acts on them, and numbers come out. Then the output is fed back in as the next input, over and over. The goal is to understand this general structure, not to memorize formulas.
  - In the **harmonic oscillator**, the two numbers are the position x and the velocity v. If x starts at one and v starts at zero, the first step leaves x the same and makes v go down.
  - x and v **take turns**. First the new x is calculated from the old v. Then the new v is calculated from that new x. Step by step, the rule draws a **cosine** curve for x.
  - Very different fields, such as finance, use the same idea with different rules. Stock prices are modeled with equations that feed back on themselves, although the real market never follows them exactly.
- **Jordan's network combined neural networks with dynamical systems.** Speech production changes over time, so Jordan designed a network whose **output is copied back into its state units**. The state units also keep a fading copy of their own past values.
  - **Plan units** and **state units** feed the hidden layer. The hidden layer feeds the output, and the output loops back into the state units. The same weights are used at every step.
  - After more than **thirty years of small improvements**, this idea became the **LLM**.
- **In an LLM, each layer is the rule.** Each layer applies its weights to every vector, and the next layer works on the result. So **going up through the layers plays the role of time**. If you follow one number up through the layers, it traces a curve, much like the oscillator's curve, though not an exact cosine.
  - So an LLM is like a recurrent network that has been laid out layer by layer. This is just like how the spring's motion was laid out step by step when it was calculated on a computer.
  - The rule in each layer is the weights of its heads. Those weights are learned through backpropagation by predicting the next word.
  - Agentic systems also contain loops, such as the loop between the critic and the revision LLM. So dynamical systems show up at every level of AI.
  - The math of inner products that LLMs depend on was first studied deeply in **quantum mechanics**, about a hundred years ago. So physics and AI are closely connected in more than one way.

## p5
- An LLM is given **15 vectors** and asked to predict the **16th**. The vectors can come from anywhere, because the machine only ever sees lists of numbers.
  - They can be **15 words** of a sentence, such as "The cat that the dog chased ran up the old tree and sat on the," with the next word missing.
  - They can be **15 frames of a spectrogram**, with the next slice of speech missing.
  - They can be **15 patches of an image**, read row by row, with the bottom-right patch missing.
  - They can be **15 amino acids** in a protein. In the B chain of insulin, the amino acid that comes after the first fifteen is the one written Y.
- **The same design and the same prediction game work for language, speech, images and proteins.** Whatever the vectors stand for, the job is always to predict what comes next in the sequence.

## p6
- English has about 30,000 words, so training an LLM on words takes enormous amounts of data, money and energy. But speakers also know a much smaller system, which is the rules for how vowels and consonants can follow each other to make words. That system uses **only a few dozen sounds**, so an LLM for it can be small enough to study closely.
- **A simple English syllable is a consonant, then a vowel, then a consonant**, as in Don, sit, shave, cup, dog and fish. The pattern is about sounds, so the silent e in shave does not count.
  - English also allows **clusters**, as in split, flat, black, glad, desk, help and milk. Only certain clusters are allowed, so **sblit**, **lfat**, **desb** and **lapm** are impossible. A product named "desb" would sound un-English right away.
  - Long words are chains of syllables. **Atlantic** is fine, because t and l are on opposite sides of a syllable break. But **tlantic** is impossible, because tl cannot start an English syllable.
- **Every language has its own rules for which sounds can follow which**, and speakers pick them up without being taught.
  - **Mandarin** allows only nasal sounds at the end of a syllable, so words like mat, sit and shave are impossible in Mandarin. **Cantonese** also allows a final p, as in cup.
  - **Russian and Polish** allow clusters like zb or dl at the start of a word, which English never allows.
  - **Spanish** does not allow a word to start with s and t together. So Spanish speakers add an e to the start of a word like stadium, which keeps each syllable simple.

## p7
- Guessing the next letter of an English word shows directly what speakers know about sounds. **After a vowel, almost any letter can come next.** But **at the start of a word, the choices narrow sharply**.
  - After **sp**, only l, r or a vowel can come. After **skr**, or after an **m** at the start of a word, only a vowel can come.
  - After **k**, a vowel or n can come, as in knee. After **sh**, a vowel or r can come, as in shrimp.
- **Guessing the next letter is predicting the 16th vector.** A GPT that only plays this game learns English sounds and spelling. After a vowel, its predicted probability distribution is **flat**. After skr, the distribution is **sharply peaked**, because English allows almost nothing else there.
  - In plain terms, the knowledge is in the shape of the distribution. It is spread out where English allows many choices, and piled up where English allows only a few.

## p8
- You can build an LLM that learns English syllables by **describing it in plain English** to an agentic system, instead of programming it by hand. The request asked for **five layers**, **four heads in each layer**, and **input vectors that are 64 numbers long**.
  - It asked the system to pick **1000 English words at random** and train the LLM on them. Training meant taking each letter, trying to **predict the next letter**, and then improving the weights to predict better.
  - It also asked the system to show **ten generated words after each step of training**, to reveal what the LLM knew about English at that point.
- The agentic system translated the request into its own technical terms. It built a small **character-level transformer**, which is another name for an LLM that works one letter at a time, with **attention heads**.
  - **Attention** means a head looks over the rest of the sequence to decide which items before it matter. This is the same way predicting barks requires paying attention to dog.
  - The system chose to train on **pronunciations** instead of spellings, so the silent e in shave would not confuse it. It also wrote the program in Python on its own.
- The results show how hard the problem is. After training on 1000 words, the generated words were **still mostly gibberish**, with maybe a few vowels starting to show up in the right places. The suggested next step was to train on **10,000 words** for many more steps.
  - Deciding which sounds can follow which seems easy for any speaker, but it is not easy even for an LLM.
- This way of working has a name.
  - **Software 1.0** is writing programs in a programming language such as Python or C.
  - **Software 2.0** is giving a neural network input data and output data, so the program becomes the network's **weights**, which predict the outputs from the inputs.
  - **Software 3.0** is using an agentic system, which is a set of LLMs talking to each other and to the user, to build and run a program. Doing this with plain English instructions is called **vibe coding**. It means someone with a good idea no longer needs to hire a programmer to build it.
- The first attempt at this kind of problem was **Claude Shannon's 1948 paper, "A Mathematical Theory of Communication."** Shannon worked by hand and produced sequences of letters that got closer and closer to English. They went from random strings of consonants, to strings with vowels, to strings with real short words.
  - That paper started **information theory**, one of the most important fields in engineering. Information theory is still important for LLMs today.
  - **Viterbi**, one of the people who developed dynamic programming, published his most famous work in an information theory journal. So the ideas behind backpropagation and LLMs share the same roots.
