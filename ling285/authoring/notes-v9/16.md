## p2
- This **neural network** simulates a very simple piece of human perception. It takes the **two formants**, F1 and F2, of an isolated vowel and decides which of five words it heard, with 2 input neurons, hidden layers of 3, 2 and 4 neurons, and 5 output neurons.
- **The weights are the network's knowledge.** The network is told the right answer as a probability distribution, so for a speaker's /i/ it is told **0, 0, 1, 0, 0**. At first the weights are random, so the distribution it produces is very different, and the network learns by correcting that **mistake**.

## p3
- **Forward propagation** carries the input through the network. With **F1 of 320 and F2 of 2000**, each neuron in the first hidden layer multiplies each formant by its weight and adds the results, and each later layer does the same with the activations before it.
  - With random weights, the network gives more than half of its probability to **done**, so it decides it heard done when the answer is dean.
- To fix the mistake, **all the weights must change**, using **backpropagation**, which is made of **stochastic gradient descent** and **dynamic programming**.

## p4
- **Changing a weight at the very end is directly and immediately reflected in the output probabilities**, which are the network's decision.
  - The probability of done comes partly from a weight of 0.1 times an activation of about 1.57. Raising that weight would raise the probability of done, the opposite of what is wanted, so it should go **down**.
- **Changing a weight near the input sets off a chain of changes** through every hidden layer before it reaches the decision, so deciding how to change it is a very hard problem.
  - That is why the weights at the end are the easier ones to change, and why backpropagation fixes them first.

## p5
- The real formant data from the class shows why AI is hard. Each recording is a dot, with **F1 along the horizontal axis** and **F2 up the vertical axis**, 525 dots in all, 105 for each vowel.
  - The data do show a pattern. The **/i/ dots sit high**, with a **high F2 and a low F1**, just as the theory predicts.
  - But there is **enormous overlap**. Many /æ/ dots sit among the /i/ dots, and the /u/, /a/ and schwa clouds pile on top of one another.
- **If the vowels sat in separate clusters, AI would be easy.** Because they overlap, many points are ambiguous, and for a new speaker in the middle of the overlap the best answer is only the vowel whose dots are most common there.
  - Removing the differences between speakers, called **normalization**, was tried for about seventy years without success.
  - This overlap was first found in the early 1950s by **Peterson and Barney**, and good speech recognition only arrived around 2011 or 2012, with neural networks trained by backpropagation.

## p7
- **Stochastic gradient descent** is the same algorithm used to improve an average from data, now used to improve every weight, with the same **learning rate** and the same tradeoff between learning fast and learning accurately. **Dynamic programming** supplies the order, so the weights at the end are improved first and the hardest problem is solved last.
  - The error says which way each output should move. Done, at about 56 percent, should go down, dean should go up, and the others should go down.

## p8
- For the last weights, it is easy to tell whether each should go up or down, because one inner product connects them to the decision. The network said done when the answer was dean, so any last weight that pushes done up should be **lowered**.

## p9
- **Backpropagation changes the last weights first, then the ones before them, and so on to the first.** Each later problem is easier because something has already been learned from the problems solved before it.
  - Modern systems apply this to about **six trillion weights**, which is what the huge data centers are doing.
  - **Geoffrey Hinton** won the **2024 Nobel Prize in Physics** for backpropagation, which has roots in physics through dynamical systems.
  - In plain terms, the blame for a mistake is easiest to assign to the weights closest to the mistake, and that blame is then passed backward to the weights that came before.

## p10
- Training uses **two matrices** of numbers, one with **F1 and F2** for each recording and one with the matching row of **zeros and a single one** for the true vowel. Learning picks a row, computes the decision, compares it with the true answer, and changes the weights if the decision is wrong.
- **If the network makes the right decision, there is no error, so there is nothing to learn.** A network can keep getting the right answer by **memorizing** its data without learning the pattern underneath it.
  - Children learning English show the same thing, as **Carol Chomsky** observed. They first say **went** correctly from memory, then learn the regular pattern and say **goed**, and only later learn that went is an **exception**.
  - In plain terms, getting the right answer early can come from memory, and real learning sometimes shows up as new mistakes.

## p11
- **The import lines bring into Python the programs for doing inner products, backpropagation and related work**, so none of that has to be written by hand. This works because of **libraries**, an idea that goes back to **Margaret Hamilton's** software for **Apollo 11**, and around 2015 **Facebook** released **PyTorch** and **Google** released **TensorFlow**.
- **Sequential means a network that is a sequence of layers**, and each **Linear** line is one processing layer that does inner products. **nn.Linear(2, 3)** says "I receive information from 2 neurons, and I have 3 neurons," and the input layer gets no line because it does no processing.
- **SGD** is stochastic gradient descent, and **lr** is the **learning rate**, set here to 0.1. **A higher learning rate learns much faster but less accurately, and a lower learning rate learns more accurately but much more slowly.**
  - So changing the learning rate from 0.1 to 0.3 makes the network **learn faster**, but its **accuracy goes down**.
  - **Loss** is the **mistake**, **backward** is **backpropagation**, and **step** updates the weights.

## p12
- **Lord Edgar Adrian** discovered in the 1920s that **neurons are nearly digital**, either **firing** or **not firing**. The **sigmoid** works like this discovery, taking an inner product and giving back a number between zero and one.
  - An inner product of **minus 4**, minus 6 or minus 1000 gives about **zero**, so the neuron is **off**, and one of **4**, 6 or 100 gives about **one**, so the neuron is **on**.
  - So the sigmoid **digitizes** neural processing, the way brain chemistry does.
- **Some things that seem alike are perceived as different, and some things that are very different are perceived as the same**, and the sigmoid captures both.

## p13
- Applying the sigmoid one hidden neuron at a time changes the whole calculation downstream, because every later activation is recalculated. With the sigmoid on all nine hidden neurons and the same random weights, the network's choice moves from done to Dan, so it is still wrong until it is trained.

## p14
- In the program, **nn.Sigmoid** is added after each hidden linear layer, and the last layer gets no sigmoid because its outputs go into the loss calculation. The sigmoid can also be replaced by functions such as **ReLU** to test whether recognition improves.
  - **AI is duplicating abilities that animals have.** Its most fundamental ideas come from discoveries about how brains work, with computer scientists adding ideas of their own on top.

## p15
- The full training program runs **2000 updates** with a learning rate of 0.1 and records the **accuracy**, the percent of recordings classified correctly, after every update.
- **The accuracy starts at 20 percent.** With random weights the network knows nothing, but with **five vowels**, even a random guess is right **one time out of five**, which is called **chance**.
  - With **ten categories**, chance would be **10 percent**.
- After a while the accuracy **jumps up to about 40 percent**, so the network is learning something, and then it **levels off** near **45 percent**. Each pass of learning is called an **epoch**.

## p16
- Training was repeated **ten times**, each time from a **different set of random weights**, called a **seed**. The runs take **different paths**, one staying at chance for about 500 epochs and another jumping up early, but **all ten end at the same accuracy**, close to 45 percent.
  - Children learning language are similar. Homes that talk mostly about sports or mostly about politics give children different words, yet by about age four they speak the same language.
- **The network levels off near 40 percent, not 100, because the data overlap so much.** For a point in the middle of the overlap, even a person would have to guess, and AI is not magic.
  - Adding or removing layers, or changing the number of neurons, tests whether the 40 percent can be improved.
