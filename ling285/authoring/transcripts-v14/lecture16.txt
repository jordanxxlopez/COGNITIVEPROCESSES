5|The scatterplot shows all **525** vowel tokens, **105** per vowel, with **F1** across and **F2** up, in hertz. >> Each dot is one recording, and its color gives the correct word. >> These are the same two numbers the network receives. || Five colors match the five outputs. >> Red **i (dean)**, magenta **ae (Dan)**, blue **u (dune)**, cyan **a (Don)**, green **schwa (done)**. >> Each vowel forms a cloud, since its formants vary from token to token. >> No tokens were removed, so a few strays sit far from their clouds. || **i** and **ae** stand out. >> **i** sits high on F2, mostly above about 2000 Hz, with a low F1. >> **ae** spreads toward high F1, past 800 Hz. || **u**, **a** and **schwa** overlap. >> They crowd into about 300 to 800 Hz in F1 and 800 to 1600 Hz in F2. >> A token there could belong to any of the three. || Overlap limits any classifier that uses only F1 and F2. >> Tokens in the same place look identical to the network. >> No rule based on these two numbers can label them all correctly, so accuracy stays well below perfect.

15|The code trains the all-linear vowel network from one starting point, fixed by **torch.manual_seed(0)**. >> Four **nn.Linear** layers with **bias=False** keep the sizes 2, 3, 2, 4 and 5, with no activations. >> Formants are divided by **1000**, turning hertz into kilohertz. >> **argmax(1)** gives each token’s correct class number. || Training uses **CrossEntropyLoss** and **SGD** at **learning rate 0.1** for **2,000 epochs**. >> Each epoch clears gradients, computes the loss on all tokens, backpropagates and steps once. >> So each epoch is one **full-batch update**. || Accuracy is checked after every update. >> The largest score is the network’s answer. >> Accuracy is the share of the **525** training tokens it gets right, so this is **training accuracy**. || The curve starts near **20%** and ends at **44.95%**. >> It stays flat for about 200 updates, then climbs into the 40s. >> A sharp dip near update 390 recovers quickly. >> After about 450 updates it is flat, at 236 of 525 tokens correct. || The curve comes from an equivalent **NumPy** run, since PyTorch was unavailable where it was made.
16|The training repeats with **seeds 0 through 9**, each with a fresh model and optimizer. >> Only the **initialization**, the starting weights, changes. >> Data, scaling, loss, learning rate and the 2,000 updates are identical. || All ten runs start near **20%** and then diverge. >> Some climb within 100 updates, others stay flat for 200 or more. >> Several dip back toward 20% briefly, and peaks reach close to **47%**. || The runs then converge. >> The fastest settle by about 350 updates, the slowest by about 1,000. >> **All ten finish at 44.95%**, and the curves overlap. || Starting weights change the path but not the end point. >> More seeds would not raise the final accuracy. >> The limit comes from the network and the overlapping vowel data. || The curves are **NumPy** reference runs. >> Equal seed numbers do not give equal PyTorch weights, so individual PyTorch lines would differ.
