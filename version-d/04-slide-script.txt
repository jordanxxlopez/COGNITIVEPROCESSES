2|**Attention is the ability to focus on specific stimuli or locations in our environment.** **Selective attention** means attending to one thing while ignoring others; **divided attention** means paying attention to more than one thing at a time.||**Distraction** is one stimulus interfering with the processing of another stimulus. **Attentional capture** is rapid shifting of attention, usually caused by a **loud noise, bright light, or sudden movement**.||These distinguish deliberate allocation of attention from interference and shifts triggered by competing input.
3|**Selective attention is the ability to focus on one message and ignore others.** We do not attend to a large fraction of the information in the environment.||**We filter out some information and promote other information for further processing.** A message can therefore be physically present without receiving the same processing as the attended stream.||Selection makes some information more available for the task while limiting competing content. The attended stream is promoted for further processing while other content is filtered.
4|**Colin Cherry (1953)** used **dichotic listening**: **one message is presented to the left ear and another to the right ear**.||The participant **“shadows” one message to ensure attention to that message**, repeating it aloud as it arrives. This makes the designated stream’s task priority observable.||The question is whether listeners can **completely filter out the message to the unattended ear and attend only to the shadowed message**. Researchers test what information from the unattended stream remains available.
5|In dichotic listening, **participants could not report the content of the message in the unattended ear**, but **knew there was a message and knew the speaker’s gender**. This concerns selective listening in the **cocktail-party effect**.||**Information in the unattended ear is being processed at some level.** A **change in gender** or a **change to a tone** can be noticed.||Physical properties can therefore remain available when message content is not reportable. Failing to report meaning is different from the signal receiving no processing at all.
6|Models of selective attention ask **where the attention filter occurs: early in processing or later in processing**. They differ in the analysis available to unattended information.||The **early-selection model** is **Broadbent’s filter model (1958)**. The **intermediate-selection model** is **Treisman’s attenuation theory (1964)**. **Late-selection models** include the evidence discussed by **MacKay (1973)**.||The distinction concerns whether meaning is analyzed before selection, prevented by selection, or sometimes available from a weakened unattended stream.
7|**Broadbent’s filter model is an early-selection model: it filters the message before incoming information is analyzed for meaning.**||The initial **sensory memory** stage **holds all incoming information for a fraction of a second before transfer to the next stage**. Both messages can initially be registered.||Initial registration does not mean that both messages have been understood. The later filter determines which stream continues to higher-level analysis.
8|In **Broadbent’s filter model**, the **filter identifies the attended message based on physical characteristics**. **Only the attended message is passed on to the next stage**.||Physical characteristics can include **ear of presentation, pitch, or voice**. Selection therefore does not require first understanding every message.||This is **early selection** because the message is filtered **before incoming information is analyzed for meaning**.
9|The **detector** in Broadbent’s model **processes information to determine higher-level characteristics of the message**, including meaning.||Its input is the message that has already passed the filter. “All information” at this stage means the **selected information reaching the detector**, not both original streams.||The model is early-selection because the filter acts before that analysis. An unattended message blocked by the filter should not receive the same semantic processing through this route.
10|The next memory stage in **Broadbent’s filter model receives the output of the detector**. It **holds information for approximately 10–15 seconds and may transfer it to long-term memory**.||This store comes after selection and higher-level analysis. It is different from the initial sensory stage, which briefly holds incoming information before the filter.||The sequence is **incoming information → sensory memory → filter → detector → later memory**. The model’s attention claim depends on where the restriction occurs along that route.
11|**Broadbent’s model is also called a bottleneck model because the filter restricts information flow.** The restriction concerns which message continues, rather than slowing every message equally.||The model **lets information through based on specific physical characteristics**. Only the selected channel receives the later analysis.||It is also called an **early-selection model** because this restriction comes before meaning. The prediction is limited access to the content of an unattended, rejected stream.
12|A shortcoming of a strict Broadbent filter is that **participants’ names get through**. In **Moray (1959)**, listeners’ names were presented to the unattended ear; **about one third detected their own name**.||Participants can also **shadow meaningful messages that switch from one ear to another**. In **Gray and Wedderburn’s “Dear Aunt Jane” experiment (1960)**, the **left ear received “Dear—4—Jane”** and the **right, shadowed ear received “8—Aunt—2.”**||Participants reported **“Dear Aunt Jane.”** Following meaning across ears challenges the proposal that selection completely excludes content outside one physical channel.
13|**Treisman’s attenuation theory is an intermediate-selection model.** The attended message can be separated from the unattended message **early in the information-processing system**, and **selection can also occur later**.||The **attenuator analyzes the incoming message in terms of physical characteristics, language, and meaning**. It reduces the unattended stream’s strength rather than completely removing it.||This preserves a distinction between attended and unattended input while allowing some meaningful unattended information to influence later processing.
14|In **Treisman’s attenuation theory**, the **attended message is let through the attenuator at full strength**. It has stronger input to the following **dictionary unit**.||The full-strength message is more likely to activate relevant words. Attention therefore creates a processing advantage for the selected stream.||The unattended stream need not disappear completely. The contrast is between full-strength and attenuated information, helping explain both effective shadowing and occasional competing breakthroughs.
15|In **Treisman’s attenuation theory**, the **unattended message is let through at a much weaker strength**. It is **attenuated, not shut off**.||Reduced-strength input can still activate a word if that word’s **activation threshold** is sufficiently low. Common or important words may therefore become available from weak input.||This explains why an unattended name can sometimes be noticed without requiring the entire unattended message to be as available as the attended stream.
16|Treisman’s **dictionary unit contains words, each with a threshold for being activated**. **Words that are common or important have low thresholds; uncommon words have high thresholds**.||The threshold determines how much activation is required. A person’s own name can have a low threshold and therefore respond even to attenuated input.||The mechanism combines **message strength** with **word threshold**: the same weak signal can activate an important word while failing to activate many less familiar words.
17|**Unattended inputs are attenuated, not shut off.** Selection follows an ordered hierarchy: **physical cues → syllabic pattern → specific words → grammatical structure → meaning**.||These levels describe increasingly organized analysis of the incoming signal. Weakening the stream limits how effectively it supports later processing without requiring complete elimination.||The dictionary unit’s thresholds help determine what becomes active. A low-threshold word can break through even though much of the unattended message remains difficult to report.
18|In **late-selection models**, **selection of stimuli for final processing does not occur until after information has been analyzed for meaning**.||In **MacKay (1973)**, participants heard **“They were throwing stones at the bank”** in the attended ear. The unattended ear received either **“river”** or **“money.”**||The sentence is ambiguous between a riverbank and a financial bank. If the unattended word changes the interpretation, its meaning must have influenced processing beyond a purely physical sound difference.
19|In **MacKay (1973)**, participants chose which test sentence was closest in meaning to the attended message: **“They threw stones toward the side of the river yesterday”** or **“They threw stones at the savings and loan association yesterday.”**||**The meaning of the biasing word shifted participants’ choice**, although they were **unaware of the presentation of the biasing words**. River favored the river interpretation; money favored the financial interpretation.||MacKay argued that the biasing word **must have been processed for meaning even though it was unattended**. Meaning can influence interpretation without conscious report of the competing input.
20|A **late-selection account** proposes that **all inputs receive full processing, but only important, task-relevant inputs enter short-term memory and eventually lead to a response**.||The sequence places **perceptual processing before the selective filter**, followed by later memory and response. Meaning can therefore be analyzed without every analyzed message becoming reportable.||After meaning is analyzed, task relevance determines which input is retained and used for a response.
21|**Broadbent (1958), filter model:** selection is **early, before meaning is analyzed**. **Only the attended channel** gets through, selected on physical features such as **ear, pitch, or voice**. Shadowing shows that unattended content often cannot be reported.||**Treisman (1964), attenuation theory:** selection is **intermediate, early and late**. Unattended input is **turned down**, while **low-threshold words** can still activate. Own-name detection and **“Dear Aunt Jane”** motivate that flexibility.||**Deutsch and Deutsch (1963), and MacKay (1973), late selection:** information is analyzed for **meaning before selection controls response and awareness**. An unattended biasing word shifting sentence interpretation supports this later meaningful influence.
22|**There is no single answer to the early–late controversy.** Under some conditions **early selection can be demonstrated**, and under other conditions **late selection** can be demonstrated.||Researchers therefore focus on **understanding the factors that control attention**. Task demands and available processing capacity help explain why selection differs across conditions.||The goal is to predict when unattended information will matter, rather than assume one filter location must account for every result.
23|**Automatic processes are processes that do not demand attentional control.** The **visual-search task** provides an example when a distinctive feature is detected readily among other items.||A target that stands out can require less deliberate item-by-item inspection than a difficult search. Automaticity concerns control and resource demands under those task conditions.||A distinctive target can be selected with little effortful inspection of each individual item.
24|**Automatic processes do not demand attentional control**, but they can **interfere with more effortful, attention-demanding processes**.||In the **Stroop task**, reading the word can interfere with naming the **ink color** when word meaning and color conflict. The automatic response is not the one required by the current instruction.||The comparison with visual search shows that automatic processing can either facilitate performance or create interference, depending on the task’s goal.
25|**Processing capacity** is **how much information a person can handle at any given moment**. **Perceptual load** is **the difficulty of a given task**.||**High-load, difficult tasks use higher amounts of processing capacity. Low-load, easy tasks use lower amounts.**||When the main task uses more capacity, less remains available for irrelevant information. When it uses less, spare capacity can support distractor processing. That spare capacity allows task-irrelevant stimuli to be processed and interfere with the response.
26|In **Forster and Lavie (2008)**, **presentation of a task-irrelevant stimulus slows response time**. The distraction effect is **stronger for easier tasks than for harder tasks**.||Under the harder, higher-load condition, **less perceptual capacity remains** for the irrelevant stimulus. Under the easier condition, more is available to process it.||The response-time cost of the irrelevant stimulus is therefore larger when the main task leaves more capacity available.
27|**Overt attention** shifts from one place to another **by moving the eyes**. **Covert attention** shifts **while the eyes stay fixed**.||**Saccades are rapid eye movements from one place to another. Fixations are short pauses on points of interest.** An **eye tracker** measures those movements and pauses.||**Central vision** is the area being looked at; objects there fall on the **fovea**. **Peripheral vision** is off to the side. The **fovea has much higher resolution than the periphery**.
28|**Stimulus salience** concerns **areas that stand out and capture attention**. It is a **bottom-up process** depending on physical characteristics of the stimulus. **Color and motion are highly salient**.||Selection can be driven by the image itself through **light–dark differences, color, contrast, and motion**.||**Attentional capture is an involuntary shift of attention due to stimulus salience.** A sudden movement can draw attention even when it is unrelated to the observer’s current goal.
29|**Top-down determinants of eye movements** include **scanning based on cognitive factors and the meaning of features**. What the observer knows and seeks affects where they look.||A **scene schema is knowledge about what is contained in typical scenes**. Schemas **help guide fixations from one area of a scene to another**.||These influences produce **variations in how people scan scenes**, even when the physical image is the same. The guidance comes from expectations and goals rather than only physical salience.
30|A **scene schema** supplies knowledge about **what is contained in typical scenes** and helps **guide fixations from one area to another**.||**Võ and Henderson (2009)** compared viewing behavior for **semantically consistent and inconsistent objects**. An object that violates the expected scene contents is viewed differently from one that fits.||**Fixation duration** measures part of that difference. The viewing pattern reflects expectations about what belongs in the scene.
31|**Eye movements are influenced by the task. Scanning can be based on task demands.** In meal preparation, gaze goes toward objects needed for the current or next action.||A useful object can receive a fixation even when another feature is more visually conspicuous. The goal determines what information needs to be sampled.||Changing the task can therefore change the scan pattern within the same scene, illustrating **top-down guidance** of eye movements.
32|**Precueing means directing attention without moving the eyes.** In **Posner et al. (1978)**, participants responded **faster to a light at an expected location than at an unexpected location**, even while their eyes stayed fixed.||The cue changes which location receives priority before the target appears. The response-time difference provides evidence for **covert attention**.||Maintaining fixation separates that priority change from an overt movement that would bring the target onto the fovea.
33|In **Posner et al. (1978)**, **precueing** produced faster responses at an **expected location** than an **unexpected location** while the eyes stayed fixed.||A **valid cue** indicates the location where the target appears. An **invalid cue** directs attention elsewhere, so responding includes redirecting attention to the actual target.||The reaction-time comparison supports **attention without eye movements**. It concerns where processing was prioritized, not merely the time needed to move the eyes.
34|The **same-object advantage** shows that we can **covertly attend to specific objects**. **When attention is directed to one place on an object, its enhancing effect spreads to other places on that object**.||In **Egly et al. (1994)**, a cue at **A** is followed by a target at the cued position, an **invalid same-object position**, or an **invalid different-object position**.||The critical comparison holds **distance from the cue equal**. Faster detection within the same object shows that object membership matters beyond spatial distance alone.
35|Whether **C has an advantage over B** depends on how **A, B, and C** belong to the perceived objects. In the changed arrangement, **C has no advantage over B**.||When **A and C are on the same object again**, the relevant same-object relationship returns. The advantage changes with the object arrangement.||The result connects selection with perceptual organization: holding distance comparable while changing object membership can remove or restore the benefit.
36|**Practice enables people to simultaneously do two things that were difficult at first.** **Schneider and Shiffrin (1977)** divided attention between **remembering a target and monitoring rapidly presented stimuli**.||The **memory set contained one to four target characters**. **Test frames could contain random-dot patterns, a target, or distractors**.||Performance requires keeping the target set available while checking the incoming frames. Practice can change how efficiently those demands are coordinated.
37|The procedure begins by **presenting a target stimulus in the memory set**, followed by **a series of 20 rapidly presented test frames**.||The participant decides **whether a target from the memory set was present in a frame**. Current input must be compared with the retained target while distractors are excluded.||Repeated trials track changes in this combined retention-and-monitoring task, allowing practice effects to be examined.
38|**After about 600 trials, the task had become automatic for participants** in the reported condition. Performance improved toward a stable high level through practice.||Repeated trials improved the coordination of remembering the target and monitoring test frames.||The practiced response required less deliberate control, which is the change described as automatic processing.
39|**Schneider and Shiffrin suggest that practice made it possible for participants to divide their attention.** **Automatic processing occurs without intention and uses only some of a person’s cognitive resources**.||**Practice results in automatic processing** in the trained conditions. Component operations require less deliberate coordination, leaving more capacity available for other demands.||For skilled performers, **paying attention to their performance has sometimes been argued to degrade performance**. Deliberately monitoring a highly practiced component can interfere with its fluent execution.
40|Practice can make dividing attention possible, but **automatic processing is task dependent**. A task can remain sufficiently hard that automatic processing is not achieved even with practice.||**Automatic processing occurs without intention and uses some cognitive resources**.||A familiar activity can improve while still demanding attention. The difficulty and conditions of the actual task determine whether another activity can be added without interference.
