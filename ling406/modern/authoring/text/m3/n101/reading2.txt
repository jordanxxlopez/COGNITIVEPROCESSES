2|**Dual-route models propose two routes because reading shows several findings that one route would not explain easily.** >> Pseudoword reading (reading pronounceable made-up words) is fast and automatic. >> Word reading is faster. >> Reading is fastest for **high-frequency** words, which are words that occur often in language. >> Accuracy and response time are also affected by **regularity**, which is how consistently a spelling maps onto one pronunciation. >> **Frequency and regularity interact**, so the effect of one depends on the other. >> In **acquired dyslexia** (reading loss after brain damage), pseudoword reading and irregular word reading are **dissociable**, meaning one can be impaired without the other. || The model proposes two routes. >> The **sublexical route** does **grapheme-to-phoneme conversion**, which means turning written units into sounds. This is also called **decoding**. >> The **lexical route** recognizes real words. >> Two routes seem needed because dyslexia can impair one kind of reading without the other.
3|**The Dual Route Cascaded model joins an interactive word route to a separate rule route.** Coltheart and colleagues (2001) published this model in Psych Review. >> Its lexical part is just the **Interactive Activation model**. >> The model has **no implementation of semantics**, so it does not model meaning. >> Its **orthographic lexicon** (store of written word forms) and **phonological lexicon** (store of spoken word forms) are both independent of semantics. >> Its **Grapheme-Phoneme Rule System** has processing assumptions that are completely different from the interactive part. || Both routes can contribute activation toward a spoken response. >> The rule system joins the output instead of becoming another interactive layer. >> So the DRC uses two different kinds of computation.
4|**The Grapheme-Phoneme Rule System works serially, letter by letter, and frequency does not change how it works.** >> Its rules are activated **serially** (one after another), so it moves through the letters in order. >> The rule system has **no feedback** from the lexical route. >> Word frequency has no effect on it in any way. >> The two routes meet only at the **phoneme response buffer** (the shared output stage), where the rule system is connected to the same output units. >> Because they share those output units, the two routes can **compete** to activate different patterns.
5|**Grapheme-phoneme conversion (GPC) rules map written units onto phonemes (sound categories), and a model also needs rules for choosing among them.** >> Some rules concern individual letters, while others concern several letters or a particular letter context. >> **Context-sensitive rules** restrict a pronunciation to specified surrounding letters or positions. >> **Meta-rules** decide when to apply rules at each level of analysis. >> A **larger-unit rule** supersedes smaller-unit rules, so a rule for several letters takes priority over rules for its individual letters. >> Position labels specify whether a mapping applies at the beginning, middle, end or all positions.
6|**The GPC rules are often based on the most frequent pronunciation, but they work as fixed, categorical rules.** >> The rules follow the most frequent pronunciation for a letter or letter combination, so they are partly based on statistics. >> The rule for **-OUGH** has weaker statistical support than the rule for **-EIGH**. >> Even so, both count as rules and **behave the same way** during processing. >> A **probabilistic account** (one where each alternative gets its own degree of support) would instead let different pronunciations carry different strengths of support. >> A spread of pronunciation frequencies across many alternatives means more uncertainty than a single dominant pronunciation.
7|**The DRC's simple rules miss many cases, and this was seen as a feature, not a bug.** >> Finer rules could pronounce more exceptions correctly, and the DRC's own rules went through several revisions to improve nonword reading. >> The argument is that people do not use such finely tuned rules for the GPC route. >> If they did, the **regularization errors** (pronouncing an exception word as if it followed the usual rule) seen in **surface dyslexia** would not appear. >> The slowdown for low-frequency exception words would not appear either. >> The theory claims that people's sublexical computation is constrained. || A **cognitively useful model** should reproduce the relevant failures, not only maximize pronunciation accuracy. >> The crucial test is whether the same processing assumptions produce the observed pattern of success, interference and regularization.
8|**Informational encapsulation means that a process does not freely use every source of relevant knowledge.** >> Parsing strategies like **late closure** and **minimal attachment** were motivated by syntactic complexity alone. >> The idea was that syntactic processing is informationally encapsulated from world knowledge and **lexical co-occurrence statistics** (how often words appear together). >> The dual-route models are designed to be similarly modular. >> The GPC route keeps running and gives correct pronunciations for many words, but it gives incorrect responses to some exceptions. >> We can see its operation when people make **regularization errors** or when they are forced to name **pseudowords** (pronounceable made-up words). || In dual-route accounts, GPC conversion proceeds without consulting whole-word meaning or lexical feedback. >> Pseudoword naming exposes the conversion procedure because no familiar lexical entry is available. >> Regularization errors expose it when conversion favors the wrong pronunciation. >> This resembles a modular parsing proposal, but the comparison concerns processing restrictions, not shared representations.
9|**The DRC can simulate many phenomena in visual word recognition.** >> **Coltheart and colleagues (2001)** tested the model against effects including **frequency**, **lexicality** (whether an item is a word or a nonword), **regularity** and their **interactions**. >> The tested effects also include **lexical decision** and patterns found in acquired dyslexia. >> Accounting for several effects with one architecture is stronger than fitting a single result. || Evaluation also requires examining which assumptions stay fixed and which change between tasks. >> The model gives strong weight to human behavioral evidence as a constraint on its architecture. >> The listed effects span reading aloud, lexical decision and patient performance. >> These are related but distinct tasks, so any task-specific adjustment has to be identified as such.
10|**To model lexical decision (deciding whether a written item is a word), the DRC adds decision criteria to its recognition activity.** >> This sometimes means going to extremes to make contact with the data. >> The model first reduces **letter-word inhibition**, which makes the task harder. Without that change, the results make no sense. >> A "yes" answer occurs if any single word has an activity above a threshold of 0.69. >> A "yes" answer also occurs if the total activity over the orthographic input lexicon exceeds the threshold S of 10 for cycles 0 to 20. That threshold drops to 1.98 if lexicon activity exceeds 0.2 at cycle 20. >> A "no" answer occurs if neither criterion is met by the deadline D of 42 cycles. The deadline becomes 48 if lexicon activity exceeds 0.112 after 20 cycles. >> This is described as nearly twice as fast as the model normally reads aloud. >> The thresholds and deadlines implement response rules, and their conceptual role matters more than the exact numbers. || The implementation also changes inhibition and uses time-dependent thresholds. >> These choices help the model fit the data. >> They add assumptions beyond the basic two-route diagram.
11|**The DRC's routes are modular, meaning each route has its own assumptions and limited contact with the other.** >> The GPC route and the lexical route each have their own processing assumptions. >> They are **informationally encapsulated** from one another, so no lexical feedback reaches the GPC rules. >> They are **domain-specific**, meaning the GPC rules take only letters as input and pass phoneme activations to the phoneme system. >> Modularity has three related senses, namely restrictions on inputs, rules of computation, and restrictions on communication. || Modularity is a specific claim about how components operate and communicate. >> Having two pathways alone would not establish those stronger restrictions.
12|**Seidenberg and McClelland (1989) treated reading skill as emerging from learned mappings among spelling, pronunciation and meaning.** >> They studied these mappings with **PDP models** (parallel distributed processing networks) and trained a simple associative network to learn them. >> Orthography is spelling, phonology is sound structure, and semantics is meaning. >> They studied mappings from orthography to phonology in a single route. || Reading skill emerges from learning rather than from a hand-built list of rules and lexical entries. >> A connection between domains represents a learned mapping, not an extra stored dictionary entry for each item.
13|**In the PDP account, rules are generalizations learned from many words, not a separate process.** >> Whole-word knowledge is **distributed**, so some is stored in orthography-to-phonology mappings and some in other parts of the system. >> The same learning mechanism can capture patterns shared by many words and information about one familiar word. >> "Distributed" describes how knowledge is spread across the network, so the model still has memory for individual words. >> The research strategy differs from dual-route models. >> It asks whether **domain-general learning** (learning that is not specific to reading) can explain reading. >> This contrasts with reverse-engineering the system from adult and neuropsychological data.
14|**The network produces the frequency by regularity interaction without assuming that frequency and regularity come from different processes.** >> Regular words are consistent with statistical patterns from many other words. >> Exception words are inconsistent with those patterns. >> Frequency also affects how well words are learned, so highly frequent words are less affected by inconsistency with other words. >> A low-frequency exception has both weak item-specific learning and poor support from the dominant pattern. >> That combination creates a larger disadvantage than either factor alone. || Producing this interaction does not by itself establish whether the implementation contains symbolic rules. >> The interaction is shared evidence that both architectures must explain.
15|**Regularity is redefined as consistency, which depends on how many similar spellings support a pronunciation.** >> A **regular consistent** word, such as LATE or DUST, has many **friends** and no **enemies**. Friends are similar spellings with a compatible pronunciation, and enemies support a competing pronunciation. >> A **regular inconsistent** word has many friends but at least one enemy, such as GAVE and MINT. >> An **ambiguous** word has about equal numbers of friends and enemies, such as DOWN and KNOWN, or POUR and SOUR. >> An **exception** has few if any friends and many enemies, such as HAVE and PINT. || Friends and enemies describe pronunciation relations among similar spellings, not semantic relations between words. >> Spelling-sound support varies in degree, and a simple regular or irregular label can hide that. >> PINT has relatively little support compared with its competing neighborhood.
16|**In principle, the network can pronounce nonwords using the same learned weights it uses for words.** >> A new spelling activates patterns that overlap with familiar spellings, so the network generalizes to it. >> No stored entry for that particular nonword is required. >> The same statistical patterns that give rise to regularity effects also support nonword reading. >> This is proposed as a mechanism for decoding without a separate GPC rule module. || Novel pronunciations can come from applying learned statistical structure. >> Whether one learned mapping can handle both familiar words and new items must still be checked against the model's actual performance.
17|**Early nonword accuracy was poor, which raises a question about the theory or the implementation.** >> Nonword accuracy was not very good in the early model. >> This is a classic case of ambiguity in model evaluation. >> One possibility is that the theoretical claim is wrong, so nonwords and exceptions cannot be read by the same associative mechanism. >> The other possibility is that the problem lay in how the model was built. Its representations may fail to capture the similarities needed for generalization. >> Improving the implementation while keeping the theoretical mechanism helps tell these possibilities apart. || A failed simulation does not identify its own cause. >> A representational improvement is a different theoretical move from adding a separate nonword route.
18|**Nonword reading is related to phonological representations, meaning how sounds are coded in the model.** >> Many studies show a relationship between decoding (nonword reading) and phonological processing. >> The early Seidenberg and McClelland model used **Wickelfeatures** (the early model's way of coding speech sounds), which were an unusual phonological representation. >> **Plaut and colleagues (1996)** improved the phonological representations and got better nonword performance. || Changing the representation can improve decoding without adding a symbolic rule system. >> Better performance after that change is evidence about implementation, not proof that every associative model will succeed.
19|**Generalization depends on similarity, so poor sound representations hurt generalization to new items.** >> This principle is inherited from behaviorism. >> Poor phonological representations, like Wickelfeatures, fail to capture the similarity space of words in the language. >> Word-specific information is more robust to poor representations, because it does not depend entirely on generalization. >> A nonword has no item-specific experience, so it depends more heavily on generalization. || The same weakness can have unequal effects on words and nonwords without any dedicated nonword mechanism. >> Distinguishing a weaker shared representation from damage to a separate route matters, because the two locate the explanation differently.
20|**Harm and Seidenberg (1999) manipulated the amount of noise in the phonological representations.** >> Increasing noise makes the sound representations less reliable while the general learning framework stays the same. >> Adding noise produced poorer nonword decoding and relative sparing of word recognition. >> The model replicated several key findings from the developmental dyslexia literature. >> These included the link between the degree of phonological deficit and **phonological dyslexia** (a reading pattern tied to weak sound processing). >> Noise is the manipulated property, so the simulation tests a directional mechanism rather than only observing a correlation. || A selective-looking reading deficit can emerge from degraded shared representations. >> Nonwords are especially dependent on reliable generalization, so they are especially affected.
21|**Lesions to semantics produced a specific impairment on exception words.** >> Nonword reading can be specifically impaired even though the model has no dedicated nonword mechanism. >> **Plaut and colleagues (1996)** explored the other end of this dissociation, **surface dyslexia** (a reading pattern with trouble on exception words). >> They implemented a simplified semantic system in the **triangle model**, a network that links orthography, phonology and semantics. >> An exception has weak support from typical spelling-sound regularities, while meaning-related support can help produce its learned pronunciation. >> Reducing that support creates a surface-dyslexia-like pattern, without defining a separate exception-word list as the sole explanation. >> A **lesion** here is a controlled change to the computational model, not an observed injury in a patient.
22|**The triangle model is not simply the dual-route model renamed, because semantic representations are directly involved.** >> The dual-route model's lexicon is independent of semantics, while the triangle model's semantic representations take part directly. >> A later model, **Harm and Seidenberg (2004)**, implemented **featural semantics** (meaning represented as features) and simulated the mapping of spelling to meaning. >> The orthography-to-phonology (OP) and semantics-to-phonology (SP) mappings share the same processing assumptions and learning algorithm, and both are probabilistic. >> These pathways interact over learning, so the OP pathway develops differently in the presence of the SP pathway. >> This interactivity and gradedness lets the models capture that **double dissociations** (two impairments that each occur without the other) are never entirely clean. >> Phonological dyslexics are not perfect on exception words, and surface dyslexics are not perfect on nonwords. || Multiple pathways alone do not make a model modular, because learning rules, information types and interactions set the accounts apart. >> The OP and SP mappings use the same general probabilistic assumptions, unlike the DRC's distinct GPC and lexical procedures.
23|**Woollams and colleagues (2007) tested the prediction that semantic ability and exception-word reading are strongly associated.** >> The patients had **semantic dementia** (a progressive condition). >> Lower semantic scores were associated with poorer low-frequency exception reading. >> The model and patient results match in their overall relationships, although individual patients vary. >> This links a reading weakness to a broader semantic measure, not only to a reading-task dissociation. || On the semantic score scale, values fall from left to right. >> The downward trend therefore means that poorer semantics goes with poorer exception reading. >> It does not mean that better semantics harms reading.
24|**Some patients fall outside the general trend, and Woollams and colleagues would treat them as outliers when evaluating model fit.** >> Patients who are left of the vertical boundary and above the horizontal boundary count as **statistical outliers** (scores that sit far from the general pattern). >> This means the model misses a few data points, and those points are treated the way outliers are usually treated when judging model fit. >> An outlier does not automatically refute the model, because an account of graded association does not predict zero variability. >> The real question is whether these unusual cases form a stable separate pattern or arise within a noisy overall association. >> Points like these should be judged by their location relative to the broader group of patients and by repeated measurements.
25|**Following patients over time tests whether semantic and reading ability decline together.** >> Because semantic dementia is progressive, repeated testing can reveal a trajectory rather than a single unusual score. >> In most cases, when a patient's semantic ability declined over time, the patient's reading ability also declined. >> **Regression to the mean** (unusual scores moving back toward typical values on retesting) is the pattern that idiosyncratic outliers would show. >> Observations from the same person are connected, so movement toward lower scores on both measures is coupled decline. || Repeated observations help test whether an apparent dissociation persists. >> A one-time exceptional score is less convincing if the patient's later scores follow the general relation.
26|**Coltheart and colleagues (2009) simulated surface dyslexia with the DRC by generating 40,000 model patients.** >> The model patients varied on two parameters, the integrity of the lexical route and the integrity of the GPC rules. >> For each patient in the Woollams and colleagues data, the researchers selected the run of the model that best fit that patient's data. >> This selection produced an excellent fit to the data. >> The selection procedure is part of how that fit was achieved, so the fit differs from predicting each patient's pattern in advance. || The plotted patient and model lines lie close together. >> That closeness describes goodness of fit. >> The large search over simulated patients describes flexibility.
27|**A better fit can be less informative when it comes from much greater flexibility.** >> The question is why a better fit could count against this account. >> Selecting the best match from many parameter combinations can reproduce a dataset without strongly constraining the explanation. >> The issue is not that close agreement is bad in itself. >> The issue is whether the account predicts the relation from principled assumptions or accommodates each case after seeing the outcome. || Goodness of fit is only one part of model evaluation. >> A model should explain why the pattern occurs, not only contain a setting that resembles it. >> The contrast is between constrained prediction and flexible post hoc matching (fitting after the results are known).
28|**The dual-route and triangle models both have to explain the same basic reading patterns.** >> Both must explain rapid decoding of pseudowords (pronounceable made-up words), which is fast and automatic. >> Words that diverge from typical spelling-to-sound mappings are harder to read. >> This **regularity** (or **consistency**) effect interacts with word frequency. >> Pseudoword reading and **exception word** reading can be dissociated in neuropsychological patients. || The models compete over explanation, not over whether these basic reading patterns exist. >> Agreement on the phenomena does not mean agreement on mechanisms. >> One account emphasizes specialized routes, while the other emphasizes learning across interacting representational systems. >> A useful comparison holds the phenomenon constant and asks what each model changes or computes to produce it.
29|**The two models explain the same reading patterns with different mechanisms.** >> For pseudoword reading and regularity effects, the triangle model relies on statistical regularities learned over many words. The DRC instead relies on a dedicated grapheme-phoneme conversion rule system. >> For frequency effects, the triangle model says more exposure to a word leads to better learning for that word. >> The DRC instead uses distinct lexicons for input and output, separate from the GPC rules. >> Word-specific exposure therefore strengthens learned mappings in the triangle account and affects lexical processing in the DRC. || For phonological dyslexia, the DRC points to deficit or damage in the GPC route. The triangle model points to deficit or damage in phonological processing generally. >> For surface dyslexia, the DRC points to damage in the lexical route, while the triangle model points to deficit or damage in semantic processes generally. >> Each row gives competing explanations for the same finding, not two names for the same component.
30|**The key contrast is whether explanations begin with separate reading routes or with broader language associations.** >> **Dual-route models** usually use **double dissociations** (two impairments that each occur without the other) to motivate independent processes. >> Pseudowords and exception words can each be impaired on their own, so dual-route models treat them as independent processes. >> Models informed by statistical learning reveal associations instead. >> Phonology is important for learning and using OP (orthography-to-phonology) generalizations, while semantics is important for words where OP generalization is ambiguous. || Both dissociations and associations matter, because a theory should explain selective weaknesses and the related abilities that vary with them. >> The dyslexia rows of the comparison contrast GPC versus phonological damage and lexical route versus semantic damage. >> These are the key theoretical alternatives, not just different diagnostic labels.
