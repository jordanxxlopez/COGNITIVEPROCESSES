2|**The first thing to remember about phonemes is that phonemes are not letters.** A **phoneme** (a speech-sound category) belongs to spoken language. A letter belongs to a writing system. >> Writing represents language, but its symbols do not have to match phonemes one to one. >> One letter can take part in different pronunciations. >> One phoneme can be written with different spellings. >> Identifying a letter is a different task from identifying a phoneme. >> The question concerns how sound relates to writing, not how many letters a word has.
3|**Scripts differ in how reliably spelling gives pronunciation, and English is a deep script.** >> In a **mispronouncing contest**, people willfully mispronounced words like COLONEL and PARADIGM. >> Usual letter patterns give the wrong pronunciation for both words. >> So phonemes are not letters, and letters are not phonemes either. || This difference between scripts is **orthographic depth** (how consistently spelling matches pronunciation). >> **English** is relatively **deep** because of its irregularities. >> **Finnish** and **Korean** are very **shallow** scripts. >> **Pinyin** for Mandarin and **French** are relatively regular. >> A deep script is less predictable, not random. >> The difference is in the writing system, not in the readers' ability.
4|**In Finnish, each letter matches one phoneme, so Finnish children learn to decode very quickly.** Finnish is very **transparent**, or **shallow** in the terms of the **Orthographic Depth Hypothesis**. >> Each letter corresponds more or less unambiguously to one phoneme. >> Following a beginning Finnish lesson with its text makes the pattern clear within about a minute. >> A doubled consonant stands for a **geminated** consonant (a consonant held longer). >> A doubled vowel stands for a **long vowel**. >> **Decoding** (producing a pronunciation from a written form) is fast to learn. >> Consistent matches let children read written forms they have never seen.
5|**Children learn to decode more slowly in English than in most other Roman-alphabet languages.** English is an **outlier** among languages that use the Roman alphabet. >> **Aro and Wimmer** had children read **pseudowords** (made-up words that follow the spelling and sound patterns of their language). >> A pseudoword is not a stored word, so reading it tests decoding. >> In **Grade 1**, French, German, Dutch, Spanish, Swedish and Finnish learners read about 85 to 93 percent accurately. >> In Grade 1, **English** learners read only about **half** accurately. >> By Grade 4, English learners reach about 88 percent. >> Less predictable spelling-sound matches explain the slower start. >> English children can still decode. They just learn it more slowly.
6|**In Korean Hangul, similar phonemes have similar symbols, so the angular ㄱ shape marks velar consonants.** Korean is even more regular than Finnish. >> Letters sit in **syllable blocks** with an **initial**, a **medial** and sometimes a **final** position. >> **Velar** consonants (made with the back of the tongue against the soft palate) share the angular ㄱ shape. >> ㄱ is g. >> Doubling it gives ㄲ, which is kk. >> Adding a stroke gives ㅋ, which is k. >> So the letter shapes show sound structure, not only consistent pronunciation.
7|**Readers can pronounce pseudowords like GLORP, SPLING, JONK, FEESH and QUISP, which puts decoding into action.** >> These items are not English words. >> Each follows enough English spelling patterns for a **plausible pronunciation**. >> No stored pronunciation exists for them, so success cannot come from memory. >> Readers use knowledge that **generalizes** across words. >> The items test **decoding**, not vocabulary or meaning.
8|**Nonwords are read nearly as quickly and accurately as real words, so decoding is natural, automatic and implicit.** >> **Lupker, Brown and Colombo (1997)** measured **naming time** (how quickly a pronunciation becomes available when reading aloud). >> They compared pseudowords, here called **nonwords**, with real words. >> Nonword naming was only **5 to 12 percent slower** than for low-frequency words. >> The baseline is low-frequency words, not all real words. || A later question is how to characterize decoding. >> Computational models of word reading ask whether it fits **categorical rules** or **probabilistic constraints**. >> Both kinds of account could produce fast decoding.
9|**Some pseudowords, like VONTH, PHANGE, STREAD and SOUGH, have more than one plausible pronunciation.** >> Each contains a spelling pattern English pronounces in more than one way. >> Readers answer from spelling-sound patterns learned in familiar words. >> Different familiar words favor different answers to the same item. >> These items have no single agreed pronunciation. >> They test how readers handle **ambiguity** in spelling-to-sound mapping. >> So generalization can be **graded**, not all-or-none.
10|**Readers accept both /strɛd/ and /strid/ for STREAD, which is hard for a rule set to cover.** >> **Generalization** is a good way to test what regularities people have learned about a system. >> A new item cannot have been memorized, so the answer reveals the learned pattern. >> The **Wug Test** is another generalization test. >> The two readings of STREAD differ only in the vowel. >> A **categorical rule** gives one output, so two acceptable outputs are hard for it. >> A **statistical account** can give each pronunciation a different amount of support.
11|**Irregular words are harder to recognize than regular words, which is the regularity effect.** Irregular words are also called **inconsistent**. Some form of decoding is uncontroversially part of normal reading. >> The effect is straightforward for PINT, ACHE and CHOIR. >> Their usual spelling patterns give the wrong pronunciation. >> It is less clear-cut for **neighborhoods** (sets of words sharing a spelling pattern). >> ROLL, POLL and TOLL share one pronunciation, but DOLL differs. >> COOK, TOOK and BOOK share one pronunciation, but SPOOK differs. >> So difficulty depends partly on how spelling neighbors are pronounced.
12|**Readers clearly use sublexical information, so the open question is how lexical processes work.** >> **Sublexical information** (information about units smaller than a whole word) is used especially to translate spelling to sound. >> People read nonwords quickly and accurately. >> Words with typical spelling-to-sound patterns are easier to read than words without them. >> **Lexical information** (knowledge of particular words) also needs an account. >> Nonwords test generalization. Differences among familiar words reveal word-specific knowledge.
13|**Knowing a word helps identify an ambiguous letter inside it.** This comes from the **Interactive Activation Model** of **McClelland and Rumelhart (1981)**. >> Visual features activate letters. >> Letters activate candidate words such as WEAR, WORK, WORD and WEAK. >> Active words send **feedback** to their letters. || In a word perception example, blots cover parts of the letters in WORK. >> The last letter's visible features fit K and R, not D. >> Only K makes a known word, so WORK feeds back to K. >> **K** activation rises close to the maximum. >> **R** activation rises a little, then falls back. >> **D** activation stays low. >> Recognition builds up over time, not at once.
14|**In the Interactive Activation Model, known words feed activation back to their own letters.** >> **Feedback** from activation for known words increases activation for letters in those words. >> Letter-to-word activation gives evidence for a word. >> Word-to-letter feedback supports that word's letters. >> So recognition is **interactive**, not only upward from features to words. >> A word and its letters support each other. >> So an ambiguous letter is easier to recognize inside a familiar word.
15|**Real words are named faster than nonwords, and frequent words are named faster than rare ones.** These are two **lexical effects**. >> **Lexicality** compares whether the item is a word. >> **Word frequency** compares how often a word has been met. >> In one naming study, high-frequency words took about 442 ms and low-frequency words about 482 ms. >> Nonwords took about 541 to 552 ms. >> As with **picture naming**, past encounters speed naming. >> **Balota and colleagues (2004)** used **English Lexicon Project** data. >> Naming time drops steadily as frequency rises. >> The effect is **robust** over a very large number of observations.
16|**Frequency still predicts reading time after length and other variables are controlled.** >> A **confound** (another variable that changes with frequency) could fake a frequency effect. >> Length was one worry, since frequent words could be shorter. >> A **multiple regression analysis** (measuring each predictor's effect with the others included) tested this. >> About 3000 words were read by 30 young and older adults. >> The tasks were **lexical decision** (judging whether a string is a real word) and **naming**. >> **Objective** and **subjective frequency** had **negative** coefficients in all four columns. >> So higher frequency went with **faster** responses. >> So the frequency effect is not just a confound.
17|**The frequency effect is much larger for exception words than for regular words.** This **frequency by regularity interaction** is a landmark finding in psycholinguistics. >> **Exception words** have a pronunciation that breaks the usual spelling pattern. >> **Naming latency** is the time to begin saying a word. >> At **high frequency**, both kinds are named in about 540 ms. >> At **low frequency**, exception words take about 583 ms and regular words about 557 ms. >> An **interaction** means one factor's effect depends on the other. >> So experience matters most when pronunciation conflicts with the usual pattern. >> The finding has affected other areas, most immediately **inflectional morphology**.
18|**One interpretation is that word recognition uses two separate processes, a sublexical one and a lexical one.** >> The **sublexical process** is decoding from spelling units. >> The **lexical process** is knowledge of a particular word. >> For **high-frequency (HF)** words, the lexical process is so fast that the sublexical process has little influence. >> The sublexical process shows up only for **nonwords** and **low-frequency (LF)** words. >> For an LF exception word, decoding gives a regularized answer. >> That answer competes with the correct one, so naming slows. >> This is one interpretation of the interaction, not the interaction itself.
19|**Acquired phonological dyslexia is brain-injury reading difficulty specifically with pseudoword naming.** It is **acquired** (caused by injury) as opposed to **developmental** dyslexia. >> **Cacciopo van Vliet and colleagues (2003)** tested patients M.O. and I.B. >> Both read real words and nonwords aloud. >> **Real words** were about 85 to 100 percent correct. >> This held across concreteness, word class and frequency. >> **Nonwords** got plausible responses much less often, often under half. >> Nonwords with low **grapheme-to-phoneme correspondence** were hardest, at about 15 to 20 percent. >> A **grapheme** is a written unit standing for a sound. >> So familiar-word reading survives while decoding new forms fails.
20|**Acquired surface dyslexia is brain-injury reading difficulty specifically with irregular words.** >> Mispronunciations tend to be **regularizations** (reading a word by the common spelling-sound pattern). >> DEAF becomes “deef”, SAID “sayed”, BROAD “brode” and SHOE “show”. >> ONE becomes “own”, FLOOD “flude” and GONE “goan”. >> STEAK becomes “steek”, SEW “sue” and SOOT “suit”. || Two patients, MP and KT, were tested. >> **Regular words** were about 89 to 100 percent correct. >> **Nonwords** were about 95 to 100 percent correct. >> **Exception words** dropped, most for low frequency. >> KT scored 47 and 26 percent on high- and low-frequency exceptions. MP scored 93 and 73. >> So the errors are systematic, not random.
21|**Surface and phonological dyslexia show opposite patterns, which is a classic double dissociation.** >> **Surface dyslexia** impairs irregular words, with regularization errors. >> Surface dyslexia leaves **pseudoword reading** relatively spared. >> **Phonological dyslexia** impairs pseudoword naming. >> Phonological dyslexia leaves **exception word reading** relatively spared. >> A **double dissociation** (one group impaired on task A, another on task B) needs both directions. >> Relatively spared does not mean perfect. >> So the pair is hard to explain as one task being harder for everyone.
22|**Double dissociations are powerful because the impairment reverses across patients.** >> If task A were simply harder, damage would hurt A more in every patient. >> A patient with the reverse pattern rules that out. >> In reading, phonological dyslexia hurts pseudowords more. >> Surface dyslexia hurts exception words more. >> So the two tasks place different demands on the reading system. >> Each patient's profile is compared first, then the two profiles. >> Two low scores without an opposite pattern are not a double dissociation. >> A theory is still needed for what the separate processes are.
23|**Double dissociations are evidence that pseudoword and irregular word reading rely on separable processes.** In **Morton's logogen model**, from **Morton and Patterson (1980)**, each dyslexia comes from different damage. >> **Logogens** (stored word units) come as visual input logogens and output logogens. >> **Grapheme-phoneme conversion** turns letters into sounds without a stored word. >> **Phonological dyslexia** results from specific damage to the grapheme-phoneme conversion module. >> Nonwords have no stored word, so they are read poorly. >> **Surface dyslexia** results from damage to input or output logogens, or their connections. >> Exception words then rely on conversion, so they come out regularized. >> These are theoretical components, not a brain map.
24|**Patterson (1981) gave early hints that the dual-route account is not so simple.** In that account, words are read from stored whole-word pronunciations or by **non-lexical grapheme-phoneme translation**. >> Surface dyslexia errors were thought to use only the non-lexical route. >> So they should show no lexical influences. >> **Marcel (1980)** found several lexical influences in the error data. >> **Neologisms** (made-up non-words) occurred less often than a purely non-lexical process predicts. >> One patient read incense as “increase”, partly from the ambiguous consonant c. >> A purely non-lexical error would have been the neologism “inkense”. || This poses a **classic dilemma**. >> Either surface dyslexia reflects a more complicated combination of the two routes. >> Or non-lexical reading is itself a more complicated route. >> Models of normal reading ask the same question, as in **Glushko (1979)**. >> Patterson argued that combining normal and patient evidence holds the best promise.
