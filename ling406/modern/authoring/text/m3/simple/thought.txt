2|Linguistic relativity asks whether differences in language change how people organize concepts. This is because the Sapir and Whorf quotations say that **linguistic categories** (the word groups a language uses) shape how experience is interpreted. The strongest reading says language decides what a person can think. The weaker reading says habitual language use biases attention, memory, or preferred ways of describing things. || These two readings need different evidence. The quotations are broad ideas, not experiments. || **Influencing thought** (shaping how a person thinks) is different from **completely determining thought** (leaving no other option). This is because influencing only biases attention, memory or preferred descriptions, while determining would decide what a person can think.
3|Language differences can overlap with other differences between communities. This is because a difference between language communities can go along with factors other than linguistic structure. Sapir and Whorf should not automatically get the strongest reading of their quotations. In the first half of the twentieth century, linguistics was part of **anthropology** (the study of human cultures). So treating language as part of culture seemed natural then. || Testing linguistic relativity needs a narrower claim than saying each language creates a separate world. This is because **domains** (specific areas of experience) such as space and time let researchers test preferred ways of representing things. A precise study must identify which **cognitive process** (a mental operation such as remembering) is affected. It must also check which other explanations the comparison controls.
4|A location description needs a **frame of reference** (the set of directions used to say where something is). This is because saying where the ball is requires choosing what counts as left, front, or a stable direction. The ball can be described relative to the viewer, relative to the chair's own orientation, or by a direction that depends on neither. Different descriptions can pick out the same physical position. The object does not have to move for its description to change. This is because changing the reference changes the relation being described.
5|A description can use one of three frames, which are intrinsic, relative, and absolute. This is because an **intrinsic frame** (the object's own orientation) gives "at the chair's front". A **relative frame** (the observer's viewpoint) gives "to the left of the chair from my viewpoint". An **absolute frame** (a stable direction) gives "north of the chair". This is because north does not reverse when the observer turns around. Rotating the observer changes left and right, but it does not change north. So the frame has to be stated, since different frames pick out different directions. This classification comes from **Levinson and colleagues (2002)**.
6|Most languages describe nearby space from the speaker's own position. This is because left, right, in front, and behind all depend on where the speaker is. Tzeltal, a Western Mayan language spoken in Chiapas, does not do this. This is because Tzeltal commonly uses **absolute directions** where English speakers might use relative terms. A small number of other languages also use absolute directions, including some spoken in Bali and Queensland. Those languages are mostly unrelated to one another. || This raises a question about habits. This is because the question is whether habitual language use relates to nonverbal spatial coding. The comparison concerns preferred spatial descriptions.
7|**Tzeltal's uphill and downhill terms** work as an absolute system. This is because things are uphill or downhill from one another, not to the left or right of the speaker. These terms historically came from landmarks, but each use does not just point to the nearest visible hill. The direction is kept as a stable reference. So the speaker's current left and right do not set it again. This is why positions can be described consistently as the speaker turns. Where a term came from is a different property from whether it is absolute.
8|New Yorkers use **uptown** and **downtown** as if they were cardinal directions. This is because these terms only work inside Manhattan, so they are literally a landmark-based system. Manhattan is angled relative to magnetic north. This is because the city's conventional map orientation differs from magnetic north, so the subway map is off on north and south. A local convention is not automatically an absolute frame that works everywhere. This is because its usefulness depends on the landmark system being available.
9|**Majid and colleagues (2004)** used a non-linguistic test of relative and absolute coding of space. This is because the **chips task** rotates the participant 180 degrees between two tables. A participant sees a configuration, waits, and then chooses its match at the second table. A **relative response** keeps the arrangement with respect to the person's viewpoint. An **absolute response** keeps the arrangement's orientation in the environment. This is because after rotation the two responses point to different choices. Dutch speakers mostly gave relative responses. Tzeltal speakers gave more absolute responses. The pattern fits each group's preferred frame. It does not separate language from all other experience.
10|**Spatial inference** can combine relations learned in different displays. This is because participants learn one relation between two objects, rotate, and learn a second relation with a shared object. They then place one object relative to another using both relations. Relative and absolute coding lead to different placements. This is because the person's orientation has changed between the displays. The cube appears in both displays, so it links the cone and cylinder relations. The final placement separates a viewer-relative inference from one that keeps environmental direction. Dutch and Tzeltal patterns differ again. This is because each group leans toward the direction that matches its preferred frame.
11|Testing conditions may explain part of the language difference. This is because **Li and Gleitman** noted that the Tzeltal participants were tested outside, with visible and familiar landmarks. Typical psychology lab studies happen in windowless rooms. Landmarks can encourage landmark-based coding, so a windowless room makes viewer-relative descriptions more convenient. A language comparison can be **confounded** (mixed up with another difference) by a setting comparison. The critical contrast is access to spatial cues, not simply the label "laboratory." Manipulating landmarks within English speakers tests whether the behavior can change without changing their native language.
12|English speakers strongly preferred **relative responses** when the blinds were down. This matches the Dutch speakers in earlier studies. With the blinds up and a view of the street, the preference is less pronounced. Outdoors, the preference is also less pronounced. This is because outside landmarks change which references are useful. The language stayed the same across these conditions. So task context can change the response, which challenges the idea that language alone fixes the frame. The change is a weakening, not a full switch to absolute coding.

This is because visible landmarks and familiarity can go along with native language in a cross-community study. So a controlled comparison must separate the environment from any effect of habitual linguistic coding. An uncontrolled comparison cannot tell these two effects apart. || A **confound** is a factor that changes along with the variable of interest. This is because it offers another explanation for the result. It is not just any feature that happens to be present in the experiment. 15|Levinson and colleagues argued that the simplified task made the experimenter's purpose too obvious. This is because low memory demands and short time or distance between displays make the rotation easy to notice. Li and Gleitman's participants were Ivy League students. This is because those students are good at working out what the experimenter wants. Participants who work out the purpose can change their answers. This is because a **demand-characteristic explanation** (the idea that a study's apparent purpose shapes responses) can act apart from habitual spatial coding. So the response focuses on memory load and task transparency. It does not deny that landmarks can ever matter.
16|**Levinson and colleagues (2002)** re-ran the animals in a row experiment with Dutch college students. They added a fourth animal and a longer delay to raise memory load. They also increased the distance between the stimulus and response tables. This is because more distance makes the rotation less obvious. Under these conditions, the bias toward relative framing remained. So the environmental effect depends on how the task is arranged. Each change has a purpose. More animals and a longer delay tax memory, and the separated tables lower how obvious the rotation is.

19|**Metaphorical language** expresses one kind of experience using terms from another. This is because calling an argument ineffective describes how well it works, not a literal action with a blade. 20|**Boroditsky and colleagues (2010)** compared spatial metaphors for time in English and Mandarin. English and Mandarin both use horizontal spatial language for time. Mandarin also often uses vertical terms. An earlier event can take an "up" term, and a later event can take a "down" term. These expressions are the starting observation. A behavioral task is needed to test whether the vertical contrast goes beyond words. The "up" in an earlier month is a temporal use. It does not claim that the month occupies a physical location.
21|**Boroditsky (2001)** ran a priming experiment on time judgments. Participants first process a horizontal or vertical spatial relation. They then answer whether one event is earlier or later. English speakers respond faster after horizontal primes than after vertical primes. Mandarin speakers have the opposite pattern in the comparison tested. Short training on vertical metaphors for time changes the pattern for English speakers. This suggests the pattern depends on experience, not on a fixed split between language groups. Lower reaction times mean faster processing. So horizontal and vertical results should be compared within each group.

24|**Casasanto and Bottini (2010)** had participants sort events as past or future by pressing colored buttons. The mapping from color to category is reversed across blocks. So the past response is on the left half the time and on the right the other half. With standard text reading, responses are faster when past maps left and future maps right. This is because the response is about time, not an explicit spatial judgment, so the effect reveals an implicit spatial association. Color alone cannot explain the pattern. This is because the two mappings are **counterbalanced** (each mapping is used in turn across blocks). The effect concerns response time across mappings. It does not change which events count as past or future.
25|Short-term reading experience can change the link between space and time. This is because **Casasanto and Bottini (2010)** had participants read reversed text and then do the past and future button task. By the second mirror-reading block, the compatibility effect reverses. Responses are then faster when earlier events map to the right and later events map to the left. A flexible temporal mapping is hard to explain as a fixed result of grammar alone. This is because recent perceptual and reading experience also contributes to performance. The first block keeps the usual advantage, while the second favors the opposite mapping. So each block should be compared on its own colors before overall times are compared.
26|**Pullum (1989)** criticized how an account of different word roots became an exaggerated story about language and thought. His critique points against exaggerated claims about language and thought. Claims about a language's vocabulary are not automatic evidence for cognitive limits. This is because languages can express distinctions through separate roots, derived words, or phrases. Counting one form without the others can misrepresent a language's expressive capacity. A reliable claim needs an accurate linguistic description and an appropriate behavioral test. Languages can package the same distinctions in different ways. Roots, derived forms, and phrases are different, so simple vocabulary counts can mislead.
