2|**Memory** is the set of processes involved in **retaining, retrieving and using information** about stimuli, images, events, ideas and skills **after the original information is no longer present**. The experience itself is over, but something from it is still available to work with. >> Whatever we can still use after the source is gone is the work of memory. || Memory is active **any time a past experience affects how we think or behave now or in the future**. It is the past reaching into the present, and sometimes into what we will do next. >> Tulving described remembering our own past events as a kind of **mental time travel**, since it carries us back to when and where something happened.
3|Memory is an **active system that stores, organizes, alters and recovers information**. It does not simply file things away unchanged, because it organizes and even alters what it holds. >> So what we remember reflects how we stored it as well as what actually happened. || Three key terms describe how memory handles information. **Encoding** is converting information into a usable form for storage, **storage** is holding that information in memory, and **retrieval** is taking memories back out of storage so they can be used. >> A memory can fail at any of these three points, so forgetting has more than one possible cause. || The old computer on this slide is a reminder that short-term and long-term storage are a real design problem. Computer scientists had to think hard about the split when a computer's fast working memory was tiny. >> Human memory also has a small active store and a much larger lasting store.
4|The **tree of memory** splits memory into three kinds at the top, which are **sensory**, **short-term** and **long-term** memory. Sensory and short-term memory are grouped together because both are brief, while long-term memory lasts. >> The three branches differ in how long they hold information and how much they can hold. || Long-term memory then splits into **declarative** memory and **procedural** memory. Declarative memory is knowledge we can state in words, while procedural memory is knowing how to do things, such as skills. >> Declarative memory splits again into **episodic** memory, for personal events we lived through, and **semantic** memory, for facts and general knowledge. >> So remembering one particular birthday is episodic, while knowing what a birthday is counts as semantic.
5|The **modal model of memory**, from **Atkinson and Shiffrin**, describes **three types of memory** connected in a line. **Sensory memory** is the first stage and holds all incoming information for a second or less. **Short-term memory** holds about five to seven items for roughly fifteen to twenty seconds, and **long-term memory** can hold a large amount of information for years or even decades. >> Each store passes information on to the next, and each one has its own limits. || In the diagram, input flows into sensory memory, then into short-term memory, and then into long-term memory, while information can also come back from long-term memory into short-term memory. Output, such as a response, comes out of short-term memory. >> **Rehearsal** loops back on short-term memory, and it is called a **control process** because the person chooses to do it.
6|The modal model can be walked through with the everyday task of looking up and calling a phone number. When a person looks at a screen full of listings, **all the information on the screen enters sensory memory**. >> At this first step, everything is taken in at once and nothing has been chosen yet. || Most of what is on the screen will never be used, because only one number matters. All of that unused information fades out of sensory memory almost immediately. >> So sensory memory acts as a brief holding area that gives attention a moment to pick what matters.
7|Next, the person **focuses on one number**, and **it enters short-term memory**. Focusing is what moves the number out of the brief sensory snapshot into the store we actively work with. >> Everything the person did not focus on stays behind in sensory memory and fades away. || So attention is the gateway between sensory memory and short-term memory. Short-term memory is small, so only what we attend to gets in. >> If attention had not picked out the number, it would have faded with everything else on the screen.
8|Next, the person **rehearses the number** to keep it in short-term memory while making the call. Saying it over and over keeps it from fading, and the rehearsed number is what lets them dial correctly. >> In the diagram, rehearsal is drawn as an arrow looping back into short-term memory. || Rehearsal only works while it keeps going. If the person is interrupted and stops repeating the number, it can be lost within seconds. >> Here short-term memory leads straight to behavior, since the remembered number becomes the act of dialing.
9|Next, the person **memorizes the number**, so it is **stored in long-term memory**. Once it is stored, the number no longer has to be repeated to stay available. >> In the diagram, a storage arrow now runs from short-term memory into long-term memory. || Short-term memory held the number for the call, while long-term memory keeps it for later. Moving information into long-term memory is what lets it outlast the moment. >> Memorizing takes more work than repeating, because the goal is to keep the number for good rather than for a few seconds.
10|Later, the person **retrieves the number from long-term memory**, and it **goes back into short-term memory** so they can call again. The diagram labels short-term memory with **awareness**, because whatever it holds is what we are conscious of right now. >> The retrieval arrow runs from long-term memory back into short-term memory. || So information flows in both directions between the two stores. New information goes into long-term memory for keeping, and stored information comes back into short-term memory whenever it is needed. >> Short-term memory is where what we are perceiving now and what we already know come together.
11|**Sensory memory** is **storing an exact copy of incoming information for less than a second**, and it is the **first stage of memory**. The copy is exact because nothing has been interpreted or selected yet. >> Because it lasts less than a second, attention has only a brief moment to pick what to keep. || Sensory memory has a version for each sense. An **icon** is a fleeting mental image, the visual version, and an **echo** is the brief continuation of a sound in the auditory system after the sound is heard. >> An echo is why we can sometimes replay the last few words someone said even though we were not really listening.
12|**Sensory memory** is the **retention, for brief periods of time, of the effects of sensory stimulation**, and the information in it **decays very quickly**. **Persistence of vision** is the brief retention of the perception of light. >> A sparkler waved in the dark leaves a trail of light, because each position lingers briefly in visual sensory memory. >> Film is a series of still frames, and each one lingers just long enough to blend into the next, so we see smooth motion. || In the spinning card demonstration, a card with different letters on each side is spun quickly, and the letters from both sides are seen together at once. Each side lingers while the other side comes into view, so the two blend into one display. >> This is persistence of vision at work in a single simple object. || Sensory memory **holds a large amount of information for a short time**. It **collects** information, **holds it for initial processing** and **fills in the blanks** between separate moments of input. >> Filling in the blanks is exactly what makes a film look smooth.
13|**Sperling** set out to measure two things about sensory memory, its **capacity**, meaning how much it holds, and its **duration**, meaning how long it lasts. An array of letters was flashed very quickly on a screen, and participants were asked to report as many letters as they could. >> The letters are gone before anyone could keep looking at them, so whatever people report has to come from memory. || This is the **partial report experiment**, and trying it directly makes the problem it solves easy to feel. By the time a few letters have been named, the rest seem to have slipped away. >> That feeling raises the real question, which is whether the letters were never stored or were stored and then faded.
14|Sperling compared **three methods** that all flash the same kind of letter array. In the **whole report** method, participants report as many letters as they can from the entire array. >> Naming letters takes time, so the memory may fade while the report is still going. || In the **partial report** method, participants hear a tone **after** the letters disappear, and the tone tells them which single row to report. Because the tone comes too late to look back, they must have been holding every row in memory when it sounded. >> One row is short enough to report before the memory fades. || The **delayed partial report** method is the same as partial report, except there is a short delay between the letters and the tone. The delay gives the memory time to fade before the person learns which row to give. >> Comparing it with immediate partial report reveals how fast the memory fades.
15|The display has **three rows of four letters**, and the top row is marked as the one to report. In the **delayed partial report** condition, the tone points to the top row only after a delay, and by then the participant can come up with just one letter from it. >> All four letters in that row were there when the display appeared. >> The delay let the other three fade before the tone told the person which row mattered. || The contrast with immediate partial report is the whole point. With an immediate tone, most of a row can be reported, but after a delay, very little survives. >> That difference reveals how quickly the visual image fades.
16|The three methods give strikingly different results for the same displays. In **whole report**, people could name only about a third of the letters in the array. In **partial report**, people could name most of the letters in whichever row was cued, and they could do this for **any** row. In **delayed partial report**, they could name only about one letter of the cued row. >> The people and the displays never changed, so the differences come from the method. || Partial report reveals how much was stored. If people could give most of any row they were asked for, then most of every row must have been in memory when the tone sounded, which is far more than whole report suggests. >> Delayed partial report reveals how fast the store empties, because after a brief wait almost nothing was left.
17|**Sperling was studying visual sensory memory**, which is called **iconic memory**. Before his study, people thought iconic memory could hold only four or five items, because that was all anyone could report in whole report. >> The old view mistook what people could report for what they had stored. || His other conditions sorted this out. It is true that people can only **report** four or five items before the memory **decays**, or fades away. But sensory memory actually **encodes the whole scene**, as partial report revealed. >> So the limit is in reporting fast enough, not in what was taken in. || The conclusion is that **sensory memory has a large capacity but fast decay**. Within about a second, most of it is gone, leaving only what attention moved into short-term memory. >> Attention has to choose quickly, and whatever it does not choose is lost.
18|Plotting **how much is still available as the tone is delayed** makes the fade easy to follow. When the tone comes right away, most of the letters can be reported. As the delay grows to a fraction of a second, availability drops quickly, and by about one second, partial report has fallen to nearly the level of whole report. >> The red square on the right marks the whole report level for comparison. || Nothing was shown during the delay, so the drop cannot come from new input getting in the way. It comes from the visual image itself fading. >> That fast fade is also why whole report stalls at a few letters, since the image is gone before the person can finish naming them.
19|**Short-term memory**, or **STM**, is the **second stage of memory**. It stores **small amounts of information briefly**, and it is **very sensitive to interruption or interference**. >> A distraction or a competing thought can knock out what it is holding. >> That is why a number vanishes the moment someone starts talking to us. || **Memory span** is how much short-term memory can hold at once. STM is limited to about **seven, plus or minus two**, separate bits of information. >> So most people can hold somewhere between five and nine separate items at a time.
20|Information can be kept in short-term memory in different ways. **Recoding** is reorganizing or modifying the information, for example by grouping it into a more useful form. >> Recoding changes how the information is packaged while keeping what it says. || **Maintenance rehearsal** is repeating information silently so that it stays in short-term memory longer. It keeps information alive only as long as the repeating continues. >> Once the repeating stops, the information fades quickly. || **Elaborative rehearsal** links new information to memories and knowledge already in long-term memory, and it is a **good way to move information from short-term into long-term memory**. Connecting something new to what we already know gives it meaning and more ways to find it later. >> That is why understanding material works better than just repeating it.
21|Short-term memory **stores small amounts of information for a brief time**, and it holds **both new information coming in from the senses and information recalled from long-term memory**. It is where the present and what we already know come together. >> Most tasks need both kinds of information at the same moment. || Short-term memory is responsible for a great deal of mental life. It lets us **understand sentences**, **do arithmetic**, **dial a phone number**, **navigate from one place to another** and **know where we are and what we are doing right now**. >> Each of these requires holding something in mind while doing something else with it. || **Everything we think about or know at a given moment involves short-term memory**, because short-term memory is **our window on the present**. Whatever is in it is what we are aware of right now. >> When it is overloaded, we lose track of what we were doing.

23|Short-term memory raises the **same two issues as sensory memory**. **Duration** is how long things stay in memory, and **rehearsal** seems to extend it. **Capacity** is how many things fit at once, and **chunking** seems to extend it. >> Each limit has a strategy that seems to stretch it. || Studying short-term memory is complicated because people use **control processes** such as rehearsal and chunking all the time. Their scores then reflect the strategy as well as the store itself. >> To measure the store, a study has to stop people from using these strategies. >> The **Brown-Peterson task** is built to do exactly that, and trying it directly makes its logic clear.
24|**Brown** and **Peterson and Peterson** ran the same study at the same time and got the same results, which makes the findings convincing. The procedure has four steps. >> First, the person is given three letters and one number. >> Second, the person counts backward from the number by threes. >> Third, the counting goes on through a delay of a few seconds up to about eighteen seconds, and fourth, the person recalls the three letters. || Counting backward by threes is the key to the design. It keeps the person busy, which **prevents rehearsal**, so the delay measures how long the letters last without being refreshed. >> Without the counting, people would just keep repeating the letters and remember them perfectly.
25|On the **first trial only**, recall is high at both the short delay and the long delay. Even after the longest delay, people remember the three letters about as well as after the shortest one. >> So on a first trial, blocking rehearsal for many seconds causes very little forgetting. || This is surprising if forgetting comes simply from time passing. The letters sat unrehearsed for a long time, yet they were barely lost. >> That points toward something other than time as the main cause of forgetting on later trials.
26|On the **third trial**, recall after the short delay is still high, but recall after the long delay has dropped noticeably. The procedure is exactly the same as on the first trial, yet now the long delay costs much more. >> The only thing that changed is that two earlier trials came first. || If time alone caused forgetting, the third trial should look just like the first. It does not, so the earlier trials must be making the new letters harder to keep. >> Something left over from before is getting in the way.
27|**Many trials later**, recall after the short delay is still high, but recall after the long delay has dropped to almost nothing. The same delay that cost almost nothing on the first trial now wipes out nearly everything. >> The long delay is only harmful once many trials have built up. || The pile of earlier trigrams is what makes the new one so hard to keep. Old letters compete with the new letters when the person tries to recall them after a long wait. >> This is the clearest sign that forgetting here comes from interference rather than from time alone.
28|**Averaged over all trials**, recall is high after the short delay and low after the long delay. This average looks like a simple story in which memory fades as time passes. >> That is the result most often reported from these studies. || But the average hides the trial-by-trial pattern. The large drop at the long delay comes mostly from the later trials, after many earlier trigrams had piled up. >> Looking only at the average would make decay seem to explain everything.
29|The studies by Brown and Peterson and Peterson found that **the share of letters recalled goes down with longer delays**. Read at face value, that looks like information simply fading over time. >> That was the original interpretation. || **But this pattern depends on where a trial falls in the series.** Recall after long delays gets worse as the series of trials gets longer, while early trials hold up well even after a long delay. >> So the amount of earlier material, not just the delay, controls how much is forgotten.
30|Brown and Peterson and Peterson were interested in **decay**, the idea that a memory trace vanishes simply because time passes. Their studies were designed to test how fast short-term memory fades when rehearsal is blocked. >> Counting backward was meant to leave time as the only thing acting on the letters. || It turns out their studies revealed another kind of forgetting in short-term memory, which is **proactive interference**. In proactive interference, what is already in short-term memory makes it harder to add new things. >> The trigrams from earlier trials got in the way of the current one. || The larger point is that **forgetting in short-term memory happens through both decay and interference**. Without rehearsal, the effective duration of short-term memory is only about **fifteen to twenty seconds**. >> Rehearsal can keep information much longer, but only as long as it continues.
31|**Interference theories** explain forgetting as **memories interfering with memories**. On this view, forgetting is **not caused by the mere passage of time**, but by one memory competing with or replacing another. >> The problem is crowding and competition, not age. || There are **two types of interference**, named for the direction in which the trouble runs. **Retroactive interference** runs backward in time, while **proactive interference** runs forward in time. >> Keeping straight which memory is new and which is old is the key to telling them apart.
32|**Retroactive interference** is when a **new memory interferes with remembering old information**. Something learned recently makes it harder to recall something learned earlier. >> The arrow runs backward in time, from the new memory to the old one. || A new phone number is a good example. After using a new number for a while, it becomes hard to remember the old one, because the new number keeps coming to mind instead. >> The newer memory pushes the older one out of reach.
33|**Proactive interference** is the **opposite of retroactive interference**. It is when an **old memory interferes with remembering new information**, so something learned earlier makes it harder to learn or recall something newer. >> The trigrams from earlier trials in the Brown-Peterson task are exactly this kind of interference. || A parking lot is a good example. Memories of where we parked on campus over the past week get in the way of remembering where we parked today. >> Both kinds of interference are worst for routine events, because routine memories are so similar to each other, while unusual events are less prone to interference.
34|Short-term memory not only loses information quickly but also has a **limit on how much it can hold**. Capacity varies from person to person, and it is measured by **digit span**. >> Digit span is the longest string of digits a person can repeat back correctly. || The rows of digits get longer one at a time. Short rows are easy to repeat, but each added digit makes the task harder, until the row is too long to hold. >> The point where people start failing is the edge of their short-term memory capacity.
35|In the full digit span test, each row is one digit longer than the row before. A person reads each row, looks away and tries to repeat it back. >> The longest row the person gets completely right is their **digit span**. || For most people the span lands somewhere around seven digits. Some people manage a few more and some a few fewer. >> That range is what the phrase seven plus or minus two describes.
36|The famous paper by **George Miller** is titled **The Magical Number Seven, Plus or Minus Two**, with the subtitle **Some Limits on Our Capacity for Processing Information**. Miller joked that he was being persecuted by an integer, because the number seven kept following him around in study after study. >> The number kept showing up in very different tasks that all tested how much people can hold at once. || The paper became one of the most influential in psychology. It gave the limit of short-term memory a memorable name. >> The playful title made the idea easy to remember and hard to ignore.
37|**Miller** proposed that people can remember **seven plus or minus two** items, whether the items are **digits**, **words**, **numbers with several digits** or **phrases**. The limit seemed to be about the number of items, no matter how big each item was. >> A whole phrase could count as one item just like a single digit. || Some researchers have suggested that capacity should be described in terms of the **amount of information** rather than the **number of items**. **Alvarez and Cavanagh** tested this using colored squares and more complex objects in a **change detection** procedure. >> If capacity depends on information, complex objects should take up more room than simple ones.
38|There may be **several kinds of short-term memory**, each specific to a sense or even to a type of content. Theorists still argue about how many there are and how specialized each one is. >> A store for sounds and words might work differently from a store for pictures and locations. || **Visual short-term memory**, measured with the **change detection task**, may have a **smaller capacity** than memory for lists of digits or unrelated words. That would mean the limits depend on what kind of material is being held. >> So the famous limit of about seven may apply to verbal lists, while visual memory may hold fewer items.
39|In **change detection**, the first display, called **S1**, flashes for only a moment. It is a set of colored squares scattered across a gray background. >> The person has to take in as many of the squares as they can before the display disappears. || The flash is far too short to study each square carefully. So whatever the person keeps must be held in visual short-term memory. >> The rest of the task tests how much of this display survived.
40|Between the two displays comes a **blank gap**, with nothing on the screen to look at. The gap makes sure the first display is completely gone. >> Any comparison the person makes after the gap has to rely on memory, not on what is still visible. || Without the gap, the person could just notice something flicker. With it, they have to remember what they saw.
41|The second display, called **S2**, stays up for a couple of seconds. The person judges whether it is **the same as or different from** the first display. >> In this example, one square in the lower right has changed color. || Catching a change like this is only possible if that square was being held in memory. So accuracy on many such trials reveals how many squares a person can keep at once. >> The number of squares that can be held is the capacity of visual short-term memory.
42|When the number of colored squares, called the **set size**, is small, people are almost always right. Accuracy **falls off dramatically once there are more than four items**. >> So people seem to hold only about **three to four items in visual working memory at a time**. || A second version used colored bars at different angles. Sometimes only the angle changed, sometimes only the color changed, and sometimes people had to remember both color and angle for every bar. >> Accuracy fell with set size in the same way in all three cases. >> Remembering two features of each object was about as easy as remembering one, so objects seem to be stored as whole units.
43|**The ability to make the same or different judgment depended on how complex the objects were.** Four kinds of objects were tested, ranging from simple colored squares to Chinese characters, random polygons and shaded cubes. >> The simplest objects are flat patches of color, and the most complex are three-dimensional shapes with shading. || Capacity fell steadily as the objects got more complex. Colored squares had the highest capacity, at about four, and shaded cubes had the lowest, at fewer than two. >> So the limit depends on how much information each object carries, not only on how many objects there are.
44|The same result applies to the Chinese characters as a middle case. They are more detailed than plain colored squares but simpler than random polygons or shaded cubes, so their capacity falls in between. >> Each character still counts as one item, but its extra detail uses up more of the limited space. || A handwritten note in the original points out that the shapes labeled Chinese characters are really parts of characters, and one is drawn incorrectly. That detail does not change the result, which is that more complex objects are held in smaller numbers. >> The pattern supports describing capacity as an amount of information rather than a count of items.
45|We can hold **much more in short-term memory when things are organized into chunks**. **Chunking** is combining smaller units into larger meaningful units to improve capacity, and each chunk takes up just one slot however much it contains. >> What makes a chunk meaningful is knowledge already in long-term memory. || **Ericsson and coworkers** trained a college student until his digit span rose to around eighty digits. He was a runner, and he **chunked the digits into meaningful running times**, so a string of several digits became a single race time. >> His short-term memory still held only a few units, but each unit carried many digits. || **Chase and Simon** found that **chess players chunk the board into meaningful patterns from real games**. A strong player sees a familiar cluster of pieces as one unit. >> That is why experts can take in so much more of a board at a glance.
46|**Chase and Simon** compared chess masters and beginners at reproducing chess boards they had seen only briefly. When the pieces were arranged as in a **real game**, masters placed far more pieces correctly than beginners. >> The masters could chunk the familiar patterns into a few large units. || When the pieces were arranged **randomly**, masters were no better than beginners. Random boards have no meaningful patterns, so the masters' knowledge gave them nothing to chunk. >> So the masters did not have bigger short-term memories, they had more knowledge to organize what they saw.
47|**Control processes** are active processes that the person can control. They include **maintenance rehearsal**, which is repeating a stimulus over and over, **strategies that make a stimulus more memorable**, and **strategies of attention** that help us focus on particular stimuli. >> The memory palace, an ancient technique of placing items along an imagined building, is one such strategy for making information more memorable. || Working out all the different control processes that short-term memory needs leads to the idea of **working memory**. Working memory treats short-term memory as a system that does things with information, not only a place that stores it. >> Short-term memory turns out to be an active workspace, not just a place where items wait.
