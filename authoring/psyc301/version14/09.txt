2|**Memory** is the set of processes involved in **retaining, retrieving and using information** about stimuli, images, events, ideas and skills **after the original information is no longer present**. The book has been closed, the conversation has ended or the event is over, and yet information from it is still available to us. >> Memory covers all kinds of content, from a picture we saw to a skill we practiced. >> The defining feature is that the information outlasts the experience that produced it. || Memory is **active any time some past experience has an impact on how we think or behave now or in the future**. Memory is the past affecting the present, and possibly the future. >> Recognizing a friend’s face, finishing a familiar song and riding a bike all draw on earlier experience. >> When we plan tomorrow, memory supplies what happened in similar situations before, which shapes the plan. || **Endel Tulving** describes **episodic memory**, our memory for personally experienced events, as a kind of **“mental time travel.”** >> When we remember an episode, we mentally return to the time and place where it happened. >> The event itself is long gone, but remembering brings back where and when it happened as well as what happened.
3|**Memory is an active system** that **stores, organizes, alters and recovers information**. Recovering information from memory is called **retrieval**. Memory reorganizes and changes information as it is stored and used, so a retrieved memory reflects how the information was encoded and organized as well as the original experience. || Three key terms describe the stages of memory. >> **Encoding** is **converting information into a usable form for storage**. When we encounter something, we build a mental representation of it that memory can hold. >> **Storage** is **holding this information in memory** over time. >> **Retrieval** is **taking memories out of storage** so they can be used again. || A failure at any stage leads to forgetting. >> If information is never encoded, there is nothing to store. >> If it is stored but cannot be retrieved, it is present in memory but unavailable when we need it. || The distinction between short-term and long-term memory has a parallel in computing. Computer scientists had to think much harder about short-term versus long-term memory when **RAM**, a computer’s fast working memory, maxed out at **16KB**. >> A small, fast working store holds what is in use right now, while a much larger store holds everything else. >> Human memory has a similar division between a small store for current use and a vast store for lasting knowledge.
4|The **tree of memory** organizes the different kinds of memory into a hierarchy. At the top is **memory**, which branches into **sensory**, **short-term** and **long-term memory**. These top branches differ in duration and capacity. >> **Sensory memory** holds the effects of stimulation for a very brief moment. >> **Short-term memory** holds a small amount of information for immediate use. >> **Long-term memory** holds a very large amount of information for long periods. >> Sensory and short-term memory are grouped together as the brief, limited-capacity stores. || **Long-term memory** divides into **declarative** and **procedural memory**, which differ in content. >> **Declarative memory** is memory for facts and events, the kind of knowledge we can state or describe. >> **Procedural memory** is memory for skills and how to do things, such as tying shoes or typing. It shows up in performance, such as riding a bike smoothly, even when we cannot explain every step. >> The difference is between knowing that something is true and knowing how to do something. || **Declarative memory** divides further into **episodic** and **semantic memory**. >> **Episodic memory** holds personally experienced events, such as a particular birthday party. >> **Semantic memory** holds general facts and knowledge, such as the capital of France. || The tree separates memory systems by how long they hold information and by what kind of information they hold. >> Sensory and short-term memory handle information that is in use right now. >> Long-term memory holds everything we know and can do, and each of its branches is used differently.
5|The **modal model of memory**, proposed by **Atkinson and Shiffrin (1968)**, describes **three types of memory** connected in a flow of information. >> **Sensory memory** is the **initial stage**, which **holds all incoming information for seconds or fractions of a second**. >> **Short-term memory** **holds five to seven items for about 15 to 20 seconds**. >> **Long-term memory** **can hold a large amount of information for years or even decades**. || The flow diagram traces information through the system. >> **Input** from the environment enters **sensory memory**. >> Selected information passes from sensory memory into **short-term memory**. >> Information in short-term memory can be stored in **long-term memory**, and stored information can be retrieved back into short-term memory. >> **Output**, such as a response or an action, comes from short-term memory. || **Rehearsal** is a **control process**, an activity the person carries out on the contents of memory. >> In the diagram, rehearsal is a loop around short-term memory. >> Repeating information keeps it active in short-term memory and helps transfer it into long-term memory. || Each stage keeps only part of what it receives, so information is filtered as it moves forward. >> Sensory memory receives everything from the senses, but most of it fades almost immediately. >> Attention selects a small part for short-term memory. Information that never receives attention never reaches short-term memory, and information that is never processed further stays out of long-term memory.
6|The modal model applies to the everyday task of looking up and calling a phone number. In the first step, a person looks at a computer screen full of listings. **All the information on the screen enters sensory memory**. >> Sensory memory registers the whole display at once, including every name and number on the screen. >> In the flow diagram, the **sensory** box is highlighted, with input arrows pointing into it. || Sensory memory holds this broad registration only briefly. >> The person needs just one number, so most of the listings are irrelevant to the task. >> They fade from sensory memory within moments. || Sensory memory therefore acts as a brief buffer. It holds the full scene long enough for attention to choose what to keep. Everything attention ignores fades away, which keeps short-term memory from being flooded with information the task does not need.
7|In the second step, the person **focuses on 555-5100**, and **it enters short-term memory**. **Attention** selects this one number from everything registered in sensory memory. >> In the flow diagram, the arrow runs from sensory memory to **STM**, and the STM box is highlighted. >> The selected number becomes the content the person is actively working with. || Attention is the gateway between sensory memory and short-term memory. >> Sensory memory briefly registers everything that reaches the senses. >> Short-term memory holds the selected item so it can guide what the person does next. >> Every other listing on the screen stays behind in sensory memory and fades within moments, while 555-5100 stays available for the call. || This selection matters because short-term memory has a small capacity. Holding every number on the screen would overwhelm it. Choosing only the relevant number keeps short-term memory free for the information the task actually requires.
8|In the third step, the person **rehearses the number to keep it in short-term memory while making the phone call**. Repeating “555-5100, 555-5100” is **maintenance rehearsal**. >> In the flow diagram, a circular **rehearsal** arrow loops around STM. >> An arrow labeled **remember number to make call** runs out of STM, since the rehearsed number guides dialing. || Rehearsal refreshes the number each time it is repeated, before it can fade. >> This lets the person hold the number after looking away from the screen. >> The person keeps the digits active while pressing each key in turn. || Rehearsal extends the duration of short-term memory, but only while it continues. >> If the person is interrupted and stops repeating the number, it can be lost within seconds. >> The output arrow represents short-term memory guiding behavior directly, linking stored information to action.
9|In the fourth step, the person **memorizes the number**, and it is **stored in long-term memory**. In the flow diagram, an arrow labeled **storage** runs from STM into **LTM**, and the LTM box is highlighted. >> Once stored, the number stays available long after the call is over. >> The person no longer needs the screen or constant repetition to keep it. || Short-term and long-term storage play different roles for the same number. >> Short-term memory held it for immediate use during the call. >> Long-term memory keeps it across days or weeks, ready for future calls. || Memorizing involves processing the number so that it leaves a lasting record, rather than simply repeating it for the moment. The arrow marks the transfer of information from temporary use into lasting knowledge, which is how experiences become part of what we know.
10|In the fifth step, the person **retrieves the number from long-term memory**. **It goes back to short-term memory and is remembered**. >> In the flow diagram, an arrow labeled **retrieval** runs from LTM back to STM. >> STM is labeled **awareness**, since whatever is in short-term memory is what we are currently thinking about. >> An arrow labeled **remember number to make call again** runs out of STM. || **Retrieval** makes stored information available for current use. >> The person does not need to look up the number again. >> The stored number returns to short-term memory, where it can be rehearsed and used to dial, just as the newly seen number was. || Information flows in both directions between short-term and long-term memory. >> New information moves from short-term memory into long-term storage. >> Stored information moves back into short-term memory whenever it is needed, and long-term memory holds it outside awareness until then.
11|**Sensory memory** is **storing an exact copy of incoming information for less than a second**. It is **the first stage of memory**. >> The copy is exact because it preserves the raw sensory input before it has been interpreted or selected. >> It lasts less than a second, so it gives attention only a moment to choose what to keep. || Sensory memory has different forms for different senses. >> An **icon** is **a fleeting mental image or visual representation**. It is visual sensory memory, a brief afterimage of what we just saw. >> An **echo** is **a brief continuation of a sound in the auditory system after the sound is heard**. It is auditory sensory memory. || Icons and echoes keep sensory input available just long enough for further processing. >> A visual scene can be briefly examined after it disappears. >> A sound can be briefly replayed in the auditory system, such as when we catch the end of a sentence we were not fully attending to. || Sensory memory differs from later stages in two ways. It holds information for less than a second, and it holds an unprocessed copy of the input. >> Because the copy is exact, it preserves details that have not yet been interpreted. >> Because it fades so fast, attention has to choose quickly what to keep.
12|**Sensory memory** is **the retention, for brief periods of time, of the effects of sensory stimulation**. **Information decays very quickly**. **Decay** means the stored information fades away with the passage of time. || **Persistence of vision** is **the retention of the perception of light**. >> When a **sparkler** is waved in the dark, we see a **trail of light**. The sparkler is only at one point at a time, but visual sensory memory holds its recent positions, so the points blend into a line. >> In **film**, separate **frames** are shown one after another with brief gaps. Persistence of vision holds each frame briefly as the next one arrives, so we perceive smooth motion instead of flickering still images. >> A demonstration from **Mr. Wizard’s World** uses a spinning card with letters, such as **M, ZA, DS, W** and **L**, on its two sides. When the card spins quickly, the letters from both sides are seen together. || Sensory memory **holds a large amount of information for a short period of time**. It plays three roles. >> It **collects information** from the senses. >> It **holds information for initial processing**, giving the brain time to work on it. >> It **fills in the blanks** between separate moments of input, as with film frames. Without it, each brief stimulus would vanish the instant it ended.
13|**Sperling (1960)** measured the **capacity and duration of sensory memory**. **Capacity** is how much information the store can hold, and **duration** is how long it lasts. >> An **array of letters was flashed quickly on a screen**. >> Participants were **asked to report as many letters as possible**. || This is the **partial report experiment**, a task that can be tried directly. >> Because the letters are flashed so briefly, participants cannot keep looking at them while they answer. >> Everything they report has to come from what was held in memory after the display vanished. || Measuring sensory memory is difficult because reporting takes time. >> While a participant names one letter, the memory of the others is fading. >> A low score could therefore reflect a small store or a large store that faded during the report. >> Sperling’s task separates these possibilities by changing how much must be reported and when. Asking for only part of the display, chosen after it disappears, measures how much was available at the start. || Sperling kept the display brief and controlled exactly how much participants had to report. >> The brief flash makes sensory memory the only source of the letters during the report. >> Changing the size of the report separates what was stored from what survived long enough to be named.
14|**Sperling (1960)** used three methods to measure the capacity and duration of sensory memory, each with **an array of letters flashed quickly on a screen**. || **Method 1, the whole report method**. **Participants were asked to report as many letters as they could see**. >> They had to name letters from the whole array after it disappeared. >> The long response gives the memory time to fade before every letter is reported, so the score reflects what can be named before the memory fades. || **Method 2, the partial report method**. **After viewing the items, participants heard a tone that told them which row of letters to report**. >> A high tone signaled the top row, a medium tone the middle row and a low tone the bottom row. >> Participants did not know which row would be tested until after the letters were gone, so they had to hold the whole array in memory. >> Each tone points to four letters, a short enough report to finish before the memory fades. Good performance on whichever row is cued means every row was held in memory. || **Method 3, the delayed partial report method**. This is **the same as partial report, but with a short delay between the display of letters and the tone**. >> The delay gives the sensory memory time to fade before the participant learns which row to report. >> Comparing immediate and delayed cues reveals how quickly sensory memory decays.
15|The **iconic memory** display in **Sperling (1960)** has **three rows of four letters**. >> The top row is **X M L T**, the middle row is **A F N B** and the bottom row is **C D Z P**. >> The whole array flashes and then disappears. || In the **partial report delayed condition**, the tone arrives after a delay and signals the **top row**. >> The participant reports only **M**. >> By the time the tone arrived, the other letters in the top row had faded from sensory memory. || All four letters of the row were registered when the array appeared. >> The cue arrives only after the letters are gone, so the participant cannot look back at the display. Whatever is reported must come from what sensory memory still holds when the tone sounds. >> In immediate partial report, the participant can usually report most letters from the cued row. In delayed partial report, only one or two letters, such as M, remain. || The contrast between immediate and delayed cueing reveals how quickly iconic memory decays. The letters were fully registered at the start, but by the time a delayed cue arrives, most of the row has disappeared. >> Each row holds four letters, and the participant does not know in advance which row will be cued, so accurate report of any cued row requires memory for the entire array.
16|The results of **Sperling (1960)** compare the three methods. >> In the **whole report method**, participants reported an **average of 4.5 out of 12 letters, or 37.5%**. >> In the **partial report method**, participants reported an **average of 3.3 out of 4 letters, or 82%**. **Participants could report any of the rows**, even though they learned which row to report only after the display was gone. >> In the **delayed partial report method**, participants reported an **average of 1 out of 4 letters, or 25%**. || The partial report result reveals how much was available. >> If participants could report 82% of whichever row was cued, about 82% of every row must have been in sensory memory. >> Applying that rate to all three rows gives about 10 letters out of 12, more than twice the 4.5 letters reported in whole report. >> Whole report therefore underestimates capacity. People name only about four or five letters because the rest fade while they are speaking, not because the rest were never stored. || The delayed partial report result reveals how fast the information fades. >> With a delay before the tone, performance dropped to 1 letter out of 4. >> Sensory memory holds a lot, but this rich store lasts well under a second.
17|**Sperling was studying visual sensory memory**, also called **iconic memory**. **Before his study, people thought that visual sensory memory could hold only 4 to 5 items**, the number reported in the full report condition. || **The other conditions in his study showed two things**. >> **It is true that people can only report 4 to 5 items before memory decays**, or fades away. >> **But sensory memory actually encodes the whole scene**. The partial report method revealed that nearly every row was available at first. || The **conclusion** is that **sensory memory has a large capacity but fast decay**. >> **Within just 1 second, most of sensory memory decays**. >> What remains is **only what was moved to short-term memory through attention**. >> The large capacity gives attention a full snapshot to choose from, and the fast decay means attention must choose quickly. Everything else in sensory memory is lost, so attention determines which small part of a rich sensory moment survives. || Sperling’s study therefore overturned the earlier view. The low whole report score reflects decay during the report, not a small store. >> Before his work, the 4 to 5 letters reported in full report were taken as the full capacity of the store. >> The partial report method revealed that nearly the whole scene is encoded, at least for a fraction of a second.
18|The graph plots the **percentage of letters available to the participant** against the **delay of the tone** in seconds. >> With **no delay**, about **82%** of the letters were available in partial report. >> With a **0.1-second** delay, availability dropped to about **60%**. >> With a **0.3-second** delay, it was about **51%**. >> With a **1-second** delay, it was about **39%**. || The **whole report** level, plotted as a separate red square, sits at about **36%**. >> By a delay of about 1 second, partial report has dropped nearly to the whole report level. >> The advantage of cueing a single row has almost disappeared. || The delay is the time between the display and the tone. >> Participants did not see the letters any longer during the delay. >> The decline reflects sensory memory fading after the letters disappeared, which is the fast decay of iconic memory. || The curve also explains why whole report is limited. Naming letters takes longer than iconic memory lasts, so by the time a participant reaches the fifth or sixth letter, the icon has largely faded. >> At no delay, most of the display is available, and within about one-third of a second, availability has fallen sharply.
19|**Short-term memory**, or **STM**, is **the second stage of memory**. It **stores small amounts of information briefly** and is **very sensitive to interruption or interference**. >> A distraction or a competing thought can wipe out what is in short-term memory. >> This is why a phone number can vanish if someone talks to us while we are trying to remember it. Interruption stops rehearsal, and new information can push out or blur what is being held. || **Memory span** is the amount of information STM can hold at once. **STM is limited to holding seven, plus or minus two, bits of information at once**. >> Most people can hold between five and nine items. >> This range is written as **7 ± 2**. || Short-term memory has two separate limits. >> **Capacity** is how much it can hold at once. >> **Duration** is how long information stays available. Interference can shorten duration even when the amount held is well within capacity. >> The 7 ± 2 limit applies to separate units, such as unrelated digits or letters. Grouping items into larger units lets more information fit, because each group counts as one unit.
20|Information is **stored in STM** through several processes. **Recoding** is **reorganizing or modifying information in STM**. >> Recoding changes how the information is represented, such as grouping digits into larger units or turning a string of letters into a familiar acronym. >> A recoded form is often easier to hold and use. || **Maintenance rehearsal** is **repeating information silently to prolong its presence in STM**. >> Repeating a phone number over and over keeps it active. >> Maintenance rehearsal works only while it continues. When repetition stops, the information can fade. || **Elaborative rehearsal** **links new information with existing memories and knowledge in long-term memory**. It is **a good way to transfer information from STM into LTM**. >> Connecting a new fact to an example, a related idea or a personal experience gives it meaning. >> Those connections give memory several paths back to the information, which makes it easier to store and later retrieve. || The three processes differ in depth. >> Recoding changes the form of the information. >> Maintenance rehearsal repeats it without changing it. >> Elaborative rehearsal connects it to existing knowledge, which is why it creates more lasting memory traces than repetition alone.
21|**Short-term memory stores small amounts of information for a brief duration**. It **includes both new information received from the sensory stores and information recalled from long-term memory**. STM is where incoming information and stored knowledge meet. || **STM is responsible for a great deal of our mental lives**. Everyday tasks that depend on it include these. >> **Understanding sentences**, because the beginning of a sentence has to be held while the rest is heard, together with stored word meanings. >> **Doing arithmetic**, because numbers and partial results have to be held while calculating. >> **Dialing a phone number**, because the digits have to be held while pressing keys. >> **Navigating from one place to another**, because a stored mental map has to be combined with what we currently see. >> **Knowing where we are and what we are doing right now**. || **Everything we think about or know at a particular moment involves STM**, **because short-term memory is our window on the present**. >> STM holds the contents of current awareness. >> Long-term knowledge contributes to present thought when it is retrieved into STM. >> Because STM holds the contents of awareness, its limits shape how much we can think about at once. When too much competes for it, some information is lost and performance suffers.

23|Short-term memory raises **two important issues**, just as sensory memory does. >> **Duration** is **how long things stay in memory**. **Rehearsal seems to extend duration**, since repeating information keeps it active longer. >> **Capacity** is **how many things fit in memory at a time**. **Chunking seems to extend capacity**, since grouping items into larger meaningful units lets more fit at once. || **Studying short-term memory is complicated because people use control processes a lot**. >> **Control processes** are strategies a person chooses to use, such as rehearsal and chunking. >> When participants rehearse or chunk, their performance reflects both the store and their strategies. >> Measuring the true duration and capacity of STM therefore requires tasks that block or control these strategies. || The **Brown–Peterson task** measures the duration of short-term memory and can be tried directly. It blocks rehearsal with a demanding distractor task, so the measured forgetting reflects what happens to information when it cannot be refreshed. >> Rehearsal keeps information active longer, and chunking packs more information into each unit, so both make the store look larger or longer-lasting than it is.
24|The **duration of short-term memory** was measured by **Brown (1958)** and **Peterson and Peterson (1959)**. These were **the same studies, done at the same time, with the same results**, which strengthens confidence in the findings. The procedure has four steps. >> **Step 1**. The participant is given **three letters and one number**, such as **F Z L 45**. The three letters, called a **trigram**, are the material to remember. >> **Step 2**. The participant **counts backward from the number by 3s**, as in 45, 42, 39, 36. >> **Step 3**. The counting continues through a **delay of 3 to 18 seconds**. >> **Step 4**. The participant **recalls the three letters**. || Examples of trials include **F Z L 45**, **B H M 87** and **X C G 98**. >> Each trial uses a new trigram and a new starting number. >> Because each trial uses the same procedure, differences between trials come from what happened earlier in the series. || Counting backward by threes is the key feature of the design. >> It requires steady attention and keeps the participant’s inner voice busy. >> It prevents **maintenance rehearsal** of the letters. Without it, participants would simply rehearse the trigram and recall it perfectly. >> Varying the delay from 3 to 18 seconds traces how quickly unrehearsed information is lost.
25|The results of **Brown (1958)** and **Peterson and Peterson (1959)** for the **first trial only** compare recall after a **3-second** delay and an **18-second** delay. The bar graph plots **percent recalled** against **delay**. >> After 3 seconds, recall is very high. >> After 18 seconds, recall is nearly as high, only slightly lower than after 3 seconds. || On the first trial, the letters survive 18 seconds of counting with little loss. >> The participant cannot rehearse during the delay, yet the trigram is still remembered well. >> Time alone causes only a small loss on this trial. || The first trial has no earlier trigrams in the task. >> There are no older letter sets in memory to compete with the current one. >> This nearly equal pair of bars is the baseline for the later trials. If decay were the main cause of forgetting, recall at 18 seconds should be poor even here, so any extra forgetting on later trials must come from something that changes across the series. || The first trial is important for interpreting everything that follows. >> The delay and counting task stay the same on every later trial. >> The large drop at long delays appears only after several trials, which points to interference from earlier trigrams.
26|For the **third trial only**, the results of **Brown (1958)** and **Peterson and Peterson (1959)** look different. >> After a **3-second** delay, recall is still very high. >> After an **18-second** delay, recall is much lower, at a little more than half the 3-second level. || The delay and the counting task are the same as on the first trial. What differs is that the participant has already seen two earlier trigrams. >> Those older letter sets are still in memory. >> When the participant tries to recall the latest letters, letters from previous trials come to mind too. || This competition is **proactive interference**, in which older information disrupts memory for newer information. >> The longer the delay, the more the older trigrams get in the way. >> Only two trigrams separate the first trial from the third, yet this small amount of earlier material produces a large increase in forgetting at the long delay. || The third-trial bars tell a different story from the first trial. >> The 18-second bar is now a little more than half the height of the 3-second bar. >> The correct trigram is harder to retrieve because similar letters from earlier trials compete with it.
27|**Many trials later**, the results of **Brown (1958)** and **Peterson and Peterson (1959)** are more extreme. >> After a **3-second** delay, recall is still very high. >> After an **18-second** delay, recall is close to zero. || By this point, many earlier trigrams have built up in memory. >> Each one is a possible competitor for the current trigram. >> All the letter sets are similar, which makes them easy to confuse. || **Proactive interference** has accumulated across the series. >> At a short delay, the current trigram is still fresh enough to stand out from older ones. >> At a long delay, it has weakened enough that older trigrams win the competition at retrieval. || The comparison across trials separates two causes of forgetting. >> Time alone is the same on the first trial and on later trials, since every long delay lasts 18 seconds. >> What grows across trials is the number of older trigrams in memory, so the extra forgetting on later trials comes from proactive interference. >> Every earlier trigram adds to the competition for retrieval, so the 18-second bar has nearly disappeared while the 3-second bar remains tall. >> Across the first, third and later trials, forgetting in short-term memory depends heavily on interference, in addition to time.
28|**Averaged over all trials**, the results of **Brown (1958)** and **Peterson and Peterson (1959)** show a large drop in recall from the short delay to the long delay. >> After **3 seconds**, recall is very high. >> After **18 seconds**, recall is low, at roughly one-fifth of the 3-second level. || The average combines the first trial, the third trial and the many later trials. >> Early trials contribute high recall at both delays. >> Later trials contribute high recall at 3 seconds and very low recall at 18 seconds. >> The early trials pull the average up, and the later trials pull it down, which is why the averaged 18-second bar sits between the first-trial and many-trials-later results. || The average curve is the result most often reported from these studies, and it was originally taken as evidence of rapid decay. >> Looked at trial by trial, the data reveal that forgetting grows as earlier trigrams pile up. >> The steep average decline comes mostly from later trials, where proactive interference is strongest, so the average hides its role. >> The size of the drop depends heavily on how many trials came before, which an average alone cannot reveal.
29|The studies by **Brown** and **Peterson and Peterson** show that **the percentage of letters recalled decreases with longer delays**. After 18 seconds of counting, fewer letters are recalled than after 3 seconds. || **But this pattern interacts with where in the series of trials the individual trial occurs**. >> **Recall of letters after long delays decreases as the series of trials gets longer**. >> An **interaction** means that the effect of one factor depends on another. Here, the effect of delay depends on trial position. || On the first trial, a long delay costs little. On later trials, a long delay costs a great deal. >> The difference comes from the older trigrams that build up across the series and compete with the current one. >> Pure decay predicts the same loss on every trial, since the delay is always 18 seconds. Interference predicts growing loss as older trigrams accumulate. The data match the interference prediction. || The interaction between delay and trial position is the key finding of these studies. >> Delay and trial position work together. >> The longer the delay and the more trigrams that came before, the worse recall becomes.
30|**Peterson and Peterson** and **Brown** were interested in the **decay** of short-term memory. >> **Decay** is the idea that **a memory trace vanishes because of the passage of time**. >> They expected the letters to fade simply because time passed while rehearsal was blocked. || **It turns out their studies demonstrate another type of forgetting that happens in STM**, which is **proactive interference**. >> **What is already in STM affects the ability to add new things**. >> Older trigrams make it harder to remember the newest one, and forgetting increased with the number of earlier trials, which decay alone cannot explain. || The **larger point** is that **forgetting in STM occurs through both decay and interference**. >> The passage of time weakens memory traces. >> Competing memories make the target harder to retrieve. >> The **effective duration of STM is 15 to 20 seconds** for information that is not rehearsed. Rehearsal can keep information active much longer, which is why we can hold a phone number for as long as we keep repeating it. >> Without rehearsal, decay and interference work together to remove information within about 15 to 20 seconds.
31|**Interference theories** describe forgetting as **“memories interfering with memories.”** >> **Forgetting is not caused by the mere passage of time**. >> It is **caused by one memory competing with or replacing another memory**. >> The more similar two memories are, the more they compete. || There are **two types of interference**. >> **Retroactive interference** occurs when newer information disrupts memory for older information. >> **Proactive interference** occurs when older information disrupts memory for newer information. || The two types are named by the direction of the disruption in time. >> In retroactive interference, the effect works backward, from new to old. >> In proactive interference, the effect works forward, from old to new. >> Both follow the same principle. A memory is harder to retrieve when another similar memory competes with it at the moment of recall. || Interference theories locate the cause of forgetting in the relationships between memories. >> A memory becomes hard to retrieve when other, similar memories compete with it. >> Interference can come from information learned before the target or after it. >> Retroactive interference comes from learning that follows the target, and proactive interference comes from learning that came before it.
32|**Retroactive interference** occurs **when a new memory interferes with remembering old information**. >> On a timeline, the **old** information is learned first and the **new** information comes later. >> An arrow from the new information curves back to the old, because the newer memory reaches back and disrupts the older one. || An **example** is **when a new phone number interferes with the ability to remember an old phone number**. >> After moving and getting a new number, a person tries to recall the old one. >> The new number is rehearsed and used often, so it keeps coming to mind and blocks the old one. || Retroactive interference explains why updating information can make older versions hard to recall. Each time we learn a replacement, such as a new password, a new address or a new phone number, the newer information competes with the older version. >> The new phone number becomes the dominant memory, and the timeline’s arrow points back from it to the old number. >> The target memory is the old number, and the interference is retroactive because the disruption comes from something learned afterward.
33|**Proactive interference** is **the opposite of retroactive interference**. It occurs **when an old memory interferes with remembering new information**. The older memory carries forward and disrupts the newer one. || An **example** is when **memories of where you parked your car on campus over the past week interfere with your ability to find your car today**. >> Today’s parking spot is the target. >> Memories of last week’s spots come to mind instead and make today’s spot harder to recall. >> The more often the routine repeats, the more competitors build up. || **Both proactive and retroactive interference are worst for routine events**. >> Routine events, such as parking in the same lot every day, are very similar to each other, so they are easy to confuse. >> **Unusual events are less prone to interference**. A memorable event, such as the day the car was parked somewhere unusual, has few similar memories to compete with, so it stays easy to retrieve. >> Each day’s parking spot is stored alongside all the earlier ones, so finding today’s car means picking the right memory out of many similar memories.
34|**Not only is information lost rapidly from STM, but there is also a limit to how much information can be held there**. STM has a **capacity limit** as well as a duration limit. Even with no delay, a long list exceeds what short-term memory can keep at once. || **Capacities vary from person to person**, and they are **measured by digit span**. **Digit span** is the number of digits a person can repeat back in the correct order. >> A digit span test presents rows of digits that get longer, such as **2 1 4**, then **3 9 6 7**, then **6 4 9 7 8**, then **7 3 8 2 0 1**. >> The person repeats each row in order. >> As the rows get longer, they eventually exceed what the person can hold. || The digits must be recalled in order, so each digit has to be remembered along with its position in the row. >> The test therefore measures both item and position. >> It provides a standard measure of short-term memory capacity, useful for comparing individuals and for studying what affects capacity. >> Errors begin once the row length passes what short-term memory can hold, so the longest perfect row marks the limit.
35|A full **digit span** test uses rows of increasing length. >> The rows run from four digits, **2 1 4 9**, through **3 9 6 7 8**, **6 4 9 7 8 4**, **7 3 8 2 0 1 5**, **8 4 2 6 1 4 3 2** and **4 8 2 3 9 2 8 0 7**, up to ten digits, **5 8 5 2 9 8 1 6 3 7**. >> Most people recall the shorter rows easily. Errors begin to appear as the rows approach seven digits and become common beyond that. || **The number of digits in the longest row recalled completely correctly is the digit span**. >> Every digit has to be correct and in the right order. >> A row with one digit wrong or out of place does not count, because it means the list has exceeded the person’s capacity. || If a person gets the seven-digit row completely right but makes errors on the eight-digit row, their digit span is **seven**. This scoring measures how much the person can hold in short-term memory at one time.
36|**George A. Miller** wrote **“The Magical Number Seven, Plus or Minus Two,”** subtitled **“Some Limits on Our Capacity for Processing Information,”** reprinted in Psychological Review, volume 101. The paper was first read as an invited address before the Eastern Psychological Association in Philadelphia on **April 15, 1955**. >> Miller opens by saying he has been **persecuted by an integer**. >> For seven years, the number seven had followed him around, showing up in his own data and in published journals. >> The number appeared in many disguises, sometimes a little larger and sometimes a little smaller than usual, but never changing so much as to be unrecognizable. || Miller concluded that the persistence of this number is more than a random accident. >> Across tasks such as judging tones and remembering digits, performance broke down at around seven items. >> Something systematic limits how much information people can process at once, and that limit became the classic estimate of short-term memory capacity. >> The phrase plus or minus two captures individual and task differences. Some people and materials allow a little more, others a little less.
37|**Miller (1956)** proposed that **people can remember 7 ± 2** units. >> These units can be **digits**, **words**, **numbers with multiple digits** or **phrases**. >> A phrase contains several words, and a multidigit number contains several digits, yet each counts as one unit. || **Some researchers have suggested that, rather than describing memory capacity in terms of the “number of items,” it should be described in terms of the “amount of information.”** >> Seven digits and seven phrases are both “seven items,” but seven phrases contain far more words. >> On this view, a complex item takes up more capacity than a simple one. || **Alvarez and Cavanagh (2004)** tested this idea. >> They **used colored squares as well as complex objects**. >> They **used the change detection procedure**, in which participants see a display, then judge whether a second display is the same or different. >> Comparing simple and complex objects reveals whether capacity depends on how much information each object carries. || If memory counted only items, a list of seven digits and a list of seven phrases would be equally easy. >> In practice, the meaningfulness and complexity of each item affect how much can be held. >> Alvarez and Cavanagh’s change detection task measures how many objects of each type participants can hold in visual short-term memory.
38|**There may be multiple, modality-specific, or even domain-specific, forms of short-term memory**. >> **Modality** refers to the type of sensory input, such as vision or hearing. >> **Domain** refers to the type of content, such as words, numbers or spatial locations. >> **How many such forms exist, and how specific they are, is something theorists argue about**. || **Visual short-term memory**, or **VSTM**, holds visual information for a short time after it disappears. >> VSTM is **measured with the change detection task**. >> In this task, VSTM **may have a smaller capacity than memory for lists of digits, unrelated words** and similar material. || Remembering the colors and locations of objects is a different job from repeating a list of spoken words. >> If verbal and visual information use separate stores, each would have its own capacity. >> A smaller capacity for visual objects fits the idea of separate forms of short-term memory. >> Visual short-term memory, measured by change detection, holds fewer items than verbal memory for digits or words, which fits the idea of separate stores, each specialized for one kind of information.
39|In **change detection**, the first display, **S1**, appears for **100 milliseconds**. It contains a set of **colored squares** on a gray background. >> The squares include white, blue, green, red, purple and black squares, scattered at different positions. >> Some colors appear more than once, such as two red squares and two green squares. || Participants have only a tenth of a second to take in the display. >> They need to remember which color was at which location. >> After the display disappears, they must hold this information in **visual short-term memory**. || Because colors repeat, remembering a list of colors is insufficient. Two red squares at different places must be kept distinct, so the task measures memory for color-location pairs, a demanding test of visual short-term memory. || The brief exposure means participants must encode the display quickly and rely entirely on memory for the later comparison. >> Each square has a color and a location. >> Participants need to remember which color appeared at which location. >> A tenth of a second is too short to name the colors, so the display has to be held as a visual snapshot.
40|A simple display of three objects lets us experience the demand of visual short-term memory. >> The display contains a **yellow rectangle** standing upright, a **gray rectangle** lying horizontally and a **blue oval**. >> The objects differ in **color**, **shape**, **orientation** and **location**. || To detect a change, a person needs to remember each object’s properties together. >> The yellow object is the tall rectangle, the gray object is the wide rectangle, and the blue object is the oval. >> Each property has to stay linked to the right object. || A change to any one property, such as a color swap or a rotated rectangle, can only be detected if that property was remembered for that specific object. Linking features to the right object is called binding, and change detection with multi-feature objects tests how well visual short-term memory keeps features bound together. >> If the features come apart in memory, a change such as a swapped color could go unnoticed. >> Remembering three colors and three shapes separately is not enough, since a change can swap which color belongs to which shape.
41|The second display, **S2**, appears for **2,000 milliseconds**. Participants judge whether it is the **same as or different from S1**. >> S2 contains the same set of colored squares at the same positions, except for one change. >> The square in the lower right that was **green** in S1 is now **white** in S2. || To notice the change, the participant has to compare S2 with the memory of S1. >> S1 is gone, so only visual short-term memory can supply the earlier colors. >> Knowing that the display had green squares somewhere is insufficient. The participant needs the color tied to that specific location. || If memory holds the color at every location, the single change stands out. If memory has lost some colors, a change at one of those locations will be missed. >> Accuracy therefore measures how much of S1 survived in visual short-term memory. >> Performance across set sizes reveals how many items it can keep at once. >> The more items participants can hold, the better they detect changes. >> The 2,000-millisecond second display gives plenty of time to judge, so errors reflect memory rather than rushed viewing.
42|The full **change detection** procedure has three phases. >> **S1** appears for **100 milliseconds**. >> A **900-millisecond gap** follows, with a blank screen, so S1 is fully gone and the judgment depends on memory. >> **S2** appears for **2,000 milliseconds**, and the participant judges same or different. || **Panel A** varies the number of colored squares, called the **set size**, from 1 to 12. >> Percent correct stays near **100%** for set sizes up to 3. >> It falls to about **88%** at 4, about **70%** at 8 and about **63%** at 12. >> **Accuracy falls off dramatically when there are more than four items**. **We can hold only about three to four items in visual working memory at a time**. >> This limit is smaller than the 7 ± 2 found for verbal lists, which fits the idea of a separate visual store. || **Panel B** uses colored bars at different angles and compares three kinds of changes. >> In **orientation-only** changes, a bar rotates while keeping its color. >> In **color-only** changes, a bar changes color while keeping its angle. >> In **conjunction** changes, the participant has to remember color and orientation together for each bar. >> For all three, percent correct stays near **95%** at set size 2, about **91%** at 4 and about **78%** at 6. || Remembering two features of each object is about as easy as remembering one. Objects seem to be stored as integrated units, so the limit is set by the number of objects more than by the number of features.
43|**Participants’ ability to make the same/different judgment depended on the complexity of the stimuli**, according to **Alvarez and Cavanagh (2004)**. Panel (a) has four kinds of stimuli. >> **Colored squares**, such as red, green and blue squares. >> **Chinese characters**, such as three simple written forms. >> **Random polygons**, irregular blob-like shapes. >> **Shaded cubes**, three-dimensional cubes with different shading. || Panel (b) plots estimated **capacity**, the number of objects held in visual short-term memory, for each kind of stimulus. >> **Colored squares** have the highest capacity, about **4.4** objects. >> **Chinese characters** have a capacity of about **2.8** objects. >> **Random polygons** have about **2.0** objects. >> **Shaded cubes** have the lowest, about **1.6** objects. || The more complex the stimuli, the fewer of them can be held. >> Each object counts as one item, but complex objects carry more visual detail and use up more of the limited capacity. >> Capacity depends on the **amount of information** in each object, so the same store holds many simple objects or only a few complex ones. This supports the information-based view of capacity. >> Capacity falls step by step from about 4.4 colored squares to about 1.6 shaded cubes, so the limit tracks information load more closely than item count.
44|The same **Alvarez and Cavanagh (2004)** stimuli carry a correction to their labels. The forms labeled **Chinese characters** are circled, with a note in Chinese reading **“These are radicals. And one of them is written wrong.”** >> **Radicals** are components that make up Chinese characters, rather than full characters on their own. >> One of the three forms is also written incorrectly. || The forms still serve their purpose in the study. >> Each is a complex visual shape with its own arrangement of strokes. >> That visual detail is what participants had to hold in memory, and it placed the forms between the simple squares and the complex polygons in difficulty. || The result is unchanged. **Participants’ ability to make the same/different judgment depended on the complexity of the stimuli**. >> Colored squares had a capacity of about 4.4, the written forms about 2.8, random polygons about 2.0 and shaded cubes about 1.6. >> Visual short-term memory holds fewer objects as the objects carry more information. >> The capacity pattern across all four stimulus types holds regardless of the labeling issue. >> The labeling issue concerns what the forms are called, and it leaves their visual complexity, the property the study measured, unchanged.
45|**We can hold much more in short-term memory when things are organized into chunks**. **Chunking** is **combining smaller units into larger meaningful units to improve capacity**. >> A chunk counts as one unit in short-term memory, even if it contains several pieces. >> The phone number 555-5100, for example, can be held as a few groups rather than seven separate digits. >> A chunk is meaningful because it connects to knowledge already stored in long-term memory, so more knowledge allows larger chunks. || **Ericsson and coworkers (1980)** trained a **college student** who reached a **digit span of 79** after training. >> The student was a runner. >> He **chunked digits into meaningful times for running**, a sport he was familiar with. >> A typical span is about seven. His short-term memory still held only a handful of units, but each unit was a running time containing several digits, so the total number of digits grew enormously. || **Chase and Simon (1973)** found that **chess players chunk information based on meaningful positions within a game of chess**. >> Experienced players see a board as familiar groups of pieces. >> Each group acts as one chunk, so they can remember far more pieces than a beginner.
46|**Chase and Simon (1973)** compared **chess masters** and **beginners** on the number of **correct piece placements** they could recall after briefly viewing a chessboard. || With **meaningful arrangements**, positions that could occur in a real game, the master recalled far more pieces than the beginner. >> The master’s bar is roughly three times as tall as the beginner’s. >> Real positions match patterns stored in long-term memory, so the master can store them as chunks. || With **random arrangements**, pieces placed without regard to the rules of chess, the master and the beginner performed about the same, and both recalled few pieces. >> Random placements match no stored patterns. >> The master must store each piece separately, just as the beginner does, so the advantage disappears. || The study separates the role of knowledge from the role of memory capacity. >> If masters simply had better memories, they would outperform beginners on random boards too. >> The master’s skill comes from **chunking based on chess knowledge**, while the master’s short-term memory itself is about the same size as the beginner’s. >> Chess knowledge supplies ready-made chunks for real positions, while random positions offer no chunks, so expertise gives no advantage there.
47|**Control processes** are **active processes that can be controlled by the person**. They turn short-term memory from a passive store into an active system. >> **Maintenance rehearsal** is **repeating a stimulus over and over** to keep it active. >> **Strategies used to make a stimulus more memorable**, such as linking it to things we already know. >> **Strategies of attention that help us focus on specific stimuli**, selecting what enters and stays in short-term memory. || **Building a “memory palace” is an ancient strategy for making information more memorable**. >> A memory palace is a familiar place imagined in the mind, such as a building with many rooms. >> Items to remember are placed at locations along a route through the building. >> The places are already stored in long-term memory, so they provide ready-made cues. Walking through the building in the mind later brings each item back in order. || Looking closely at the different control processes that short-term memory needs leads to the idea of **working memory**. Working memory is short-term memory understood as an active workspace, where information is held and manipulated at the same time. >> Maintenance rehearsal keeps information active, memory strategies organize it for later recall, and attentional strategies select what enters short-term memory.
