PSYCH 301  ·  Ch. 5  Short-Term Memory
Sperling (1960): Iconic Memory
SENSORY MEMORY
What’s the point?
●Sperling was studying visual sensory memory
●Before his study, people thought that visual sensory memory could only hold 4-5 items (full report 
cond)
●The other conditions in his study showed that
–
It’s true that people can only report 4-5 items before memory decays (or fades away)
–
BUT sensory memory actually encodes the whole scene
Conclusion: Sensory Memory has a large capacity, but fast decay
Within just 1 second, most of sensory memory decays, leaving only what was moved to STM via attention.
