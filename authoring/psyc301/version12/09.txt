2|**Memory** is the set of processes involved in **retaining, retrieving and using information** about stimuli, images, events, ideas and skills **after the original information is no longer present**. The book has been closed, the conversation has ended or the event is over, and yet information from it is still available to us. >> Memory covers all kinds of content, from a picture we saw to a skill we practiced. >> The defining feature is that the information outlasts the experience that produced it. || Memory is **active any time some past experience has an impact on how we think or behave now or in the future**. Memory is the past affecting the present, and possibly the future. >> Recognizing a friend’s face, finishing a familiar song and riding a bike all draw on earlier experience. >> Memory is therefore at work in almost everything we do, well beyond deliberately trying to recall a list. || **Endel Tulving** describes **episodic memory**, our memory for personally experienced events, as a kind of **“mental time travel.”** >> When we remember an episode, we mentally return to the time and place where it happened. >> The event itself is long gone, but remembering brings its details back into present thought. || Memory links the past to both the present and the future. Information about earlier experience shapes what we expect, how we interpret new events and what we choose to do next. >> When we meet a familiar person, memory supplies their name and our shared history, which guides how we greet them. >> When we plan tomorrow, memory supplies what happened in similar situations before, which shapes the plan. >> Episodic memory carries the details of time and place, so remembering an event brings back where and when it happened as well as what happened.
3|**Memory is an active system** that **stores, organizes, alters and recovers information**. Recovering information from memory is called **retrieval**. >> Memory reorganizes and changes information as it is stored and used. >> Each act of remembering works with this organized, changing record. || Three key terms describe the stages of memory. >> **Encoding** is **converting information into a usable form for storage**. When we encounter something, we build a mental representation of it that memory can hold. >> **Storage** is **holding this information in memory** over time. >> **Retrieval** is **taking memories out of storage** so they can be used again. || The three stages answer different questions. >> Encoding concerns how the memory is formed in the first place. >> Storage concerns how the memory is kept. >> Retrieval concerns how the memory is accessed when it is needed. || The distinction between short-term and long-term memory has a parallel in computing. Computer scientists had to think much harder about short-term versus long-term memory when **RAM**, a computer’s fast working memory, maxed out at **16KB**. >> A small, fast working store holds what is in use right now, while a much larger store holds everything else. || The three key terms describe a sequence that every lasting memory passes through. Information first has to be encoded, then stored, and then retrieved when it is needed. >> A failure at any stage leads to forgetting. If information is never encoded, there is nothing to store. If it is stored but cannot be retrieved, it is present in memory but unavailable when we need it. >> Because memory organizes and alters information, a retrieved memory reflects how the information was encoded and organized, along with the original experience. || The comparison with early computers captures the difference between a small working store and a large storage system. A computer’s fast memory holds only what is being used at the moment, while larger storage holds everything else. Human memory has a similar division between a small store for current use and a vast store for lasting knowledge.
4|The **tree of memory** organizes the different kinds of memory into a hierarchy. At the top is **memory**, which branches into **sensory**, **short-term** and **long-term memory**. >> **Sensory memory** holds the effects of stimulation for a very brief moment. >> **Short-term memory** holds a small amount of information for immediate use. >> **Long-term memory** holds a very large amount of information for long periods. >> Sensory and short-term memory are grouped together as the brief, limited-capacity stores. || **Long-term memory** divides into **declarative** and **procedural memory**. >> **Declarative memory** is memory for facts and events, the kind of knowledge we can state or describe. >> **Procedural memory** is memory for skills and how to do things, such as tying shoes or typing. >> The difference is between knowing that something is true and knowing how to do something. || **Declarative memory** divides further into **episodic** and **semantic memory**. >> **Episodic memory** holds personally experienced events, such as a particular birthday party. >> **Semantic memory** holds general facts and knowledge, such as the capital of France. >> Both are kinds of declarative knowledge stored in long-term memory. || The tree separates memory systems by how long they hold information and by what kind of information they hold. The branches at the top differ in duration and capacity, while the branches under long-term memory differ in content. >> Sensory and short-term memory are brief and limited, so they handle information that is in use right now. >> Long-term memory is lasting and very large, so it holds everything we know and can do. || The divisions within long-term memory matter because each kind is used differently. >> We can describe declarative memories in words, such as recalling a vacation or stating a fact. >> Procedural memories show up in performance, such as riding a bike smoothly, even when we cannot explain every step.
5|The **modal model of memory**, proposed by **Atkinson and Shiffrin (1968)**, describes **three types of memory** connected in a flow of information. >> **Sensory memory** is the **initial stage**, which **holds all incoming information for seconds or fractions of a second**. >> **Short-term memory** **holds five to seven items for about 15 to 20 seconds**. >> **Long-term memory** **can hold a large amount of information for years or even decades**. || The flow diagram traces information through the system. >> **Input** from the environment enters **sensory memory**. >> Selected information passes from sensory memory into **short-term memory**. >> Information in short-term memory can be stored in **long-term memory**, and stored information can be retrieved back into short-term memory. >> **Output**, such as a response or an action, comes from short-term memory. || **Rehearsal** is a **control process**, an activity the person carries out on the contents of memory. >> In the diagram, rehearsal is a loop around short-term memory. >> Repeating information keeps it active in short-term memory and helps transfer it into long-term memory. || The modal model describes memory as a flow of information through stages. Each stage keeps only part of what it receives, so information is filtered as it moves forward. >> Sensory memory receives everything from the senses, but most of it fades almost immediately. >> Attention selects a small part for short-term memory, where it can be used and rehearsed. >> Rehearsal and other processing can transfer information into long-term memory, where it can last for decades. || The model also explains why we remember only a fraction of what we experience. Information that never receives attention never reaches short-term memory, and information that is never processed further stays out of long-term memory. The stages differ greatly in capacity, from the brief, broad sensory store to the small short-term store to the vast long-term store. || The model’s numbers describe each store. Sensory memory holds information for seconds or fractions of a second. Short-term memory holds five to seven items for about 15 to 20 seconds. Long-term memory holds a large amount of information for years or decades. >> The capacities grow from the small short-term store to the vast long-term store. >> The durations grow from a fraction of a second to a lifetime.
6|The modal model applies to the everyday task of looking up and calling a phone number. In the first step, a person looks at a computer screen full of listings. **All the information on the screen enters sensory memory**. >> Sensory memory registers the whole display at once, including every name and number on the screen. >> In the flow diagram, the **sensory** box is highlighted, with input arrows pointing into it. || Sensory memory holds this broad registration only briefly. >> Most of the listings on the screen are never used. >> They fade from sensory memory within moments. || Only part of what sensory memory registers moves on to the next stage. >> The person needs just one number. >> The other stages of the model describe what happens to that one number. || The phone-number example walks through the modal model one step at a time. Each step highlights one stage of memory and the process that moves information from one stage to the next. >> The person needs one number from a screen full of listings, so most of the incoming information is irrelevant to the task. >> Sensory memory takes in the whole screen without selection, and attention will soon pick out the one number that matters. || Sensory memory therefore acts as a brief buffer. It holds the full scene long enough for attention to choose what to keep. Everything that attention ignores fades away, which keeps short-term memory from being flooded with information the task does not need.
7|In the second step, the person **focuses on 555-5100**, and **it enters short-term memory**. **Attention** selects this one number from everything registered in sensory memory. >> In the flow diagram, the arrow runs from sensory memory to **STM**, and the STM box is highlighted. >> The selected number becomes the content the person is actively working with. || Selection narrows the information to what the task requires. >> The screen contained many numbers. >> Short-term memory now holds just the one needed for the call. || Sensory memory and short-term memory play different roles. >> Sensory memory briefly registers everything that reaches the senses. >> Short-term memory holds the selected item so it can guide what the person does next. >> The selected number now guides what the person does next. Every other listing on the screen stays behind in sensory memory and fades within moments, while 555-5100 stays available for the call. || Attention is the gateway between sensory memory and short-term memory. Information becomes available for thinking and action only after attention selects it. >> When the person focuses on 555-5100, the number moves from a brief sensory trace into a form the person can work with. >> The other listings were registered by the senses but never entered short-term memory. || This selection matters because short-term memory has a small capacity. Holding every number on the screen would overwhelm it. By choosing only the relevant number, attention keeps short-term memory free for the information the task actually requires.
8|In the third step, the person **rehearses the number to keep it in short-term memory while making the phone call**. Repeating “555-5100, 555-5100” is **maintenance rehearsal**. >> In the flow diagram, a circular **rehearsal** arrow loops around STM. >> An arrow labeled **remember number to make call** runs out of STM, since the rehearsed number guides dialing. || The number is the content of short-term memory, and rehearsal is the process that keeps it there. >> Rehearsal refreshes the number each time it is repeated. >> This lets the person hold the number after looking away from the screen. || Rehearsal bridges the gap between reading the number and finishing the call. >> The person keeps the digits active while pressing each key in turn. >> The rehearsed number supplies the sequence of actions needed to dial. || Maintenance rehearsal keeps information alive in short-term memory by repeating it. Each repetition refreshes the number before it can fade, so the person can keep using it for as long as the repetition continues. >> If the person is interrupted and stops repeating the number, it can be lost within seconds. >> Rehearsal therefore extends the duration of short-term memory, though only while it continues. || Short-term memory guides behavior directly, which the output arrow in the model represents. The rehearsed number is what the person uses to press each key, so short-term memory links stored information to action.
9|In the fourth step, the person **memorizes the number**, and it is **stored in long-term memory**. In the flow diagram, an arrow labeled **storage** runs from STM into **LTM**, and the LTM box is highlighted. >> Once stored, the number stays available long after the call is over. >> The person no longer needs the screen or constant repetition to keep it. || Short-term and long-term storage play different roles for the same number. >> Short-term memory held it for immediate use during the call. >> Long-term memory keeps it across days or weeks, ready for future calls. || Information encountered during one activity becomes lasting knowledge. >> The original call ends, but the number remains. >> That stored representation links today’s experience with future use. || Storing the number in long-term memory changes how it can be used. The number no longer depends on constant rehearsal and can be recalled on a later day. >> Memorizing involves processing the number so that it leaves a lasting record, rather than simply repeating it for the moment. >> Once stored, the number joins the large body of knowledge held in long-term memory. || The arrow labeled storage points from short-term memory into long-term memory. This direction marks the transfer of information from temporary use into lasting knowledge, which is how experiences become part of what we know.
10|In the fifth step, the person **retrieves the number from long-term memory**. **It goes back to short-term memory and is remembered**. >> In the flow diagram, an arrow labeled **retrieval** runs from LTM back to STM. >> STM is labeled **awareness**, since retrieved information enters current awareness. >> An arrow labeled **remember number to make call again** runs out of STM. || **Retrieval** makes stored information available for current use. >> The person does not need to look up the number again. >> The stored number returns to short-term memory, where its digits guide dialing. || Information flows in both directions between short-term and long-term memory. >> New information moves from short-term memory into long-term storage. >> Stored information moves from long-term memory back into short-term memory whenever it is needed. || Retrieval completes the cycle of the modal model. Information that was stored earlier returns to short-term memory, where it becomes part of current awareness and guides action again. >> The number moves from long-term memory back into short-term memory when the person wants to call again. >> In short-term memory, the retrieved number can be rehearsed and used to dial, just as the newly seen number was. || The model labels short-term memory with awareness because whatever is in short-term memory is what we are currently thinking about. Long-term memory holds information outside awareness until retrieval brings it back into use.
11|**Sensory memory** is **storing an exact copy of incoming information for less than a second**. It is **the first stage of memory**. >> The copy is exact because it preserves the raw sensory input before it has been interpreted or selected. >> It lasts less than a second, so most of it disappears almost immediately. || Sensory memory has different forms for different senses. >> An **icon** is **a fleeting mental image or visual representation**. It is visual sensory memory, a brief afterimage of what we just saw. >> An **echo** is **a brief continuation of a sound in the auditory system after the sound is heard**. It is auditory sensory memory. >> Icons hold what we see, and echoes hold what we hear. Both keep the input available for a moment after the stimulus is gone. || Sensory memory is the first stage of the modal model, and it differs from later stages in two ways. It holds information for less than a second, and it holds an exact, unprocessed copy of the input. >> Because the copy is exact, sensory memory preserves details that have not yet been interpreted or selected. >> Because it lasts so briefly, it gives attention only a moment to choose what to keep. || Icons and echoes keep sensory input available just long enough for further processing. A visual scene can be briefly examined after it disappears, and a sound can be briefly replayed in the auditory system, such as when we catch the end of a sentence we were not fully attending to.
12|**Sensory memory** is **the retention, for brief periods of time, of the effects of sensory stimulation**. **Information decays very quickly**. >> **Decay** means the stored information fades away with the passage of time. || **Persistence of vision** is **the retention of the perception of light**. >> When a **sparkler** is waved in the dark, we see a **trail of light**. The sparkler is only at one point at a time, but visual sensory memory holds its recent positions, so the points blend into a line. >> In **film**, separate **frames** are shown one after another. Persistence of vision holds each frame briefly as the next one arrives, so we perceive smooth motion. >> A demonstration from **Mr. Wizard’s World** uses a spinning card with letters, such as **M, ZA, DS, W** and **L**, on its two sides. When the card spins quickly, the letters from both sides are seen together. || Sensory memory **holds a large amount of information for a short period of time**. It plays three roles. >> It **collects information** from the senses. >> It **holds information for initial processing**, giving the brain time to work on it. >> It **fills in the blanks** between separate moments of input, as with film frames. || Sensory memory lets the brain treat separate moments of input as continuous experience. Without it, each brief stimulus would vanish the instant it ended. >> In film, frames are shown one after another with brief gaps. Visual persistence holds each frame long enough for the next one to arrive, so we see smooth movement instead of flickering still images. >> The sparkler’s trail and the spinning-card demonstration from Mr. Wizard’s World rely on the same effect. Information from one moment combines with the next, so separate images are perceived together. || Sensory memory holds a large amount of information but loses it very quickly. Its role is to collect input, hold it briefly for initial processing and fill in the gaps between separate moments of stimulation.
13|**Sperling (1960)** measured the **capacity and duration of sensory memory**. **Capacity** is how much information the store can hold, and **duration** is how long it lasts. >> An **array of letters was flashed quickly on a screen**. >> Participants were **asked to report as many letters as possible**. || This is the **partial report experiment**, a task that can be tried directly. >> Because the letters are flashed so briefly, participants cannot keep looking at them while they answer. >> Everything they report has to come from what was held in memory after the display vanished. || Reporting letters takes time. >> While a participant names one letter, the memory of the others is fading. >> Sperling’s task separates how much is initially stored from how fast it fades by changing how much must be reported and when. || Sperling’s question was how much information sensory memory holds and how long it lasts. Answering it is difficult, because reporting what we saw takes time, and sensory memory fades while we report. >> A participant who names letters one by one may lose the rest before reaching them. >> A low score could therefore reflect a small store or a large store that faded during the report. || The partial report experiment separates these possibilities. By asking for only part of the display, and choosing that part after the display has disappeared, it measures how much information was available at the start, before fading could take its toll. || Sperling designed his method around this problem. He kept the display brief, so participants could not keep looking at the letters while they answered, and he controlled exactly how much they had to report. >> The brief flash makes sensory memory the only source of the letters during the report. >> Changing the size of the report separates what was stored from what survived long enough to be named.
14|**Sperling (1960)** used three methods to measure the capacity and duration of sensory memory, each with **an array of letters flashed quickly on a screen**. || **Method 1, the whole report method**. **Participants were asked to report as many letters as they could see**. >> They had to name letters from the whole array after it disappeared. >> The long response gives the memory time to fade before every letter is reported. || **Method 2, the partial report method**. **After viewing the items, participants heard a tone that told them which row of letters to report**. >> A high tone signaled the top row, a medium tone the middle row and a low tone the bottom row. >> Participants did not know which row would be tested until after the letters were gone, so they had to hold the whole array in memory. || **Method 3, the delayed partial report method**. This is **the same as partial report, but with a short delay between the display of letters and the tone**. >> The delay gives the sensory memory time to fade before the participant learns which row to report. >> Comparing immediate and delayed cues reveals how quickly sensory memory decays. || The three methods differ in how much must be reported and when the participant learns what to report. Comparing them reveals both the capacity and the duration of sensory memory. >> Whole report asks for everything at once, so its score reflects what can be named before the memory fades. >> Partial report asks for one row, chosen after the display disappears, so its score reflects how much of the whole display was available at the start. >> Delayed partial report adds a wait before the tone, so its score reflects how much remains after a short delay. || Because the tone comes after the letters are gone, the participant cannot focus on one row in advance. Good performance on whichever row is cued means that every row was held in memory when the tone sounded. || The tone method also lets Sperling vary timing precisely. The tone can sound immediately after the display or after a short delay, so the same task measures sensory memory at different moments after the letters vanish. >> A high tone signals the top row, a medium tone the middle row and a low tone the bottom row. >> Each tone points to four letters, a short enough report to finish before the memory fades.
15|The **iconic memory** display in **Sperling (1960)** has **three rows of four letters**. >> The top row is **X M L T**, the middle row is **A F N B** and the bottom row is **C D Z P**. >> The whole array flashes and then disappears. || In the **partial report delayed condition**, the tone arrives after a delay and signals the **top row**. >> The participant reports only **M**. >> By the time the tone arrived, the other letters in the top row had faded from sensory memory. || The single letter **M** reflects how much of the top row survived the delay. >> All four letters of the row were registered when the array appeared. >> Waiting before the cue left just one letter available for report. >> The cue arrives only after the letters are gone, so the participant cannot simply look back at the display. Whatever the participant reports must come from what sensory memory still holds at the moment the tone sounds. || Each row in the display holds four letters, and the participant does not know in advance which row will be cued. Accurate report of any cued row therefore requires memory for the entire array. >> In immediate partial report, the participant can usually report most letters from the cued row. >> In delayed partial report, the wait before the tone allows the sensory trace to fade, so only one or two letters, such as M, remain. || The contrast between immediate and delayed cueing reveals how quickly iconic memory decays. The letters were fully registered at the start, but by the time a delayed cue arrives, most of the row has already disappeared from sensory memory.
16|The results of **Sperling (1960)** compare the three methods. >> In the **whole report method**, participants reported an **average of 4.5 out of 12 letters, or 37.5%**. >> In the **partial report method**, participants reported an **average of 3.3 out of 4 letters, or 82%**. **Participants could report any of the rows**, even though they learned which row to report only after the display was gone. >> In the **delayed partial report method**, participants reported an **average of 1 out of 4 letters, or 25%**. || The partial report result reveals how much was available. >> If participants could report 82% of whichever row was cued, about 82% of the whole array must have been in sensory memory. >> That is far more than the 4.5 letters reported in whole report. || The delayed partial report result reveals how fast the information fades. >> With a delay before the tone, performance dropped to 1 letter out of 4. >> Sensory memory holds a lot, but it loses it very quickly. || The three results fit together into a clear picture. Whole report measures how much can be reported before the memory fades. Partial report measures how much was available at the start, and delayed partial report measures how fast that information disappears. >> Partial report performance of 82% means participants had access to most of the twelve letters at the start, roughly ten letters. >> That is more than twice the 4.5 letters reported in whole report. >> The drop to 25% with a delay means most of that information was lost within a fraction of a second. || Whole report underestimates the capacity of sensory memory. People can name only about four or five letters because the rest fade while they are speaking, not because the rest were never stored. || The numbers make the logic concrete. If participants report 3.3 of the 4 letters in whichever row is cued, they must have had about 82% of every row available. Applying that rate to all three rows gives about 10 letters out of 12. >> Ten available letters compared with 4.5 reported letters reveals how much is lost during whole report. >> The 25% delayed score reveals that this rich store lasts well under a second.
17|**Sperling was studying visual sensory memory**, also called **iconic memory**. **Before his study, people thought that visual sensory memory could hold only 4 to 5 items**, the number reported in the full report condition. || **The other conditions in his study showed two things**. >> **It is true that people can only report 4 to 5 items before memory decays**, or fades away. >> **But sensory memory actually encodes the whole scene**. The partial report method revealed that nearly every row was available at first. || The **conclusion** is that **sensory memory has a large capacity but fast decay**. >> **Within just 1 second, most of sensory memory decays**. >> What remains is **only what was moved to short-term memory through attention**. >> Attention picks out a few items to keep, and the rest of the scene is lost. || Sperling’s study overturned the earlier view of visual sensory memory. Before his work, the 4 to 5 letters reported in full report were taken as the full capacity of the store. >> The partial report method revealed that nearly the whole scene is encoded. >> The low whole report score reflects decay during the report, not a small store. || The study also clarified the role of attention. Only the information that attention moves into short-term memory survives beyond the first second. Everything else in sensory memory is lost, so attention determines which small part of a rich sensory moment becomes part of continued thought. || The conclusion links capacity and decay. A large capacity means sensory memory can take in a whole scene at once, while fast decay means that scene is available only briefly. >> The large capacity gives attention a full snapshot to choose from. >> The fast decay means attention must choose quickly, before the snapshot fades.

19|**Short-term memory**, or **STM**, is **the second stage of memory**. It **stores small amounts of information briefly** and is **very sensitive to interruption or interference**. >> A distraction or a competing thought can wipe out what is in short-term memory. >> This is why a phone number can vanish if someone talks to us while we are trying to remember it. || **Memory span** is the amount of information STM can hold at once. **STM is limited to holding seven, plus or minus two, bits of information at once**. >> Most people can hold between five and nine items. >> This range is written as **7 ± 2**. || Short-term memory has two separate limits. >> **Capacity** is how much it can hold at once. >> **Duration** is how long information stays available. Interference can shorten duration even when the amount held is well within capacity. || Short-term memory is limited in both duration and capacity, and it is easily disrupted. Information held there can be lost when attention shifts to something else. >> Interruption stops rehearsal, so the information fades. >> Interference from new information can push out or blur what is being held. || The limit of 7 ± 2 items describes how much short-term memory can hold at one time. This limit applies to separate units of information, such as unrelated digits or letters. Grouping items into larger units can let more information fit, because each group counts as a single unit.
20|Information is **stored in STM** through several processes. **Recoding** is **reorganizing or modifying information in STM**. >> Recoding changes how the information is represented, such as grouping digits into larger units. >> A recoded form is often easier to hold and use. || **Maintenance rehearsal** is **repeating information silently to prolong its presence in STM**. >> Repeating a phone number over and over keeps it active. >> Maintenance rehearsal holds information in STM for as long as the repetition continues. || **Elaborative rehearsal** **links new information with existing memories and knowledge in long-term memory**. It is **a good way to transfer information from STM into LTM**. >> Connecting a new fact to things we already know gives it meaning. >> Those connections make the new information easier to store and later retrieve. || The three processes for storing information in short-term memory differ in depth. Recoding changes the form of the information, maintenance rehearsal repeats it, and elaborative rehearsal connects it to existing knowledge. >> Recoding can make information more compact, such as turning a string of letters into a familiar word or acronym. >> Maintenance rehearsal works only while it continues. When repetition stops, the information can fade. >> Elaborative rehearsal links new information to what we already know, which creates lasting memory traces. || Elaborative rehearsal is the better route into long-term memory. Connecting a new term to an example, a related idea or a personal experience gives memory several paths back to the information, which makes it easier to retrieve later.
21|**Short-term memory stores small amounts of information for a brief duration**. It **includes both new information received from the sensory stores and information recalled from long-term memory**. >> STM is where incoming information and stored knowledge meet. >> Current thinking draws on both. || **STM is responsible for a great deal of our mental lives**. Everyday tasks that depend on it include these. >> **Understanding sentences**, because the beginning of a sentence has to be held while the rest is heard. >> **Doing arithmetic**, because numbers and partial results have to be held while calculating. >> **Dialing a phone number**, because the digits have to be held while pressing keys. >> **Navigating from one place to another**, because the route and recent turns have to be held. >> **Knowing where we are and what we are doing right now**. || **Everything we think about or know at a particular moment involves STM**, **because short-term memory is our window on the present**. >> STM holds the contents of current awareness. >> Long-term knowledge contributes to present thought when it is retrieved into STM. || Short-term memory is where current thinking happens. It holds information arriving from the senses and information retrieved from long-term memory, and it combines them to guide what we do. >> Understanding a sentence uses stored word meanings retrieved from long-term memory together with the words just heard. >> Navigation combines a stored mental map with what we currently see around us. || Because short-term memory holds the contents of awareness, its limits shape how much we can think about at once. When too much information competes for short-term memory, some of it is lost, and performance on the current task suffers.

23|Short-term memory raises **two important issues**, just as sensory memory does. >> **Duration** is **how long things stay in memory**. **Rehearsal seems to extend duration**, since repeating information keeps it active longer. >> **Capacity** is **how many things fit in memory at a time**. **Chunking seems to extend capacity**, since grouping items into larger meaningful units lets more fit at once. || **Studying short-term memory is complicated because people use control processes a lot**. >> **Control processes** are strategies a person chooses to use, such as rehearsal and chunking. >> When participants rehearse or chunk, their performance reflects both the store and their strategies. >> Measuring the true duration and capacity of STM therefore requires controlling the strategies people use. || The **Brown–Peterson task** measures the duration of short-term memory and can be tried directly. || Duration and capacity can both be stretched by control processes. Rehearsal keeps information active longer, and chunking packs more information into each unit. >> This makes short-term memory hard to measure directly, because participants naturally rehearse and chunk to improve their performance. >> To measure the store itself, researchers have to design tasks that block or control these strategies. || The Brown–Peterson task takes this approach to duration. It blocks rehearsal with a demanding distractor task, so the measured forgetting reflects what happens to information when it cannot be refreshed.
24|The **duration of short-term memory** was measured by **Brown (1958)** and **Peterson and Peterson (1959)**. These were **the same studies, done at the same time, with the same results**. The procedure has four steps. >> **Step 1**. The participant is given **three letters and one number**, such as **F Z L 45**. The three letters, called a **trigram**, are the material to remember. >> **Step 2**. The participant **counts backward from the number by 3s**, as in 45, 42, 39, 36. >> **Step 3**. Rehearsal, strategies for making information memorable and attentional strategies are all chosen and directed by the person. >> Maintenance rehearsal keeps information active. >> Memory strategies, such as a memory palace, organize information for later recall. >> Attentional strategies select what enters and stays in short-term memory. || The memory palace works by linking each item to a familiar location in a well-known place. Because the places are already stored in long-term memory, they provide ready-made cues for recall, and walking through them in the mind brings each item back in order.
