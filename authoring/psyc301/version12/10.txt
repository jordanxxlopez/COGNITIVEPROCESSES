2|The **modal model** view of short-term memory turned out to be **too simple**. **Short-term memory is not just passive storage**. It also requires **“control processes,”** so a model is needed that includes them. >> **Control processes** are the active operations we perform on information, such as selecting, repeating and transforming it. >> The modal model treated short-term memory mainly as a holding place, with information sitting there until it was used or lost. || **Baddeley and Hitch (1974)** proposed **working memory**, a concept similar to short-term memory but broader. **Working memory** is a **limited-capacity system for the temporary storage and manipulation of information for complex tasks such as comprehension, learning and reasoning**. >> **Storage** keeps information available for a short time. >> **Manipulation** means actively working with that information, such as changing it, combining it or using it in a calculation. || Complex tasks need both functions at once. >> **Comprehension** requires holding the start of a sentence while relating it to the words that follow. >> **Learning** requires keeping new information active while connecting it to what we already know. >> **Reasoning** requires holding facts in mind while working toward a conclusion. || Working memory changed the picture of short-term memory from a waiting room into a workspace. In the modal model, short-term memory mainly held information on its way to long-term storage or to a response. In the working memory model, the same limited space is where information is actively used. >> Holding a phone number long enough to dial it is mostly storage. >> Comparing two prices while deciding what to buy requires holding both and working with them at once. || The phrase limited capacity matters because storage and manipulation share the same resources. When a task demands a lot of processing, less room remains for holding information, and when a lot must be held, less room remains for processing. This trade-off explains why complex mental tasks become harder as more information must be juggled at once.
3|**Multiplying 43 times 6 in your head** requires storage and active processing at the same time. \[43\times6=258\] The steps run as follows. >> **Step 1. Visualize 43 × 6**, holding the whole problem in mind. >> **Step 2. Multiply 3 × 6**, which gives 18. \[3\times6=18\] >> **Step 3. Hold the 8 in memory** as the ones digit of the answer, **while carrying the 1 over to the 4**. >> **Step 4. Multiply 6 × 4 = 24, then add the carried 1 to get 25**. \[6\times4=24,\qquad24+1=25\] >> **Step 5. Combine the 25 with the 8** being held, which gives **258**. || This operation involves both **storage** and **active processes**. >> Holding the 8 in memory while the rest of the calculation continues is storage. >> Carrying the 1, multiplying and adding are active processes that change the information. >> The 8 has to survive while the other operations are carried out, so the calculation depends on storage and processing working together. This combination is what working memory provides. || The mental multiplication example breaks one familiar task into its working memory demands. Each step either holds information, changes information or does both. >> Visualizing 43 × 6 keeps the whole problem available so each step can refer back to it. >> Multiplying 3 × 6 produces a result that has to be split into the 8 to keep and the 1 to carry. >> Multiplying 6 × 4 and adding the carried 1 requires holding the carry while computing the new product. >> Combining 25 with the stored 8 requires retrieving the 8 after several intervening steps. || The calculation fails if any stored piece is lost. Forgetting the 8 while working on the tens, or forgetting to add the carried 1, produces a wrong answer. This makes mental arithmetic a clear test of working memory, since success depends on holding intermediate results while new operations are carried out.
4|**Short-term memory**, in the model of **Atkinson and Shiffrin**, and **working memory**, in the model of **Baddeley and Hitch**, differ in their structure and purpose. || **Short-term memory** in the Atkinson and Shiffrin model has two key features. >> It is a **single component for all types of information**, so words, pictures and sounds all go into the same store. >> It is **mainly used for holding information for a short time**. || **Working memory** in the Baddeley and Hitch model has **three components**. >> The **central executive**, which directs and coordinates the system. >> The **visuospatial sketchpad**, which holds visual and spatial information. >> The **phonological loop**, which holds verbal and auditory information. >> A fourth component, the **episodic buffer**, was **added by Baddeley in 2000**. || Working memory is **used for the manipulation of information during complex cognition**. >> Short-term memory emphasizes holding information. >> Working memory emphasizes using it, with separate parts for different kinds of information and a control system that manages them. || The two models differ in how they divide temporary memory. Atkinson and Shiffrin describe one store for all kinds of information. Baddeley and Hitch describe separate components for verbal and visual information, plus a control system. >> A single store predicts that any two tasks held in memory at once should interfere with each other. >> Separate components predict that a verbal task and a visual task can be done together with little interference, since each uses its own store. || The working memory model also changes the purpose of the system. Short-term memory in the modal model is mainly about holding information for a short time. Working memory is about using information during complex thinking, such as reasoning, comprehension and learning. The episodic buffer, added in 2000, extends the model further by giving it a place to combine information from different sources.
5|Each **component of working memory** has its own job. || The **phonological loop** handles verbal and auditory information. It has two parts. >> The **phonological store** **holds verbal and auditory information**, such as words and speech sounds. >> The **articulatory rehearsal process** is **responsible for rehearsal that keeps items in the phonological store from decaying**. **Articulatory** refers to the movements of speech, so this process works by silently saying the items over and over. >> Without rehearsal, items in the phonological store fade within a few seconds. || The **visuospatial sketchpad** **holds visual and spatial information**. >> Visual information concerns what things look like, such as shape and color. >> Spatial information concerns where things are and how they are arranged. || The **central executive** **pulls information from long-term memory, coordinates the other components, and directs and maintains attention**. >> In the diagram of **Baddeley’s working memory model**, the central executive sits in the middle, overlapping with the phonological loop, which holds **verbal and auditory information**, on one side and the visuospatial sketchpad, which holds **visual and spatial information**, on the other. >> The central executive is the control center that manages the two storage components. || Each component handles a different kind of information or a different job. The phonological loop works with sounds and words, the visuospatial sketchpad works with images and locations, and the central executive directs both. >> The phonological store fades within a few seconds unless its contents are refreshed. >> The articulatory rehearsal process refreshes them by silently repeating the sounds, much like an inner voice. >> The visuospatial sketchpad holds a mental picture, such as the layout of a room or the shape of an object. || The central executive does not store information itself. It decides what the storage components hold, brings in knowledge from long-term memory and keeps attention on the task. The Venn diagram places the executive between the two stores, overlapping each, because it coordinates both of them.
6|The **working memory model of Baddeley and Hitch (1974)** traces how information flows through the system. >> **Input** from the environment enters **sensory memory**. >> From sensory memory, information passes to the **central executive**. >> The central executive exchanges information in both directions with **long-term knowledge**. || The central executive also exchanges information in both directions with the **phonological loop** and the **visuospatial sketchpad**. >> Arrows run up and down between the executive and each storage component. >> Long-term knowledge also connects directly with both the phonological loop and the visuospatial sketchpad. || Working memory is a set of interacting parts. >> The executive controls what each storage component holds and does. >> The storage components can draw on long-term knowledge, so stored facts, word meanings and familiar images contribute to what is held and processed. || The flow diagram shows working memory as part of a larger memory system. Information from the senses passes through sensory memory to the central executive, which sends it to the phonological loop or the visuospatial sketchpad depending on its type. >> Verbal information, such as a spoken word, goes to the phonological loop. >> Visual information, such as a shape, goes to the visuospatial sketchpad. || The two-way arrows with long-term knowledge are important. Working memory constantly draws on stored knowledge, such as word meanings and familiar images, and it can also send new information into long-term storage. This exchange lets working memory interpret new input in light of what we already know.
7|Three effects reveal how the **phonological loop** works. || The **phonological similarity effect** is that **letters or words that sound similar are confused**. >> **Phonological** refers to the sounds of language. >> Items that sound alike, such as the letters B, D and G, are easy to mix up in memory because their sound codes overlap. || The **word-length effect** is that **memory for lists of words is better for short words than for long words**. >> **It takes longer to rehearse long words and to produce them during recall**. >> In the same amount of time, fewer long words can be rehearsed, so fewer stay active. || **Articulatory suppression** is when **speaking interferes with rehearsal, so memory is reduced**. >> Saying something out loud, such as repeating “the, the, the,” uses the articulatory rehearsal process. >> With rehearsal taken up, the items being remembered are not refreshed and fade from the phonological store. || The three effects provide evidence that the phonological loop exists and works by sound. Each effect would be hard to explain if verbal information were stored in a visual or meaning-based form. >> Items are stored by their sounds, so sound-alike items are confused, which is the phonological similarity effect. >> Rehearsal takes time, so longer words fit less well, which is the word-length effect. >> Rehearsal uses the speech system, so speaking blocks it, which is articulatory suppression. || Together, the effects describe how the loop operates. Verbal information is held as sounds in the phonological store, and it is kept alive by an inner voice that repeats it. When the inner voice is slow, busy or confused by similar sounds, memory suffers.
8|The **phonological similarity effect** is that **words that sound similar are confused by people**. **Conrad (1964)** tested this with letters. || The **setup** worked as follows. >> **Participants saw target letters that were quickly flashed**. >> **Half of the time the letters were similar, and half of the time they were not**. >> **Then participants wrote them down**. || The **observation** was in the errors. **Mistakes were made**, and they followed a clear pattern. >> Participants were **unlikely to replace a letter with one that looked like the target**, such as writing **F** instead of **E**. >> They were **likely to replace it with one that sounded like the target**, such as writing **B** instead of **E**. The names “E” and “B” share the same vowel sound. || The **interpretation** is that participants remembered the letters by their sounds. >> The letters were seen, not heard. >> Even so, the errors were based on sound, so the letters were held in a sound-based code in the phonological loop. || Conrad’s experiment reveals how visually presented letters are stored. If letters were held as images, errors should involve letters that look alike, such as F and E. Instead, errors involved letters that sound alike, such as B and E. >> The letters E and B share the same vowel sound when their names are spoken. >> E and F share many visual strokes but have different-sounding names. || The comparison between similar and dissimilar sets strengthens the conclusion. Lists of letters with similar-sounding names produced more errors than lists of letters with distinct-sounding names. Sound similarity, not visual similarity, made the letters hard to keep apart in memory.
9|The **phonological similarity effect experiment** **demonstrated the phonological similarity effect**, in which **people confuse letters that sound similar**, **even though the information was presented visually**. >> The letters reached the participants through their eyes. >> They were still confused by sound, not by appearance. || The experiment **also showed that the phonological loop is necessary for the conversion**, **not just for holding information**. >> Seen letters are converted into their spoken names. >> The phonological loop carries out this conversion and then holds the sound-based code. || The phonological loop has two roles. >> It translates visual input, such as written letters and words, into sound. >> It stores and rehearses that sound code, which is why sound-based confusions appear for visually presented items. || The phonological similarity effect for visual letters reveals an automatic recoding step. People do not have to decide to name letters silently. Reading a letter calls up its spoken name, and that name is what gets held. >> Recoding turns a visual input into a phonological code. >> The phonological code is then stored and rehearsed by the phonological loop. || This conversion is why phonological confusion appears even for written material. The phonological loop is involved at two points, first in translating written letters into sound and then in holding the sound-based code until recall.
10|The **word-length effect** is that **when memorizing words, you can remember fewer words if the words are long**. >> **People remembered more of the short words than the long words**, according to **Baddeley and colleagues (1975, 1984)**. >> Long words take longer to say, so fewer can be rehearsed in the time before they fade. || **Welsh–English bilingual children** have a **shorter digit span in Welsh than in English**, according to **Ellis and Hennelly (1980)**. >> The reason is that **Welsh numbers take longer to pronounce**. >> The children know the same numbers in both languages. The only difference is how long the words take to say. >> The very long Welsh place name **Llanfairpwllgwyngyllgogerychwyrndrobwllllantysiliogogogoch** is a famous example of how long Welsh words can be. || **The number of words you can say in 1.5 to 2.0 seconds is likely to be your digit span**. >> The phonological loop holds about as much as can be rehearsed in that window. >> Faster speech means more items fit, which ties memory span to speaking time rather than to a fixed number of items. || The word-length effect links memory span to speaking speed. The phonological loop holds about as much as can be rehearsed in the time before its contents fade, roughly 1.5 to 2 seconds. >> Short words such as one-syllable nouns can be rehearsed quickly, so many fit within that window. >> Long words such as multisyllable names take longer to say, so fewer fit. || The Welsh–English comparison provides an especially clean test. The same children counted the same numbers in two languages. Because Welsh number names take longer to pronounce, the children could hold fewer of them in the phonological loop, which gave them a shorter digit span in Welsh than in English.
11|**Articulatory suppression** is what happens **if you speak while memorizing**, which **keeps the phonological loop busy**. >> **You get worse at remembering**. >> **The word-length and phonological similarity effects are reduced**. || The **word-length effect is reduced** because rehearsal is blocked. >> Normally, short words are remembered better because they can be rehearsed faster. >> When speaking takes over the rehearsal process, neither short nor long words get rehearsed, so the advantage for short words shrinks. || The **phonological similarity effect is also reduced** because the conversion into sound is blocked. >> Normally, seen letters are converted into sound codes, which leads to sound-based confusions. >> When the phonological loop is busy, visually presented letters are not converted into sound, so sound similarity no longer matters as much. || These results **support the concept of a phonological loop**. >> One specific activity, speaking, removes both effects at once. >> Both effects therefore depend on the same speech-based system, which is the phonological loop. || Articulatory suppression provides a direct test of the phonological loop. Asking people to say something irrelevant, such as repeating “the, the, the,” occupies the speech system that rehearsal needs. >> With rehearsal blocked, memory for word lists drops. >> The advantage for short words shrinks, because short words no longer benefit from faster rehearsal. >> The confusion of sound-alike letters shrinks for visual presentation, because seen letters are no longer converted into sound. || These results are what the model predicts. A single manipulation that blocks the inner voice removes both effects that depend on it. This pattern supports the idea that rehearsal and recoding both use the same speech-based system.
12|The **visuospatial sketchpad** **holds visual and spatial information**. >> **Visual** information is about appearance, such as shape and color. >> **Spatial** information is about location and arrangement. || The sketchpad is **involved in the process of visual imagery**. >> **Visual imagery** is creating or holding a picture in the mind without seeing it. >> Imagining the layout of a room, or picturing a shape and rotating it, uses the visuospatial sketchpad. || In the working memory model, the sketchpad connects with the **central executive** and with **long-term knowledge**. >> The executive directs what the sketchpad holds. >> Long-term knowledge supplies stored images and spatial layouts that can be brought into the sketchpad. || Because the sketchpad and the phonological loop are separate components, a visual task and a verbal task can be carried out together with little interference. >> Holding a picture in the sketchpad leaves the phonological loop free for words. >> Holding words in the phonological loop leaves the sketchpad free for images and locations. || The visuospatial sketchpad supports tasks that require picturing things in the mind. Planning a route, imagining how furniture would fit in a room and mentally rotating an object all use it. >> Visual imagery holds what something looks like. >> Spatial imagery holds where things are and how they relate to one another.
13|The **sentence experiment** of **Brooks (1968)** tests the **phonological loop** and the **visuospatial sketchpad**. || The **setup** worked as follows. >> Participants **memorized a sentence**. >> They then went through the sentence word by word and **indicated whether each word was or was not a noun**. >> In **condition 1**, they **indicated by speaking**, saying “yes” or “no.” >> In **condition 2**, they **indicated by pointing** to yes or no on a sheet. || The **result** was that **pointing was easier than speaking for the participants**. || The **explanation** is that **the phonological loop was busy processing the sentence, but the sketchpad was free**. >> The sentence is verbal, so it was held in the phonological loop. >> Speaking the answers also uses the phonological loop, so it competed with the sentence. >> Pointing uses the visuospatial sketchpad, which was free, so there was no competition. || Brooks used two kinds of responses to test which component the sentence task needs. Holding a sentence and classifying its words uses the phonological loop, so a second verbal task should interfere and a spatial task should not. >> When participants spoke their answers, the verbal response competed with the verbal sentence. >> When they pointed, the spatial response used the sketchpad and left the phonological loop to the sentence. || The task itself was identical in both conditions. Only the response changed, which isolates the effect of response type. The difference in difficulty therefore reflects competition for the same component of working memory.
14|The **“F” demo** of **Brooks (1968)** tests the same two components, but with a picture instead of a sentence. || The **setup** worked as follows. >> Participants **memorized a shape**, in this case a block **F**. >> Starting from a corner marked with a star, they mentally traced around the F and **indicated whether each corner was an “inside corner” or an “outside corner.”** >> In **condition 1**, they **indicated by speaking**, saying “in” or “out.” >> In **condition 2**, they **indicated by pointing**, working down a list of corners numbered 1 to 10 and pointing to **OUT** or **IN** in each row. || The **result** was that **speaking was easier than pointing**, **the opposite of the sentence experiment**. || The **explanation** is that **the sketchpad was busy with the image, but the phonological loop was free**. >> The F is a visual image, so it was held in the visuospatial sketchpad. >> Pointing to locations on a sheet also uses the sketchpad, so it competed with the image. >> Speaking uses the phonological loop, which was free, so there was no competition. || The F task reverses the materials of the sentence task. Participants now hold a visual image instead of a sentence, so the visuospatial sketchpad is busy and the phonological loop is free. >> Tracing the corners of the F means moving around a mental image one corner at a time. >> Pointing to OUT or IN on a printed sheet requires looking and moving the hand to locations, which uses the same spatial resources. >> Saying “out” or “in” uses the phonological loop and leaves the sketchpad free for the image. || The reversal is the most important feature of Brooks’s design. Speaking was harder for the sentence and easier for the image, while pointing was easier for the sentence and harder for the image. A single store could not produce this crossover pattern.
15|**Tasks are easier when the information held in mind and the operation performed on it involve different types of short-term memory**. The two types are **verbal or phonological** and **visual or spatial**. >> In the sentence task, a verbal memory paired with a spatial response, pointing, was easy. >> In the F task, a visual memory paired with a verbal response, speaking, was easy. >> When the memory and the response used the same system, performance suffered. || **The two types of short-term memory are therefore somewhat independent**. >> **At the least, they have separate capacities**. >> Filling the phonological loop leaves room in the visuospatial sketchpad, and filling the sketchpad leaves room in the phonological loop. || Each component interferes with itself much more than with the other. >> Two verbal demands compete, and two visual-spatial demands compete. >> A verbal demand paired with a visual-spatial one leaves both running smoothly, which supports treating the phonological loop and the visuospatial sketchpad as separate components of working memory. || The two Brooks tasks together form a double pattern of interference. Verbal memory suffers from a verbal response, and visual memory suffers from a spatial response, but each is spared when paired with the other type. >> This pattern points to separate verbal and visual-spatial capacities. >> Each capacity can be filled without using up the other. || This principle has practical consequences. Two tasks that use the same component interfere, while two tasks that use different components can run side by side. Listening to directions while driving uses both systems, and the parts that overlap are where trouble arises.

17|**Mental rotation** is the ability to turn a mental image to a new orientation. **Shepard and Metzler (1971)** showed participants pairs of three-dimensional objects built from cubes and asked whether the two objects were the same object or mirror images. >> In **picture-plane rotation** pairs, one object is rotated flat within the plane of the page, like turning a clock face. >> In **depth rotation** pairs, one object is rotated in depth, as if turned around a vertical axis. >> In some pairs, the objects are mirror images that cannot be rotated into a match. || The **results** for the picture-plane pairs plot reaction time, **RT**, in seconds against the **angle of rotation** in degrees, from 0 to 180. >> At **0 degrees**, the RT is about **1 second**. >> RT rises in a straight line as the angle grows. >> At **180 degrees**, the RT is about **4.5 seconds**. || The **interpretation** is that participants **mentally rotated** one object to compare it with the other. >> A bigger difference in angle requires a longer mental rotation. >> The straight-line relationship means each extra degree of rotation adds about the same amount of time, as if the image were turned at a steady speed. >> Mental rotation is a clear example of active manipulation in the visuospatial sketchpad. || Mental rotation reveals that the visuospatial sketchpad can transform images, not just hold them. Participants turned one object in their minds until it lined up with the other, then compared them. >> The objects in each pair were the same shape or mirror images. >> Mirror images could never be rotated into a match, so their recognition depended on completing the rotation. || The rotation is continuous, so reaction time increases in a straight line with the angle. A rotation of 160 degrees takes longer than a rotation of 80 degrees, roughly in proportion to the angle. The mental image seems to pass through intermediate orientations, much as a real object would when turned. Depth rotation produced the same linear pattern, so the mental image is treated as a three-dimensional object.
18|The **central executive** **does the “work” of working memory**. Its jobs include the following. >> **Directing and maintaining attention**, which includes **focusing**, **dividing** and **switching** attention. >> **Controlling suppression of irrelevant information**, so that distractions do not take up working memory. >> **Coordinating the sketchpad and the phonological loop**, so that both can contribute to a task. >> **Performing calculations**, as in mental arithmetic. || Today, the central executive is **often split into updating, shifting and inhibition**, following **Miyake and colleagues (2000)**. >> **Updating** is replacing old information in working memory with new, relevant information. >> **Shifting** is switching between tasks or mental sets. >> **Inhibition** is suppressing unwanted thoughts or responses. || **The idea of a “central executive” is often criticized as theorizing a “homunculus” in the brain**. >> A **homunculus** is a “little person” inside the head who makes all the decisions. >> Saying that a central executive controls everything describes the control without explaining how it works. >> Splitting the executive into updating, shifting and inhibition gives specific, testable functions in place of a single controller. || The central executive controls the flow of information in working memory. It decides what to attend to, what to ignore and how to divide limited resources between the phonological loop and the visuospatial sketchpad. >> Focusing attention keeps the task-relevant information active. >> Dividing attention splits resources between two tasks. >> Switching attention moves resources from one task to another. || The homunculus criticism highlights a real weakness in early versions of the model. If the executive simply does whatever needs doing, it explains nothing. Miyake and colleagues addressed this by identifying three measurable functions, updating, shifting and inhibition, that can be studied separately and shown to differ between people.
19|The **episodic buffer** is **a fourth component, added to the working memory model by Baddeley in 2000**. >> It has a **limited capacity of about 4 “chunks.”** A **chunk** is a meaningful unit of information, which can contain several pieces. >> It **binds information from the phonological loop, the visuospatial sketchpad and long-term memory into integrated “episodes.”** **Binding** means linking different pieces of information into one combined memory. || In the updated diagram, the **central executive** sits at the top, connected to the **phonological loop**, the **episodic buffer** and the **visuospatial sketchpad** below it. >> The episodic buffer sits in the middle, connected to both the phonological loop and the visuospatial sketchpad. >> All three connect down to **long-term knowledge**. || Two findings showed **why the episodic buffer was needed**. >> **People can recall about 16 words of a meaningful sentence**, **far beyond their span for unrelated words**. Meaning and grammar bind the words into larger chunks, which the original model had no place to hold. >> **Some amnesic patients can immediately recall a just-heard story**. **Amnesia** is a severe loss of long-term memory. These patients could not store the story in long-term memory, so the story must have been held in a working memory component large enough for meaningful material. || The episodic buffer solves problems that the original three components could not handle. Some information is too large or too integrated to fit in either the phonological loop or the visuospatial sketchpad alone. >> A meaningful sentence of 16 words is far longer than the phonological loop can hold as separate words. >> Meaning and grammar bind the words into a few large chunks, and the episodic buffer holds these chunks. || The buffer connects working memory with long-term knowledge. It pulls in stored meaning to organize new information into episodes, which is why amnesic patients can briefly recall a story they cannot store for the long term. The story is held in the buffer as a meaningful episode, even though it cannot be transferred into lasting memory.
20|**Working memory and the brain** can be studied through **individual differences**, the ways people differ from one another. **Vogel and colleagues (2005)** first **determined participants’ working memory capacity** and divided them into a **high-capacity group** and a **low-capacity group**. They then **measured ERP responses**. >> An **ERP**, or **event-related potential**, is the brain’s electrical activity recorded from the scalp, time-locked to events in a task. || Participants were **shown either simple or complex stimuli**. Each trial had four phases. >> A **cue** arrow, shown for **200 milliseconds**, pointed left or right to indicate which side of the display to remember. >> A **memory display** of colored bars at different angles appeared for **100 milliseconds**. >> A blank **delay**, the retention interval, lasted **900 milliseconds**. >> A **test display** appeared for **2,000 milliseconds**, and participants judged whether the orientation of a red bar had changed. || In the **simple** condition, the cued side contained only **red bars**, the targets to remember. >> In the **complex** condition, the cued side contained red bars plus **blue bars**, which were **distractors** to be ignored. >> Comparing the conditions tests how well people keep irrelevant items out of working memory. || The Vogel study links working memory capacity to brain activity. The researchers first sorted participants into high-capacity and low-capacity groups, then recorded their brain responses during a visual memory task. >> The task required remembering the orientations of red bars on the cued side of a display. >> In some trials, blue bars appeared alongside the red bars and had to be ignored. >> ERPs during the 900-millisecond delay tracked how much information each person was holding. || The key question was what happens to distractors. If a person filters out the blue bars, brain activity should reflect only the red bars. If a person lets the blue bars in, brain activity should rise as if more items were being held.
21|In **panel b** of the **Vogel and colleagues (2005)** results, brain activity during the task is plotted separately for **high-capacity** and **low-capacity** participants in three conditions. >> **Two items**, two red bars to remember. >> **Four items**, four red bars to remember. >> **Two items with two distractors**, two red bars plus two blue bars to ignore. || **Activity continues well into the retention interval**, after the memory display has disappeared. >> This activity reflects the items being held in visual working memory. >> More items held means more activity. || For **high-capacity** individuals, **activity is greater when there are four relevant items than when there are two relevant items**. >> **Adding irrelevant blue items has no effect**. Activity with two targets and two distractors looks like activity with two targets alone. >> High-capacity people keep the distractors out of working memory. || For **low-capacity** individuals, **adding irrelevant items increases activity**. >> Activity with two targets and two distractors rises to nearly the level of four targets. >> Low-capacity people let the distractors into working memory, where they take up space meant for the targets. || The ERP results reveal how high-capacity and low-capacity people differ. The activity during the retention interval reflects how much is being held in visual working memory. >> High-capacity people show more activity for four red bars than for two, as expected. >> When two blue distractors are added to two red bars, their activity stays at the two-item level, because the distractors are kept out. >> Low-capacity people show a rise in activity when distractors are added, nearly reaching the four-item level, because the distractors get in. || The difference between groups is not mainly in raw storage space. It lies in how well each group controls what enters working memory. Low-capacity people waste part of their limited space on items they were told to ignore.
22|In **panel c** of the **Vogel and colleagues (2005)** results, each participant’s **memory capacity** is plotted against their **filtering efficiency**. >> **Filtering efficiency** is an **EEG** measure of how well a person keeps irrelevant items out of working memory. **EEG** records electrical activity of the brain from the scalp. >> Memory capacity runs from about 1 to 4 items, and filtering efficiency from 0 to 1. || **Capacity is correlated with the EEG measure of filtering efficiency**. >> The points rise from lower left to upper right, and a line drawn through them slopes upward. >> **People with higher capacity are also less distracted by the irrelevant items**. || This changes how differences in working memory capacity are understood. >> High capacity reflects how well a person controls what enters working memory, along with how much it can hold. >> People with high capacity filter out distractors, which leaves their limited space free for relevant information. >> People with low capacity let distractors in, which fills their working memory with items that are not needed. || The correlation in panel c ties the two measures together across individuals. Each point is one person, plotted by memory capacity and filtering efficiency. >> People who hold more items also filter distractors more effectively. >> People who hold fewer items let more distractors through. || This finding reframes individual differences in working memory. High capacity depends partly on attentional control, the ability to keep irrelevant information out. Improving that control could free up working memory for the information that matters.
