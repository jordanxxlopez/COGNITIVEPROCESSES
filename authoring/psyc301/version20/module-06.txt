2|**Memory** is the set of processes we use to **retain, retrieve and use information** about stimuli, images, events, ideas and skills **after the original information is no longer present**. When the book is closed or the conversation has ended, whatever we took from it is still available to us, and that lasting availability is what memory provides. >> Memory covers every kind of content, from a picture we once saw to a skill we have practiced for years. >> What defines it is that the information outlasts the experience that produced it. || Memory is **active any time some past experience has an impact on how we think or behave now or in the future**. We can think of memory as the past reaching into the present, and often into the future as well. >> Recognizing a friend, finishing a familiar song and riding a bike all depend on what we experienced earlier. >> Planning for tomorrow also draws on memory, because we rely on what happened in similar situations before. || **Endel Tulving** described **episodic memory**, which is our memory for events we personally lived through, as a kind of **“mental time travel.”** The phrase captures how remembering an episode carries us back to the time and place where it happened. >> The event itself is over, but remembering it brings back where it happened, when it happened and what took place.
3|**Memory is an active system** that **stores, organizes, alters and recovers information**, and the recovery step is called **retrieval**. Because memory reorganizes information while storing and using it, a remembered event reflects how it was encoded and organized as well as what actually happened. || Three key terms describe the stages that every lasting memory passes through. Each stage is a separate place where memory can succeed or fail. >> **Encoding** means **converting information into a usable form for storage**, so when we meet something new we build a mental representation that memory can hold. >> **Storage** means **holding this information in memory** over time. >> **Retrieval** means **taking memories out of storage** so that they can be used again. || Forgetting can happen at any one of these three stages. Thinking in stages helps us ask where a particular memory failure began. >> If information is never encoded in the first place, there is nothing for memory to store. >> If information is stored but cannot be retrieved, it is still in memory but out of reach when we need it. || Computing offers a useful parallel for the difference between short-term and long-term memory. Computer scientists had to think hard about this split when a computer’s fast working memory, called its **RAM**, maxed out at **16KB**. >> A small, fast store holds whatever is in use at the moment, while a much larger store holds everything else. >> Human memory has a similar division between a small active store and a large lasting one.
4|The **tree of memory** arranges the different kinds of memory into a hierarchy. At the top, **memory** branches into **sensory**, **short-term** and **long-term memory**, and these three differ in how long they hold information and how much they can hold. >> **Sensory memory** keeps the effects of stimulation for a very brief moment. >> **Short-term memory** keeps a small amount of information ready for immediate use. >> **Long-term memory** keeps a very large amount of information for long periods of time. || **Long-term memory** divides into **declarative** and **procedural memory**, which differ in the kind of knowledge they hold. The contrast is between knowing that something is true and knowing how to do something. >> **Declarative memory** is memory for facts and events, the kind of knowledge we can put into words. >> **Procedural memory** is memory for skills such as tying shoes or typing. It shows up in how smoothly we perform, even when we cannot explain each step. || **Declarative memory** divides again into **episodic** and **semantic memory**. Both can be described in words, but they differ in whether the knowledge is tied to a personal experience. >> **Episodic memory** holds events we personally experienced, such as a particular birthday party. >> **Semantic memory** holds general facts and knowledge, such as the capital of France.
5|The **modal model of memory**, proposed by **Atkinson and Shiffrin (1968)**, describes **three types of memory** that are linked in a flow of information. Each store hands information on to the next, and each one has its own capacity and duration. >> **Sensory memory** is the **first stage**, and it **holds all incoming information for seconds or fractions of a second**. >> **Short-term memory** **holds five to seven items for about 15 to 20 seconds**. >> **Long-term memory** **can hold a large amount of information for years or even decades**. || Information moves through the model in a fixed order. **Input** from the environment enters sensory memory first, and the information we attend to passes on into short-term memory. >> From short-term memory, information can be stored in long-term memory, and stored information can later be retrieved back into short-term memory. >> Our **output**, such as a spoken answer or an action, comes from short-term memory. || **Rehearsal** is a **control process**, which means it is an activity the person chooses to carry out on the contents of memory. Repeating information keeps it active in short-term memory, and repetition also helps move it into long-term memory. >> Because rehearsal is a choice, people can use it more or less, and that changes how much they keep. || Each stage keeps only part of what it receives. Most of what reaches sensory memory fades almost at once, and information we never attend to never reaches short-term memory. Information that we never process further also stays out of long-term memory. >> The model therefore explains forgetting as information that is lost somewhere along this path.
6|The modal model can be applied to the everyday task of looking up and calling a phone number. In the first step, a person looks at a screen full of listings, and **all the information on the screen enters sensory memory**. >> Sensory memory takes in the whole display at once, including every name and every number. >> At this point nothing has been selected yet. || This broad snapshot lasts only a moment. The person needs a single number, so nearly everything on the screen is irrelevant to the task, and the unused listings fade from sensory memory within moments. >> Losing the rest of the screen is not a problem, because the task never needed it. || Sensory memory therefore acts as a brief buffer. It holds the full scene just long enough for attention to choose what to keep, and everything attention ignores simply fades away. This arrangement keeps short-term memory from being flooded with information that the task does not need. >> A brief, complete snapshot gives attention the freedom to choose, without forcing the person to hold everything.
7|In the second step, the person **focuses on 555-5100**, and **it enters short-term memory**. **Attention** picks this one number out of everything that sensory memory registered. >> The chosen number becomes the information the person is actively working with. >> The rest of the listings stay behind in sensory memory and fade. || Attention works as the gateway between the two stores. Sensory memory briefly takes in everything that reaches the senses, while short-term memory holds only what attention selects so that it can guide the next action. >> Without attention, information never crosses from the brief store into the active one. || Selection matters because short-term memory is small. Trying to hold every number on the screen would overwhelm it, so attention keeps only the number the task requires and leaves short-term memory free to do its job. >> The small size of short-term memory is the reason a selective gateway is needed at all.
8|In the third step, the person **rehearses the number to keep it in short-term memory while making the phone call**. Saying “555-5100” over and over to oneself is called **maintenance rehearsal**. >> Each repetition refreshes the number before it has a chance to fade. >> The person can then look away from the screen and still keep the number in mind. >> As each key is pressed, the rehearsed number supplies the next digit. || Rehearsal extends how long information lasts in short-term memory, but only while the rehearsal continues. If someone interrupts and the repetition stops, the number can be gone within seconds. >> Here short-term memory guides behavior directly, because it links the stored number to the act of dialing.
9|In the fourth step, the person **memorizes the number**, and the number is **stored in long-term memory**. Once it is stored, the number stays available long after the call is over. >> The person no longer needs the screen or constant repetition to keep the number. || Short-term and long-term memory play different roles for this same number. Short-term memory held it for immediate use during the call, while long-term memory keeps it for days or weeks so that it is ready for future calls. >> The two stores are not rivals, since each one handles a different time scale of use. || Memorizing means processing the number deeply enough that it leaves a lasting record, rather than just repeating it for the moment. Storage is the step at which a passing piece of information becomes part of what we know. >> This is why a number we only repeated is often gone the next day, while a number we memorized stays with us.
10|In the fifth step, the person **retrieves the number from long-term memory**, and **it goes back to short-term memory and is remembered**. Short-term memory is the place of **awareness**, since whatever it holds is what we are thinking about right now. >> The retrieved number can then be rehearsed and dialed, just like a number read off a screen. || **Retrieval** makes stored information available for current use. The person does not need to look the number up again, because long-term memory has been holding it outside awareness until retrieval brings it back. >> A memory that is stored but never retrieved cannot guide what we do in the moment. || Information therefore flows in both directions between the two stores. New information moves from short-term memory into long-term storage, and stored information moves back into short-term memory whenever we need it. >> Short-term memory is where new input and old knowledge come together during a task.
11|**Sensory memory** stores **an exact copy of incoming information for less than a second**, and it is **the first stage of memory**. The copy is exact because it keeps the raw input before anything has been interpreted or selected. >> Sensory memory lasts so briefly that attention has only a moment to choose what to keep. || Each sense has its own form of sensory memory. An **icon** is **a fleeting mental image or visual representation**, which is visual sensory memory, a brief trace of what we just saw. An **echo** is **a brief continuation of a sound in the auditory system after the sound is heard**, which is auditory sensory memory. >> The words icon and echo name the visual and auditory versions of the same brief store. || Icons and echoes keep input available just long enough for further processing. A visual scene can be briefly inspected after it disappears, and a sound can be briefly replayed. >> This replay is how we sometimes catch the end of a sentence that we were not fully listening to.
12|**Sensory memory** is **the retention, for brief periods of time, of the effects of sensory stimulation**. In sensory memory, **information decays very quickly**, and **decay** means that stored information fades as time passes. >> Fast decay is the price of holding so much raw input at once. || **Persistence of vision** is **the retention of the perception of light**, and several everyday experiences depend on it. When a **sparkler** is waved in the dark, we see a **trail of light**, because visual sensory memory holds the sparkler’s recent positions and they blend into a line. >> The sparkler is only ever in one spot at a time, so the trail exists in memory rather than in the world. >> In **film**, separate **frames** are shown one after another with brief gaps. Each frame lingers in sensory memory while the next one arrives, so we see smooth motion instead of a flicker of still pictures. >> In a demonstration from **Mr. Wizard’s World**, a card with letters such as **M, ZA, DS, W** and **L** on its two sides is spun quickly. The letters from both sides are then seen together, because each side lingers while the other appears. || Sensory memory **holds a large amount of information for a short period of time**, and it does three jobs. It **collects information** from the senses, it **holds information for initial processing** so the brain has time to work on it, and it **fills in the blanks** between separate moments of input. >> Filling in the blanks is exactly what happens between the frames of a film.
13|**Sperling (1960)** measured the **capacity and duration of sensory memory**. **Capacity** is how much the store can hold, and **duration** is how long the information lasts. >> In his task, **an array of letters was flashed quickly on a screen**. >> Participants were **asked to report as many letters as possible**. || This procedure is the **partial report experiment**, and anyone can try a version of it directly. The letters vanish too quickly for anyone to keep looking at them, so whatever participants report must come from memory after the display is gone. >> The task therefore measures memory rather than ongoing perception. || Measuring sensory memory is tricky because reporting takes time. While a participant names one letter, the others are fading, so a low score could mean that the store is small or that a large store faded during the report. >> The two explanations predict the same low score, so a simple report cannot tell them apart. || Sperling solved this problem by controlling how much participants had to report and when they learned what to report. If the instruction came before the display, participants could look only at the letters they needed. Giving the instruction after the display forces the whole array to be held, so the report measures the store itself. >> The timing of the instruction is what turns a simple report into a measure of capacity.
14|**Sperling (1960)** used three methods, and each one flashed **an array of letters quickly on a screen**. The methods differ in what participants had to report and when they found out. >> Comparing the three methods lets the size of the store be separated from the speed of its decay. || In the **whole report method**, **participants were asked to report as many letters as they could see**. They had to name letters from the entire array after it disappeared. Naming many letters takes time, so the memory fades before the report is finished. >> Whole report therefore mixes the size of the store with how fast it empties. || In the **partial report method**, **participants heard a tone after viewing the items, and the tone told them which row of letters to report**. A high tone meant the top row, a medium tone meant the middle row and a low tone meant the bottom row. >> The tone came only after the letters were gone, so participants had to hold the whole array in memory. >> Each row had just four letters, which is a report short enough to finish before the memory fades. >> Good performance on whichever row was cued means that every row was being held. || The **delayed partial report method** is **the same as partial report, but with a short delay between the display of letters and the tone**. The delay lets the memory fade before the participant learns which row to report. >> Comparing immediate and delayed cues reveals how quickly sensory memory decays.
15|The **iconic memory** display in **Sperling (1960)** has **three rows of four letters**. The top row is **X M L T**, the middle row is **A F N B** and the bottom row is **C D Z P**, and the whole array flashes briefly and then disappears. >> Twelve letters is more than people can name before the image fades. || In the **delayed partial report** condition, the tone comes after a delay and signals the **top row**, and the participant reports only **M**. All four letters of that row were registered when the array appeared, but by the time the tone arrived the other three had faded. >> One surviving letter out of four matches the typical delayed result. || The cue always arrives after the letters are gone, so the participant cannot look back at the screen. With an immediate cue, most letters in the cued row can usually be reported, but with a delayed cue only one or two remain. >> The contrast reveals how fast iconic memory fades. >> The letters were fully registered at the start, yet most were lost before a delayed cue could point to them.
16|The results of **Sperling (1960)** compare the three methods directly. In **whole report**, participants reported an **average of 4.5 out of 12 letters, or 37.5%**. In **partial report**, they reported an **average of 3.3 out of 4 letters, or 82%**, and **participants could report any of the rows**, even though they learned which row only after the display was gone. In **delayed partial report**, they reported an **average of 1 out of 4 letters, or 25%**. >> The same people with the same displays scored very differently depending on the method. || The partial report score reveals how much was stored at the start. If participants could give 82% of whichever row was cued, then about 82% of every row must have been in sensory memory. That works out to roughly 10 of the 12 letters, which is more than twice what whole report suggests. >> Whole report underestimates capacity because the letters fade while people are naming them, not because the letters were never stored. || The delayed score reveals how quickly the store empties. After a short wait, only about one letter per row was left, so sensory memory holds a great deal of information but only for well under a second. >> Large capacity and fast decay are both needed to explain the full pattern of results.
17|**Sperling was studying visual sensory memory**, which is also called **iconic memory**. **Before his study, people thought that visual sensory memory could hold only 4 to 5 items**, because that is the number people managed in whole report. >> The older view took the whole report score as the size of the store. || **The other conditions in his study showed two things** about this belief. **It is true that people can only report 4 to 5 items before memory decays**, or fades away. **But sensory memory actually encodes the whole scene**, because partial report revealed that nearly every row was available at first. >> The limit lies in how much can be reported in time, not in how much was registered. || Sperling’s results establish that **sensory memory has a large capacity but fast decay**. **Within just 1 second, most of sensory memory decays**, and what remains is **only what was moved to short-term memory through attention**. >> The large capacity gives attention a full snapshot to choose from. >> The fast decay means attention has to choose quickly, and whatever it does not pick is lost.
18|Sperling also measured how availability changes with the **delay of the tone**. With **no delay**, about **82%** of the letters were available, and availability fell quickly over the next few tenths of a second. By a delay of about **1 second**, partial report had dropped to roughly the **whole report** level, about **36%**. >> The advantage of cueing a single row disappears within about a second. || The delay is the time between the display and the tone, and participants saw nothing during that time. The decline therefore reflects sensory memory fading after the letters were gone, which is the fast decay of iconic memory. >> Nothing new was shown during the delay, so the loss cannot be blamed on new input. || This decay also explains why whole report is limited. Naming letters takes longer than the icon lasts, so by the time someone reaches the fifth or sixth letter, most of the icon has already faded. >> The whole report limit of about four or five letters is set by decay rather than by capacity.
19|**Short-term memory**, or **STM**, is **the second stage of memory**. It **stores small amounts of information briefly**, and it is **very sensitive to interruption or interference**. >> A distraction or a competing thought can wipe out what short-term memory is holding. >> This is why a phone number can vanish the moment someone starts talking to us, since the interruption stops rehearsal and new information blurs what was there. || **Memory span** is how much short-term memory can hold at once. **STM is limited to holding seven, plus or minus two, bits of information at once**, so most people hold between five and nine items, and the range is written **7 ± 2**. >> The span counts separate units rather than raw letters or digits. || Short-term memory has two separate limits that are worth keeping apart. **Capacity** is how much it holds at once, while **duration** is how long information stays available, and interference can shorten duration even when the load is well within capacity. >> The 7 ± 2 limit applies to separate units, such as unrelated digits. >> Grouping items into larger units lets more information fit, since each group counts as one unit.
20|Information is **stored in STM** through several processes. **Recoding** means **reorganizing or modifying information in STM**, which changes how the information is represented. Grouping digits or turning a string of letters into a familiar acronym are both forms of recoding, and a recoded form is often easier to hold and use. >> Recoding changes the form of the information while keeping its content. || **Maintenance rehearsal** means **repeating information silently to prolong its presence in STM**. Repeating a phone number keeps it active, but this only works while the repetition continues. >> Once we stop repeating, the information can fade within seconds. || **Elaborative rehearsal** **links new information with existing memories and knowledge in long-term memory**, and it is **a good way to transfer information from STM into LTM**. Connecting a new fact to an example, a related idea or a personal experience gives it meaning. >> Those connections create several paths back to the information, which makes it easier to store and to retrieve later. || The three processes differ in how deeply they work on the information. Recoding changes its form, maintenance rehearsal repeats the same form, and elaborative rehearsal ties it to what we already know. >> Elaborative rehearsal leaves the most lasting trace because it builds the most connections.
21|**Short-term memory stores small amounts of information for a brief duration**. It **includes both new information received from the sensory stores and information recalled from long-term memory**, so it is the place where incoming information and stored knowledge meet. >> A task often needs both kinds of information at the same moment. || **STM is responsible for a great deal of our mental lives**. **Understanding sentences** requires holding the start of a sentence while the rest arrives, and **doing arithmetic** requires holding numbers and partial results while we calculate. **Dialing a phone number** requires holding the digits while pressing the keys. >> **Navigating from one place to another** requires combining a stored mental map with what we see around us. >> **Knowing where we are and what we are doing right now** also depends on short-term memory. || **Everything we think about or know at a particular moment involves STM**, **because short-term memory is our window on the present**. It holds the contents of our current awareness, and long-term knowledge enters present thought when it is retrieved into short-term memory. >> The limits of short-term memory therefore shape how much we can think about at once. >> When too much competes for it, information is lost and performance suffers.

23|Short-term memory raises **two important issues**, just as sensory memory does. **Duration** is **how long things stay in memory**, and **rehearsal seems to extend duration**, since repetition keeps information active. **Capacity** is **how many things fit in memory at a time**, and **chunking seems to extend capacity**, since grouping items into meaningful units lets more of them fit. >> Each issue has a strategy that seems to stretch the limit. || **Studying short-term memory is complicated because people use control processes a lot**. **Control processes** are strategies a person chooses, such as rehearsal and chunking. When people rehearse or chunk, their scores reflect both the store and the strategy, so measuring the store itself requires tasks that block or control these strategies. >> A good test of duration has to keep people from rehearsing. || The **Brown-Peterson task** measures the duration of short-term memory, and anyone can try a version of it directly. It blocks rehearsal with a demanding distractor task, so any forgetting reflects what happens to information that cannot be refreshed. >> Blocking rehearsal lets the task measure the store rather than the strategy.
24|The **duration of short-term memory** was measured by **Brown (1958)** and by **Peterson and Peterson (1959)**. They ran **the same studies, done at the same time, with the same results**, and that agreement makes the findings more convincing. The procedure has four steps. >> First, the participant sees **three letters and one number**, such as **F Z L 45**, and the three letters, called a **trigram**, are what must be remembered. >> Second, the participant **counts backward from the number by 3s**, as in 45, 42, 39. >> Third, the counting continues through a **delay of 3 to 18 seconds**, and fourth, the participant **recalls the three letters**. || Other trials use different trigrams and numbers, such as **B H M 87** and **X C G 98**. Every trial follows the same procedure, so differences between trials must come from what happened earlier in the series. >> This detail becomes important when we ask why the letters are forgotten. || Counting backward by threes is the heart of the design. It takes steady attention and keeps the inner voice busy, which prevents **maintenance rehearsal**, so the delay tests how long the letters last without being refreshed. >> Without the counting, participants would simply repeat the trigram and recall it perfectly.
25|The results of **Brown (1958)** and **Peterson and Peterson (1959)** for the **first trial only** compare recall after **3 seconds** with recall after **18 seconds**. After 3 seconds recall is very high, and after 18 seconds it is nearly as high, only slightly lower. >> On the first trial, the letters survive 18 seconds of counting with very little loss. >> Rehearsal is blocked, yet the trigram is still remembered well, so time by itself causes only a small loss. || The first trial is special because there are no earlier trigrams in memory. Nothing older is present to compete with the current letters, so this result serves as the baseline for every later trial. >> If decay were the main cause of forgetting, recall at 18 seconds should already be poor here. >> Since it is not poor, any extra forgetting on later trials must come from something that builds up across the series.
26|For the **third trial only**, the results of **Brown (1958)** and **Peterson and Peterson (1959)** look quite different. After **3 seconds** recall is still very high, but after **18 seconds** it is much lower, at a little more than half the 3-second level. >> The large drop appears only at the long delay. || The delay and the counting task are exactly the same as on the first trial. What has changed is that two earlier trigrams are now in memory, so when the participant tries to recall the newest letters, letters from earlier trials come to mind as well. >> The participant may even report a letter from an earlier trigram by mistake. || This competition is called **proactive interference**, in which older information disrupts memory for newer information. The longer the delay, the more the older trigrams get in the way. >> Just two earlier trigrams are enough to produce a large rise in forgetting at the long delay.
27|**Many trials later**, the results of **Brown (1958)** and **Peterson and Peterson (1959)** become more extreme. After **3 seconds** recall is still very high, but after **18 seconds** it is close to zero. >> The short delay is protected, while the long delay collapses. || By this point, many earlier trigrams have piled up in memory. Each one is a possible competitor for the current letters, and because all the trigrams are similar, they are easy to confuse with one another. >> Similarity is what makes the old trigrams such strong competitors. || **Proactive interference** has built up steadily across the series. At a short delay, the newest trigram is still fresh enough to stand out, but at a long delay it has weakened enough that the older trigrams win the competition at retrieval. >> Time and competition work together, since the delay gives the competitors their chance. || Comparing trials separates two possible causes of forgetting. Time is the same on every trial, since each long delay lasts 18 seconds, while the number of older trigrams keeps growing. >> The extra forgetting on later trials therefore comes from proactive interference rather than from time alone.
28|**Averaged over all trials**, the results of **Brown (1958)** and **Peterson and Peterson (1959)** reveal a large drop from the short delay to the long delay. After **3 seconds** recall is very high, and after **18 seconds** it falls to roughly one fifth of the 3-second level. >> This averaged curve looks like a steady loss over time. || The average mixes very different trials together. Early trials have high recall at both delays, while later trials have high recall at 3 seconds and very low recall at 18 seconds. >> The early trials pull the average up and the later trials pull it down, so the averaged long-delay result falls in between. || This averaged pattern is the result most often reported, and it was first taken as evidence that short-term memory decays rapidly. Looking trial by trial tells a different story, because forgetting grows as earlier trigrams pile up. >> The steep average decline comes mostly from later trials, where proactive interference is strongest. >> Averaging therefore hides interference behind something that looks like decay.
29|The studies by **Brown** and by **Peterson and Peterson** found that **the percentage of letters recalled decreases with longer delays**. After 18 seconds of counting, fewer letters are recalled than after 3 seconds. >> Longer delays mean more forgetting overall. || **But this pattern interacts with where in the series of trials the individual trial occurs**, because **recall of letters after long delays decreases as the series of trials gets longer**. An **interaction** means that the effect of one factor depends on the level of another factor. >> Here, how much a long delay hurts depends on how many trials came before it. || On the first trial a long delay costs little, but on later trials it costs a great deal. The difference comes from the older trigrams that build up and compete with the newest one. >> Pure decay predicts the same loss on every trial, since the delay is always 18 seconds. >> Interference predicts more loss as trigrams accumulate, and the data match interference.
30|**Peterson and Peterson** and **Brown** were interested in the **decay** of short-term memory. **Decay** is the idea that **a memory trace vanishes because time passes**, so they expected the letters to fade simply because time went by while rehearsal was blocked. >> Blocking rehearsal was meant to leave time as the only thing acting on the letters. || **It turns out that their studies revealed another type of forgetting that happens in STM**, which is **proactive interference**. In proactive interference, **what is already in STM affects the ability to add new things**. >> Forgetting grew with the number of earlier trials, and decay alone cannot explain that growth. || The **larger point** is that **forgetting in STM occurs through both decay and interference**. Time weakens memory traces, and competing memories make the target harder to find. >> Without rehearsal, the **effective duration of STM is 15 to 20 seconds**. >> Rehearsal can keep information much longer, which is why we can hold a phone number for as long as we keep repeating it.
31|**Interference theories** describe forgetting as **“memories interfering with memories.”** On this view, **forgetting is not caused by the mere passage of time**, but **is caused by one memory competing with or replacing another memory**. >> The more similar two memories are, the more strongly they compete. || There are **two types of interference**, and they are named for the direction of the disruption in time. In **retroactive interference**, newer information disrupts memory for older information, so the effect works backward in time. In **proactive interference**, older information disrupts memory for newer information, so the effect works forward. >> Retro means backward and pro means forward, which is an easy way to keep the names straight. || Both types follow a single principle. A memory becomes harder to retrieve when a similar memory competes with it at the moment of recall. >> This holds whether the competitor was learned before the target or after it.
32|**Retroactive interference** occurs **when a new memory interferes with remembering old information**. On a timeline, the old information comes first and the new information comes later, and the newer memory reaches back to disrupt the older one. >> The disruption runs backward in time. || A familiar case is **when a new phone number interferes with the ability to remember an old phone number**. After moving, a person tries to recall their old number, but the new number has been used again and again, so it keeps coming to mind and blocks the old one. >> Frequent use makes the new number an especially strong competitor. || The memory we are trying to find is the old number, and the disruption comes from something learned afterward, which is exactly what makes the interference retroactive. The same thing happens with a new password or a new address, where the replacement competes with the older version. >> In each case the target is old and the competitor is new.
33|**Proactive interference** is **the opposite of retroactive interference**. It occurs **when an old memory interferes with remembering new information**, so the older memory carries forward and disrupts the newer one. >> The disruption runs forward in time. || A familiar case is when **memories of where you parked your car on campus over the past week interfere with your ability to find your car today**. Today’s spot is the memory we want, but last week’s spots keep coming to mind and make today’s spot harder to recall. >> Each new day adds one more similar memory to the competition. || **Both proactive and retroactive interference are worst for routine events**. Routine events, like parking in the same lot every day, are very much alike, so they blur together in memory. **Unusual events are less prone to interference**, because they have few similar memories to compete with. >> A day when the car was parked somewhere strange stays easy to recall.
34|**Not only is information lost rapidly from STM, but there is also a limit to how much information can be held there**. Short-term memory has a **capacity limit** as well as a duration limit, so even with no delay at all, a long enough list will exceed it. >> Capacity and duration are separate limits that can each cause forgetting. || **Capacities vary from person to person**, and they are **measured by digit span**. **Digit span** is how many digits a person can repeat back in the correct order. The test presents rows of digits that get longer and longer, and the person repeats each row in order until a row becomes too long to hold. >> The point where the person starts to fail marks the edge of their capacity. || Order matters in this test, because each digit has to be remembered along with its position in the row. The test therefore measures memory for both the items and their order. >> Digit span gives a standard measure of short-term memory capacity, which is useful for comparing people and for studying what affects capacity.
35|A full **digit span** test uses rows that grow one digit at a time, starting with four digits such as **2 1 4 9** and going up to ten digits such as **5 8 5 2 9 8 1 6 3 7**. Most people repeat the shorter rows easily, while errors start to appear as rows near seven digits and become common beyond that. >> The growing rows let the test find exactly where each person’s limit lies. || **The number of digits in the longest row recalled completely correctly is the digit span**. Every digit has to be right and in the right place. >> A row with one wrong or misplaced digit does not count, since that error means the list has gone past the person’s capacity. || If someone repeats the seven-digit row perfectly but makes a mistake on the eight-digit row, their digit span is **seven**. This score measures how much the person can hold in short-term memory at once. >> A single number then summarizes the capacity of that person’s short-term memory.
36|**George A. Miller** wrote **“The Magical Number Seven, Plus or Minus Two,”** with the subtitle **“Some Limits on Our Capacity for Processing Information,”** which was later reprinted in Psychological Review, volume 101. He first gave it as an invited address to the Eastern Psychological Association in Philadelphia on **April 15, 1955**. >> Miller opens by saying that he has been **persecuted by an integer**. >> For seven years the number seven had followed him, turning up in his own data and in published journals. >> It appeared in many disguises, sometimes a little larger and sometimes a little smaller, but never so different that it could not be recognized. || Miller concluded that this number keeps appearing for a reason. Across tasks such as judging tones and remembering digits, performance broke down at around seven items, so something systematic limits how much information people can process at once. >> That limit became the classic estimate of short-term memory capacity. >> The plus or minus two allows for differences between people and between kinds of material.
37|**Miller (1956)** proposed that **people can remember 7 ± 2** units. The units can be **digits**, **words**, **numbers with multiple digits** or **phrases**. >> A phrase holds several words and a long number holds several digits, yet each one still counts as a single unit. || **Some researchers have suggested that capacity should be described in terms of the “amount of information,” rather than the “number of items.”** Seven digits and seven phrases are both seven items, but seven phrases contain far more words. >> On this view, a complex item takes up more room than a simple one. >> The meaning and complexity of the items would then affect how much fits. || **Alvarez and Cavanagh (2004)** tested this idea using **colored squares as well as complex objects**. They **used the change detection procedure**, in which people see one display and then judge whether a second display is the same or different. >> Comparing simple and complex objects reveals whether capacity depends on how much information each object carries.
38|**There may be multiple, modality-specific, or even domain-specific, forms of short-term memory**. **Modality** means the type of sensory input, such as vision or hearing, while **domain** means the type of content, such as words, numbers or locations. >> **How many such forms exist, and how specific they are, is something theorists argue about**. || **Visual short-term memory**, or **VSTM**, holds visual information for a short time after it disappears. It is **measured with the change detection task**, and on this task VSTM **may have a smaller capacity than memory for lists of digits or unrelated words**. >> A smaller visual limit would suggest that visual memory is a separate store. || Remembering the colors and places of objects is a different job from repeating a list of spoken words. If verbal and visual information use separate stores, then each would have its own capacity. >> The smaller visual limit fits this idea of separate stores.
39|In **change detection**, the first display, called **S1**, appears for **100 milliseconds** and contains a set of **colored squares** scattered across a gray background. Some colors appear more than once in the display. >> The display is brief and the colors repeat, and both features make the task demanding. || A tenth of a second is too short to name the colors, so the display has to be taken in as a visual snapshot. Participants need to remember which color was at which location, and once the display is gone they hold this information in **visual short-term memory**. >> Naming the colors silently is not an option, so the task measures visual memory rather than verbal memory. || Because colors repeat, a simple list of colors is not enough to succeed. Two squares of the same color in different places must be kept apart, so the task tests memory for color and location together. >> Holding each color in its own place is what makes the task demanding for visual short-term memory.
40|A simple display of three objects gives a sense of what visual short-term memory has to do. The display has a **yellow rectangle** standing upright, a **gray rectangle** lying on its side and a **blue oval**, and these objects differ in **color**, **shape**, **orientation** and **location**. >> Each object carries several features at once. || To notice a change, a person must remember each object’s features together. The yellow object is the tall rectangle, the gray object is the wide rectangle and the blue object is the oval. >> Remembering the colors and the shapes separately is not enough, since a change could swap which color goes with which shape. || A change to any one feature, such as a new color or a rotated rectangle, can only be caught if that feature was remembered for that particular object. Linking features to the right object is called **binding**. >> Displays with several features per object test how well visual short-term memory keeps those features bound together.
41|The second display, called **S2**, appears for **2,000 milliseconds**, and participants judge whether it is the **same as or different from S1**. S2 has the same squares in the same places, except that one has changed, since the square in the lower right that was **green** in S1 is now **white**. >> Only one square changes, so the participant has to catch a small difference. || Spotting the change requires comparing S2 with the memory of S1. S1 is gone, so only visual short-term memory can supply the earlier colors, and knowing that there were green squares somewhere is not enough. >> The participant needs the color tied to that exact spot. >> The second display stays up long enough to judge, so mistakes reflect memory rather than rushed viewing. || If memory holds the color at every location, the change stands out clearly. If some colors were lost, a change at one of those places will be missed. >> The more items people can hold, the better they detect changes, so performance across display sizes reveals capacity.
42|The full **change detection** procedure has three parts. **S1** appears for **100 milliseconds**, a **900-millisecond** blank gap follows, and then **S2** appears for **2,000 milliseconds** while the participant judges whether the two displays are the same or different. >> The gap makes sure S1 is completely gone, so the judgment depends on memory. || In the first test, the number of colored squares, called the **set size**, varied from 1 to 12. Accuracy was nearly perfect for up to three squares, but **accuracy falls off dramatically when there are more than four items**. >> **We can hold only about three to four items in visual working memory at a time**, which is a smaller limit than the 7 ± 2 found for verbal lists. || The second test used colored bars at different angles and compared three kinds of change. In **orientation-only** changes a bar rotated but kept its color, and in **color-only** changes a bar changed color but kept its angle. In **conjunction** changes, people had to remember color and angle together for each bar. >> Accuracy fell with set size in the same way for all three kinds of change. || Remembering two features of each object was about as easy as remembering one feature. Objects therefore seem to be stored as whole units. >> The limit depends on how many objects there are more than on how many features each object has.
43|According to **Alvarez and Cavanagh (2004)**, **participants’ ability to make the same or different judgment depended on the complexity of the stimuli**. They tested four kinds of objects that ranged from simple to complex. >> The simplest objects were **colored squares**, followed by **Chinese characters**, which are simple written forms. >> The more complex objects were **random polygons**, which are irregular blob-like shapes, and **shaded cubes**, which are three-dimensional cubes with different shading. || Estimated capacity fell steadily as the objects became more complex. **Colored squares** had the highest capacity at about **4.4** objects, and **Chinese characters** came next at about **2.8**. **Random polygons** were at about **2.0**, and **shaded cubes** were lowest at about **1.6**. >> The ordering of capacity matches the ordering of complexity. || The more complex the objects are, the fewer of them can be held. Each object still counts as one item, but complex objects carry more visual detail and use up more of the limited capacity. >> A colored square has very little detail, while a shaded cube has shading, edges and depth. >> Capacity therefore depends on the **amount of information** in each object, which supports the information-based view of capacity.
44|The **Alvarez and Cavanagh (2004)** stimuli come with a correction to their labels. The forms labeled **Chinese characters** carry a note in Chinese that reads **“These are radicals. And one of them is written wrong.”** >> **Radicals** are the building blocks of Chinese characters rather than full characters on their own. >> One of the three forms is also drawn incorrectly. || The forms still do their job in the study. Each one is a complex shape with its own arrangement of strokes, and that visual detail is exactly what participants had to hold in memory. >> What matters for the study is how much detail each form carries, not what it is called. || The result therefore stays the same, since **participants’ ability to make the same or different judgment depended on the complexity of the stimuli**. The written forms fell between the simple colored squares and the more complex polygons and cubes. >> The labeling problem concerns the names of the forms, not their visual complexity, which is the property the study measured.
45|**Organizing information into chunks lets short-term memory hold much more**. **Chunking** means **combining smaller units into larger meaningful units to improve capacity**, and however many pieces a chunk contains, it takes up a single slot. >> Seven digits such as 555-5100 become a few familiar groups. >> What makes a group meaningful is knowledge in long-term memory, so the more someone knows, the larger the chunks they can form. || **Ericsson and coworkers (1980)** worked with a **college student** whose **digit span** rose to **79** with training. He was a runner, and he **chunked digits into meaningful times for running**. >> Ordinary span is near seven, and his store still held only a few units. >> Each of those units, though, was a race time packed with several digits. || **Chase and Simon (1973)** found that **chess players chunk information based on meaningful positions within a game of chess**. A skilled player sees familiar clusters of pieces on the board and holds each cluster as one chunk. >> This is why a skilled player recalls far more pieces than a novice.
46|**Chase and Simon (1973)** compared **chess masters** and **beginners** on how many pieces they could place correctly after briefly viewing a chessboard. The comparison was made with two kinds of boards. >> The two kinds of boards differ only in whether the arrangement could occur in a real game. || When the pieces were in **meaningful arrangements** that could occur in a real game, the master recalled far more than the beginner, about three times as many pieces. Real positions match patterns the master has seen many times, so the master stores each familiar group of pieces as a single chunk. >> Chess knowledge turns many pieces into a few meaningful groups. || When the pieces were in **random arrangements** that ignore the rules of chess, the master and the beginner did about the same, and both recalled few pieces. Random boards match no stored patterns, so the master has to remember each piece separately, just like the beginner. >> The master’s advantage disappears as soon as the knowledge stops applying. || The study separates knowledge from memory capacity. If masters simply had better memories, they would win on random boards too. >> The master’s advantage comes from **chunking based on chess knowledge**, while the master’s short-term memory itself is about the same size as the beginner’s.
47|**Control processes** are **active processes that the person can control**, and they turn short-term memory from a passive store into an active system. **Maintenance rehearsal** means **repeating a stimulus over and over** to keep it active. >> **Strategies to make a stimulus more memorable** link it to things we already know. >> **Strategies of attention that help us focus on specific stimuli** decide what enters and stays in short-term memory. || **Building a “memory palace” is an ancient strategy for making information more memorable**. A memory palace is a familiar place pictured in the mind, such as a building with many rooms, and each item to remember is placed at a spot along a route through the building. >> The places are already stored in long-term memory, so they act as ready-made cues. >> Walking through the building in the mind brings the items back in order. || Looking closely at all the control processes that short-term memory needs leads to the idea of **working memory**. Working memory treats short-term memory as an active workspace in which information is held and worked on at the same time. >> This idea of an active workspace is the starting point for the study of working memory.
